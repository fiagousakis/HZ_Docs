# Επισκόπηση

Στο επάνω μέρος μπορούμε να επιλέξουμε αν θέλουμε να δούμε τα τραπέζια **tables** για να κάνουμε καταχώρηση παραγγελίας σε κάποιο τραπέζι ή αν θέλουμε να δούμε τις παραγγελίες **take away**.

Στα δεξιά υπάρχουν οι βάρδιες **shifts**, οι οποίες χωρίζονται στις ενεργές, σε αυτές δηλαδή που εκτελούνται εκείνη τη δεδομένη χρονική στιγμή και έχουμε και μια λίστα με τις πιο πρόσφατες βάρδιες που έχουν κλείσει.

Δεξιότερα βλέπουμε τον χρήστη μας, και από το πεδίο αυτό μπορούμε να δούμε τις αναφορές για τις καταχωρήσεις που κάναμε ως χρήστης ανά βάρδια.

Στα αριστερά, υπάρχει το μενού. Το dashboard είναι η αρχική σελίδα που βλέπουμε όταν επισκεφτόμαστε την παραγγελιοληψία POS και έχει ως προεπιλογή τα tables (dashboard και tables στο menu ταυτίζονται).&#x20;
