# Δημιουργία παραγγελίας

Μπορούμε να δημιουργήσουμε μία νέα παραγγελία από δύο σημεία:&#x20;

* από το Dashboard (Tables) επιλέγοντας ένα από τα τραπέζια (τα τραπέζια με κόκκινη ένδειξη στα αριστερά είναι ανοιχτά ενώ χωρίς κόκκινη γραμμή είναι διαθέσιμα (ελεύθερα). &#x20;
* από το Take away πατόντας δεξιά επάνω το + Create Order.

Στο επόμενο βήμα Βλέπουμε τις κατηγορίες των προϊόντων και δεξιά βλέπουμε τον αριθμό του τραπεζιού ή την ένδειξη take away και το σημείο που θα καταχωρηθούν τα επιλεγμένα προιόντα της παραγγελίας.

<figure><img src="../.gitbook/assets/image (19).png" alt=""><figcaption></figcaption></figure>

Επιλέγουμε μία κατηγορία και επιλέγουμε το προιόν που θέλουμε ή κάνουμε αναζήτηση προιόντος από το πεδίο αναζήτησης χωρίς να επιλέξουμε κατηγορία. Στη συνέχεια επιλέγουμε κάποια από τα συνοδευτικά, αν θέλουμε βάζουμε κάποια σημείωση και πατάμε προσθήκη προιόντος στο κάτω μέρος της φόρμας.\
Μπορούμε να προσθέσουμε ή να μειώσουμε την ποσότητα από το action button (3 τελείες) επιλέγοντας Add One ή Remove one.

> Παράδειγμα: κατηγορία καφέδες και επιλέγουμε τον καφέ που θέλουμε, επιλέγουμε κάποια από τα συνοδευτικά, όπως για παράδειγμα μέγεθος καφέ, ζάχαρη, είδος ζάχαρης και αν θέλουμε βάζουμε και μια σημείωση ’’ με λίγο πάγο’’ και επιλέγουμε add product.&#x20;

Για να επιστρέψουμε στις κατηγορίες και να επιλέξουμε επόμενο προϊόν άλλης κατηγορίας πατάμε στο **Home** και ακολουθούμε την ίδια διαδικασία.&#x20;

Για κάθε προϊόν στη παραγγελία έχουμε τις παρακάτω διαθέσημες ενέργειες από το action button (3 τελείες) δεξιά.&#x20;

* Edit product / για να καταχωρήσουμε κάποια επιπλέον σημείωση
* Edit price / για να τροποποιήσουμε την τιμή του
* Edit course / για να θέσουμε τη σειρά παράθεσης του προϊόντος
* Add discount / για να ορίσουμε κάποια ποσοστιαία έκπτωση
* Delete product / Για να το διαγράψουμε
* Add one / remove one για να αυξήουμε ή να μειώσουμε την ποσότητα <br>

Για το σύνολο της παραγγελίας πατώντας το action button (3 τελείες)  δεξιά από το αριθμό παραγγελίας έχουμε τις παρακάτω διαθέσημες ενέργειες.&#x20;

* Change Table / για να μεταφέρουμε την παραγγελία σε κάποιο διαφορετικό τραπέζι
* Add Discount / για να θέσουμε κάποια ποσοστιαία έκπτωση. Η έκπτωση αυτή θα εφαρμοστεί σε όλα τα προϊόντα που συμπεριλαμβάνονται σε αυτή
* Delete Order / για να διαγράψουμε τη παραγγελία.<br>

Στο πεδίο Total βλέπουμε το σύνολο των χρεώσεων, μια ανάλυση των τιμών σε καθαρή τιμή, σύνολο ΦΠΑ, αν έχει εφαρμοστεί κάποια έκπτωση καθώς και αν έχει γίνει καταχώρηση κάποιας πληρωμής και το υπόλοιπο.

\
Πατώντας το action button (3 τελείες)  δεξιά από το δωμάτιο ή την ένδειξη Take away έχουμε τις παρακάτω διαθέσημες ενέργειες

* να αλλάξουμε σερβιτόρο
* να αλλάξουμε αριθμό ατόμων
* να μεταφέρουμε σε άλλο τραπέζι
* να στείλουμε μήνυμα στη κουζίνα
* να εκτυπώσουμε αποδεικτικό&#x20;
* να αλλάξουμε την κατανομή των προϊόντων με βάση τη σειρά καταχώρησης παραγγελίας ή ανά course, δηλαδή σύμφωνα με την σειρά παράθεσης που έχει οριστεί στο κάθε προϊόν

Σε περίπτωση που έχει ήδη εκδοθεί το ΔΠ και θέλουμε να αφαιρέσουμε κάποιο προϊόν τότε πατάμε στις 3 τελείες δεξιά του προϊόντος επιλέγουμε cancel product και τo προϊόν αυτό αφαιρείται από τον λογαριασμό και για να κάνουμε επανεκτύπωση της παραγγελίας πατάμε στις 3 τελείες δεξιά του order και επιλέγουμε print order.

\
Έστω ότι ο πελάτης παραγγέλνει κ κάτι επιπλέον, καταχωρούμε τα προϊόντα πάλι όπως είδαμε προηγουμένως, πλέον βλέπουμε ότι έχουμε δυο διαφορετικά orders και πατάμε fire order για να εκδώσουμε και το επόμενο δελτίο το δελτίο παραγγελίας.

\
Κάθε δελτίο παραγγελίας μπορεί να εκτυπωθεί ξεχωριστά ή, εναλλακτικά, να πραγματοποιηθεί μαζική εκτύπωση όλων των δελτίων του τραπεζιού μέσω της επιλογής “Print Check” επάνω δεξιά.

\
Σε περίπτωση αλλαγής τραπεζιού, υπάρχει η δυνατότητα μεταφοράς παραγγελίας από ένα τραπέζι σε άλλο είτε το κάθε δελτίο παραγγελίας μεμονωμένα πατώντας στις 3 τελείες δεξιά και change table είτε μαζικά όλα τα ΔΠ μέσω της επιλογής "Transfer Table".

Κατά τη μεταφορά, αν η παραγγελία μεταφερθεί σε κάποιο άλλο ήδη ανοιχτό τραπέζι τότε γίνεται ανάθεση στο σερβιτόρο που έχει κάνει τις αρχικές καταχωρήσεις σε αυτό και θα πρέπει να ενημερωθούν τα άτομα του τραπεζιού εκ νέου.
