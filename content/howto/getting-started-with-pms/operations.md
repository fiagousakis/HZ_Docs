# Operations

* **Tasks**

Στη σελίδα αυτή, έχουμε πλήρη εικόνα όλων των σημειώσεων που υπάρχουν στις κρατήσεις του καταλύματός μας.<br>

* **Transfers**

Σε περίπτωση που το κατάλυμά μας προσφέρει υπηρεσίες μεταφοράς των πελατών, όπως παραλαβή από το αεροδρόμιο κατά την άφιξη, η σελίδα αυτή μας δίνει τη δυνατότητα να δημιουργήσουμε μια μεταφορά.<br>

* **Logs**

Στη σελίδα αυτή, μπορούμε να βρούμε καταγεγραμμένες όλες τις κινήσεις που έχουν γίνει στο σύστημά μας και από ποιον χρήστη, με βάση την πιο πρόσφατη.<br>

* **Email Logs**

Στη σελίδα αυτή, μπορούμε να δούμε όλα τα αρχεία που έχουμε στείλει ως email μέσα από το σύστημα.<br>

* **Housekeeping**

Η λειτουργία αυτή είναι απαραίτητη για το Housekeeping μας, καθώς μας εμφανίζει την κατάσταση των δωματίων μας μεμονωμένα για την ημέρα που θα ρυθμίσουμε.<br>

* **Maintenance**

Η λειτουργία αυτή μας επιτρέπει να προσθέσουμε μια προγραμματισμένη συντήρηση ή μια βλάβη στο κατάλυμά μας. Μπορούμε να αναζητήσουμε κάτι συγκεκριμένο χρησιμοποιώντας την μπάρα αναζήτησης ή εφαρμόζοντας τα κατάλληλα φίλτρα. Επίσης, μπορούμε να εκτυπώσουμε τη λίστα αυτή ή να την εξάγουμε σε Excel. Μπορούμε να προσθέσουμε μια καινούργια συντήρηση πατώντας εδώ.<br>

* **Events**

Εδώ μπορούμε να καταχωρίσουμε τυχόν εκδηλώσεις που μπορεί να λάβουν μέρος στο κατάλυμα μας ή στην περιοχή μας. Αφορά καταχώριση πληροφοριακού χαρακτήρα, η οποία μπορεί να εμφανιστεί και στο πλάνο των κρατήσεων.
