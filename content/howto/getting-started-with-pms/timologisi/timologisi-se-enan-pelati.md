# Τιμολόγηση σε έναν πελάτη

H διαδικασία τιμολόγησης μιας κράτησης για όλες τις χρεώσεις που συμπεριλαμβάνονται σε αυτή.

Εφόσον η τιμολόγηση της κράτησης εκκρεμεί, μας παραπέμπει αυτόματα στη φόρμα τιμολόγησης.\
\
Στην οθόνη που μας εμφανίζεται, από τα αριστερά βλέπουμε τις πληροφορίες της κράτησης, από τα δεξιά βλέπουμε τις διαμονές τις οποίες συμπεριλαμβάνονται σε αυτή και ακριβώς από κάτω είναι οι διαθέσιμες επιλογές τιμολόγησης. Η επιλογή «τιμολογήστε έναν πελάτη» είναι και η προκαθορισμένη. Σε αυτήν την περίπτωση, όλες οι χρεώσεις της κράτησης θα χρεωθούν στον ίδιο λογαριασμό. Για το τέλος ανθεκτικότητας θα δημιουργηθεί ξεχωριστός λογαριασμός αυτόματα.

Στη συνέχεια, επιλέγουμε αν θα τιμολογήσουμε σε ιδιώτη ή σε επιχείρηση. Ανάλογα με τις πληροφορίες της κράτησης, ο τύπος του πελάτη είναι προκαθορισμένος. Ωστόσο, αν επιθυμούμε, στο στάδιο αυτό μπορούμε να τον αλλάξουμε, για παράδειγμα από ιδιώτη σε επιχείρηση και ακριβώς από κάτω μπορούμε να αναζητήσουμε το προφίλ είτε να δημιουργήσουμε νέο προφίλ κλικάροντας στο πεδίο της δημιουργίας στα δεξιά.

Σύμφωνα με την επιλογή μας, σε αυτό το στάδιο θα εκδοθεί απόδειξη παροχής υπηρεσιών ή τιμολόγιο.

Επιλέγουμε create bills και στην επόμενη φόρμα θα δούμε τους ανοιχτούς λογαριασμούς που έχουν δημιουργηθεί. Στη συγκεκριμένη περίπτωση βλέπουμε ότι υπάρχει υπολειπόμενο ποσό προς εξόφληση και για να καταχωρήσουμε πληρωμή, επιλέγουμε τον τύπο του πελάτη. Να σημειώσουμε στο σημειο αυτό, ότι το προφίλ πελάτη που θα χρησιμοποιήσουμε για τη καταχώρηση της πληρωμής χρειάζεται να είναι το ίδιο με αυτό που θα εκδοθεί το παραστατικό. Επιλέγουμε το τρόπο είσπραξης των χρημάτων, ορίζουμε το ποσό που λάβαμε και επιλέγουμε add payment. Βλέπουμε ότι το balance έχει μηδενίσει και για να εκδώσουμε τα παραστατικά, επιλέγουμε issue invoices.
