# Τιμολόγηση

Οι επιλογές της τιμολόγησης μιας κράτησης ποικίλουν, καθώς μπορεί να έχουμε μεμονωμένες κρατήσεις, group κρατήσεις, είτε και κρατήσεις που απαιτούν μια πιο σύνθετη διαδικασία τιμολόγησης.

Θα μεταβούμε σε μια κράτηση, για να αναλύσουμε τις επιλογές της τιμολόγησης μια προς μια.

Για να ξεκινήσουμε τη διαδικασια της τιμολόγησης μπορουμε είτε να πατήσουμε το κουμπί με την κατασταση της τιμολόγησης είτε, στην περιπτωση που θέλουμε να κανουμε παραλληλα check out της κράτησης, επιλέγουμε την κατάσταση της κράτησης από in house σε check out.
