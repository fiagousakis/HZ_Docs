# Τιμολόγηση group κρατήσεων

Τιμολόγηση group κρατήσεων δηλαδή κρατήσεων που συμπεριλαμβάνουν παραπάνω από μία διαμονές κάτω από τον ίδιο κωδικό κράτησης.\
\
Ξεκινάμε πάλι την τιμολόγηση από επάνω δεξιά και για να τιμολογήσουμε τον κάθε πελάτη ξεχωριστά, θα πατήσουμε πάνω στις επιλογές της τιμολόγησης και θα επιλέξουμε τιμολογήστε τον κάθε πελάτη ξεχωριστά. Η επιλογή του πελάτη για κάθε παραστατικό που θα δημιουργηθεί θα γίνει αυτόματα ανάλογα με τα στοιχεία της εκάστοτε διαμονής.\
Για να συνεχίσουμε τη διαδικασία επιλέγουμε create bills.

Στη φόρμα που ανοίγει, έχουν δημιουργηθεί οι πρόχειροι λογαριασμοί και στη στήλη του balance διακρίνουμε ότι υπάρχει υπολειπόμενο ποσό προς εξόφληση. Στην περίπτωση που θέλουμε να προβούμε στην εξόφληση των συγκεκριμένων λογαριασμών χρειάζεται να μεταβούμε στις πληρωμές και να επιλέξουμε από ποιον πελάτη έχουμε λάβει τα χρήματα. Σε αυτό το σημείο να σημειώσουμε ότι το προφίλ που θα χρησιμοποιήσουμε είναι απαραίτητο να είναι το ίδιο με το προφίλ του πελάτη που θα εκδοθεί και το παραστατικό.

Ακριβώς από δίπλα ορίζουμε τον τρόπο που λάβαμε τα χρήματα, καταχωρούμε το ποσό και επιλέγουμε add payment.\
\
Για να προβούμε στην έκδοση των παραστατικών, επιλέγουμε issue invoices.&#x20;
