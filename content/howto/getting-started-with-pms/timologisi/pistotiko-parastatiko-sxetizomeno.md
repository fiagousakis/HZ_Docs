# Πιστωτικό παραστατικό (σχετιζόμενο)

Εάν θέλουμε να πιστώσουμε κάποιο παραστατικό που είχε εκδοθεί, θα χρειαστεί να μεταβούμε στο παραστατικό αυτό, να πατήσουμε στις τρεις τελείες δεξιά και να επιλέξουμε την ακύρωση.

&#x20;Το hotelizer pms θα εκδώσει αυτόματα το πιστωτικό παραστατικό και στην ενότητα των λογαριασμών της κράτησης θα ανοίξει έναν ανοιχτό λογαριασμό στην περίπτωση που θέλουμε να τον επεξεργαστούμε και να καταχωρήσουμε κάποια διαφορετικά στοιχεία.\
<br>

'Εστω ότι αντί για τιμολόγιο παροχής υπηρεσιών θέλουμε να εκδώσουμε Απόδειξη Παροχής Υπηρεσιών στο όνομα του πελάτη. Στην περίπτωση αυτή, θα πατήσουμε στις τρεις τελείες δεξιά του λογαριασμού και θα επιλέξουμε τη γρήγορη επεξεργασία. Στη φόρμα που μας ανοίγει, στο επάνω πεδίο, έχουμε τη δυνατότητα να αλλάξουμε το τύπο του παραστατικού, να ορίσουμε το προφίλ του πελάτη που θέλουμε να χρησιμοποιήσουμε και ακριβώς από κάτω έχουμε τη δυνατότητα να επεξεργαστούμε τις χρεώσεις που συμπεριλαμβάνονται μέσα στο παραστατικό κλικάροντας τις τρεις τελείες δεξιά και επιλέγοντας γρήγορη επεξεργασία. Αφού βεβαιωθούμε ότι έχουμε ενημερώσει το λογαριασμο με τα σωστά στοιχεία, επιλέγουμε ενημέρωση λογαριασμού και για να ολοκληρώσουμε τη διαδικασία και να εκδώσουμε το νέο παραστατικό, μεταβαίνουμε στα δεξιά του λογαριασμού και πατάμε issue invoice .
