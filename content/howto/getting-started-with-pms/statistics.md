# Statistics

<figure><img src="../.gitbook/assets/image (17).png" alt=""><figcaption></figcaption></figure>

Στην ενότητα Στατιστικά προβάλλονται τα δεδομένα απόδοσης του καταλύματος. Τα στατιστικά επανυπολογίζονται αυτόματα μία φορά την ημέρα. Ωστόσο, μέσω της ενότητας "Overview" έχετε τη δυνατότητα να πραγματοποιήσετε χειροκίνητη ενημέρωση των στατιστικών, επιλέγοντας την περίοδο που σας ενδιαφέρει.<br>

* **Overview**&#x20;

Η επισκόπηση μας δίνει στατιστικά στοιχεία του καταλύματός μας για την περίοδο του τρέχοντος έτους, όπως σύνολο εσόδων, έσοδα δωματίων, έσοδα ανά ημέρα, πληρότητα κ.ά. Μπορούμε να δούμε στατιστικά στοιχεία για οποιαδήποτε περίοδο επιθυμούμε, προσαρμόζοντας τις ημερομηνίες στο ημερολόγιο πάνω δεξιά. Οι πίνακες total revenues και room type revenues μπορούν να εξαχθούν σε αρχείο excel.<br>

* **Daily Summary**

Στην ενότητα αυτή προβάλλονται στατιστικά ανά ημέρα, όπως η ημερήσια πληρότητα, το μέσο ημερήσιο έσοδο (Average Daily Rate), το συνολικό εισόδημα, οι πληρωμές κ.ά. Η περίοδος προβολής μπορεί να προσαρμοστεί επιλέγοντας τις επιθυμητές ημερομηνίες από το ημερολόγιο, το οποίο βρίσκεται πάνω δεξιά. Επιπλέον, διατίθεται φίλτρο για την παρακολούθηση στατιστικών ανά τύπο δωματίου, σε περίπτωση που θέλετε να εστιάσετε σε συγκεκριμένες μονάδες.<br>

* **Monthly Summary**&#x20;

Mπορούμε να δούμε μια σύνοψη εσόδων ανά μήνα για το κατάλυμά μας, είτε σε μικτά είτε σε καθαρά κέρδη, για την περίοδο του τρέχοντος έτους συγκριτικά με το προηγούμενο. Μπορούμε να προσαρμόσουμε την περίοδο που θέλουμε να δούμε αλλάζοντας τις ημερομηνίες από το ημερολόγιο πάνω δεξιά. Επίσης, μπορούμε να εξάγουμε κάθε λίστα σε αρχείο Excel.<br>

* **Room Types Summary**

Στη σελίδα αυτή μπορούμε να δούμε κάποια στατιστικά στοιχεία για το κατάλυμά μας ανά τύπο δωματίου, όπως πληρότητα, έσοδα δωματίων, ADR και κρατήσεις. Μπορούμε να προσαρμόσουμε την περίοδο που θέλουμε να δούμε, αλλάζοντας τις ημερομηνίες από το ημερολόγιο πάνω δεξιά. Επίσης, μπορούμε να εξάγουμε κάθε λίστα σε αρχείο Excel.<br>

* **Sources Summary**

Στη σελίδα αυτή μπορούμε να δούμε κάποια στατιστικά στοιχεία (πρώτο γράφημα) για τις κρατήσεις του καταλύματός μας ανά πηγή/κανάλι, όπως τηλεφωνικές κρατήσεις, booking.com, website, expedia κ.ά. Στο δεύτερο γράφημα μπορούμε να δούμε πιο αναλυτικά ανά μήνα, τα έσοδα που έχουμε ανά πηγή. Μπορούμε να προσαρμόσουμε την περίοδο που θέλουμε να δούμε, αλλάζοντας τις ημερομηνίες από το ημερολόγιο πάνω δεξιά. Επίσης, μπορούμε να εξάγουμε κάθε λίστα σε αρχείο Excel.<br>

* **Countries Summary**

Στη σελίδα αυτή μπορούμε να δούμε κάποια στατιστικά στοιχεία (πρώτο γράφημα) για τις κρατήσεις και τα έσοδα του καταλύματός μας ανά εθνικότητα. Στο δεύτερο γράφημα μπορούμε να δούμε πιο αναλυτικά ανά μήνα, τα έσοδα που έχουμε ανά εθνικότητα. Μπορούμε να προσαρμόσουμε την περίοδο που θέλουμε να δούμε αλλάζοντας τις ημερομηνίες από το ημερολόγιο πάνω δεξιά. Επίσης, μπορούμε να εξάγουμε κάθε λίστα σε αρχείο Excel.<br>

* **Revenues By Department**

Στη σελίδα αυτή μπορούμε να δούμε τα έσοδα των επιμέρους τμημάτων μιας κράτησης (π.χ. έσοδα διαμονής, φόροι διαμονής, bar, εστιατόριο) ανά μήνα. Μπορούμε να προσαρμόσουμε την περίοδο που θέλουμε να δούμε αλλάζοντας τις ημερομηνίες από το ημερολόγιο πάνω δεξιά. Επίσης, μπορούμε να εξάγουμε τη λίστα σε αρχείο Excel.<br>

* **Businesses summary**

Στη σελίδα αυτή μπορούμε να δούμε κάποια στατιστικά στοιχεία (πρώτο γράφημα) για τις κρατήσεις με τις εταιρίες που έχουμε συνεργασία στο κατάλυμά μας. Στο δεύτερο γράφημα μπορούμε να δούμε πιο αναλυτικά ανά μήνα, τα έσοδα που έχουμε ανά εταιρία. Μπορούμε να προσαρμόσουμε την περίοδο που θέλουμε να δούμε αλλάζοντας τις ημερομηνίες από το ημερολόγιο πάνω δεξιά. Επίσης, μπορούμε να εξάγουμε κάθε λίστα σε αρχείο Excel.<br>

* **Segments summary**

Από προεπιλογή, δεν υπάρχουν δεδομένα σε αυτή την ενότητα των στατιστικών. Τα segments αναφέρονται σε κατηγορίες ή ομάδες πελατών που μοιράζονται κοινά χαρακτηριστικά ή προτιμήσεις, και δημιουργούνται μέσω της ενότητας Settings. Αφού δημιουργηθούν, τα segments μπορούν να συνδεθούν με τις κρατήσεις, επιτρέποντάς σας να αποκτήσετε στατιστικά δεδομένα ανά κατηγορία πελατών. &#x20;
