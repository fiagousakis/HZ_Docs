# Ομάδες Δωματίων

Η ενότητα **Ομάδες Δωματίων (Room Groups)** επιτρέπει τη δημιουργία και διαχείριση ομάδων δωματίων. Οι ομάδες χρησιμοποιούνται για τη σύνδεση πολλών δωματίων σε μια ενιαία ενότητα (π.χ. δωμάτια 101 και 102 μπορούν να συνδεθούν ως "Family Room"). Υποστηρίζουν διαφορετικούς τύπους ομάδων όπως parent-child.

<figure><img src="../../../.gitbook/assets/Screenshot 2026-07-08 140714.jpg" alt=""><figcaption></figcaption></figure>

#### Πεδίο Αναζήτησης

| Στοιχείο              | Περιγραφή             | Λειτουργία                 |
| --------------------- | --------------------- | -------------------------- |
| **Πεδίο Αναζήτησης**  | "Αναζήτηση ομάδας..." | Αναζήτηση ομάδων ανά όνομα |
| **Κουμπί Αναζήτησης** | Εικονίδιο αναζήτησης  | Εκτέλεση αναζήτησης        |

#### Κουμπί Προσθήκης

| Κουμπί              | Περιγραφή | Λειτουργία                      |
| ------------------- | --------- | ------------------------------- |
| **Προσθήκη Ομάδας** | Button    | Δημιουργία νέας ομάδας δωματίων |

#### Λϊστα Ομάδων

| Στήλη          | Περιγραφή                                   | Τύπος  |
| -------------- | ------------------------------------------- | ------ |
| **ΟΝΟΜΑ**      | Όνομα της ομάδας (π.χ. Family)              | Text   |
| **GROUP TYPE** | Τύπος ομάδας (Norma, Virtual, Parent-Child) | Text   |
| **ΕΝΕΡΓΟ**     | Κατάσταση ενεργοποίησης (ACTIVE/INACTIVE)   | Status |
| **ΕΝΕΡΓΕΙΕΣ**  | Κουμπί ενεργειών                            | Menu   |

Κάθε σειρά στον πίνακα έχει ένα κουμπί ενεργειών που ανοίγει ένα μενού με τις ακόλουθες επιλογές:

* **Επεξεργασία ομάδας** - Ανοίγει τη σελίδα λεπτομερειών για επεξεργασία της ομάδας
* **Διαγραφή ομάδας** - Αφαίρεση της ομάδας από το σύστημα



### Δημιουργία / Επεξεργασία Νέας Ομάδας Δωματίων

<figure><img src="../../../.gitbook/assets/Screenshot 2026-07-08 140741.jpg" alt=""><figcaption></figcaption></figure>

1. Κάντε κλικ στο κουμπί "Προσθήκη Ομάδας" ή κλικ στη γραμμή ομάδας για επεξεργασία.
2. Συμπλήρωση Πληροφοριών

| Πεδίο          | Περιγραφή        | Παράδειγμα                   | Υποχρεωτικό |
| -------------- | ---------------- | ---------------------------- | ----------- |
| **ΟΝΟΜΑ**      | Όνομα της ομάδας | Suite Family                 | ✓           |
| **GROUP TYPE** | Τύπος ομάδας     | Norma, Virtual, Parent-Child | ✓           |
| **ΕΝΕΡΓΟ**     | Ενεργοποίηση     | ΝΑΙ                          | -           |

3. Αποθήκευση
   * Κάντε κλικ στο κουμπί "ΔΗΜΙΟΥΡΓΙΑ ΟΜΑΔΑΣ" ή "ΕΝΗΜΕΡΩΣΗ".
   * Η ομάδα δημιουργείται και προστίθεται στη λίστα

### Διαγραφή Ομάδας Δωματίων

1. **Άνοιγμα Μενού Ενεργειών**
   * Κάντε κλικ στο κουμπί ενεργειών δίπλα στην ομάδα
2. **Επιλογή Διαγραφής**
   * Επιλέξτε "Διαγραφή ομάδας" από το μενού
3. **Επιβεβαίωση Διαγραφής**
   * Επιβεβαιώστε τη διαγραφή στο παράθυρο διαλόγου
