# Ανέσεις

Η ενότητα **Ανέσεις (Amenities)** επιτρέπει τη δημιουργία και διαχείριση ανέσεων δωματίων. Οι ανέσεις χρησιμοποιούνται για την περιγραφή των διαθέσιμων υπηρεσιών και εξοπλισμού (π.χ. WiFi, Air Conditioning, Gym, Spa).

<figure><img src="../../../.gitbook/assets/Screenshot 2026-07-08 141222.jpg" alt=""><figcaption></figcaption></figure>

#### Πεδίο Αναζήτησης

| Στοιχείο              | Περιγραφή             | Λειτουργία          |
| --------------------- | --------------------- | ------------------- |
| **Πεδίο Αναζήτησης**  | "Αναζήτηση ανέσης..." | Αναζήτηση ανά όνομα |
| **Κουμπί Αναζήτησης** | Εικονίδιο αναζήτησης  | Εκτέλεση αναζήτησης |

#### Κουμπί Προσθήκης

| Κουμπί              | Περιγραφή | Λειτουργία             |
| ------------------- | --------- | ---------------------- |
| **Προσθήκη Ανέσης** | Button    | Δημιουργία νέας ανέσης |

#### Λίστα Ανέσεων

| Στήλη         | Περιγραφή                    | Τύπος  |
| ------------- | ---------------------------- | ------ |
| **ΟΝΟΜΑ**     | Όνομα της ανέσης (π.χ. WiFi) | Text   |
| **ΚΑΤΗΓΟΡΙΑ** | Κατηγορία ανέσης             | Text   |
| **ΕΝΕΡΓΟ**    | Κατάσταση ενεργοποίησης      | Status |
| **ΕΝΕΡΓΕΙΕΣ** | Κουμπί ενεργειών             | Menu   |

Κάθε σειρά στον πίνακα έχει ένα κουμπί ενεργειών που ανοίγει ένα μενού με τις ακόλουθες επιλογές:

* **Γρήγορη Επεξεργασία** - Ανοίγει inline editor
* **Επεξεργασία** - Ανοίγει τη σελίδα λεπτομερειών
* **Διαγραφή** - Αφαίρεση της ανέσης

### 5.1 Δημιουργία/Επεξεργασία  Ανέσης

Κάντε κλικ στο κουμπί "Προσθήκη Ανέσης" ή κλικ στη γραμμή άνεσης για επεξεργασία.

**Πληροφορίες**

| Πεδίο         | Περιγραφή        | Παράδειγμα | Υποχρεωτικό |
| ------------- | ---------------- | ---------- | ----------- |
| **ΟΝΟΜΑ**     | Όνομα της ανέσης | Free WiFi  | ✓           |
| **ΚΑΤΗΓΟΡΙΑ** | Κατηγορία        | Technology | -           |
| **ΕΝΕΡΓΟ**    | Ενεργοποίηση     | ΝΑΙ        | -           |

Κάντε κλικ στο κουμπί "ΔΗΜΙΟΥΡΓΙΑ" ή "ΕΝΗΜΕΡΩΣΗ".
