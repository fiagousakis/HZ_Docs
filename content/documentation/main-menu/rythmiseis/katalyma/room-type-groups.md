# Room Type Groups

Η ενότητα **Ομάδες Τύπων Δωματίων (Room Type Groups)** επιτρέπει τη δημιουργία και διαχείριση ομάδων τύπων δωματίων. Οι ομάδες χρησιμοποιούνται για τη σύνδεση πολλών τύπων δωματίων σε μια ενιαία κατηγορία (π.χ. "Deluxe Rooms" και "Premium Rooms" μπορούν να ομαδοποιηθούν ως "Luxury Rooms").

<figure><img src="../../../.gitbook/assets/Screenshot 2026-07-08 140836.jpg" alt=""><figcaption></figcaption></figure>

#### Πεδίο Αναζήτησης

| Στοιχείο              | Περιγραφή                   | Λειτουργία                 |
| --------------------- | --------------------------- | -------------------------- |
| **Πεδίο Αναζήτησης**  | "Αναζήτηση ομάδας τύπου..." | Αναζήτηση ομάδων ανά όνομα |
| **Κουμπί Αναζήτησης** | Εικονίδιο αναζήτησης        | Εκτέλεση αναζήτησης        |

#### Κουμπί Προσθήκης

| Κουμπί                    | Περιγραφή | Λειτουργία                            |
| ------------------------- | --------- | ------------------------------------- |
| **Προσθήκη Ομάδας Τύπου** | Button    | Δημιουργία νέας ομάδας τύπων δωματίων |

#### Λίστα Ομάδων Τύπων Δωματίων

| Στήλη         | Περιγραφή                                 | Τύπος  |
| ------------- | ----------------------------------------- | ------ |
| **ΟΝΟΜΑ**     | Όνομα της ομάδας τύπου (π.χ. Deluxe)      | Text   |
| **ΕΝΕΡΓΟ**    | Κατάσταση ενεργοποίησης (ACTIVE/INACTIVE) | Status |
| **ΕΝΕΡΓΕΙΕΣ** | Κουμπί ενεργειών                          | Menu   |

Κάθε σειρά στον πίνακα έχει ένα κουμπί ενεργειών που ανοίγει ένα μενού με τις ακόλουθες επιλογές:

* **Γρήγορη Επεξεργασία** - Ανοίγει inline editor για γρήγορη τροποποίηση βασικών πεδίων
* **Επεξεργασία** - Ανοίγει τη σελίδα λεπτομερειών για επεξεργασία της ομάδας
* **Διαγραφή** - Αφαίρεση της ομάδας τύπου από το σύστημα

### Δημιουργία / Επεξεργασία Ομάδας Τύπων Δωματίων

<figure><img src="../../../.gitbook/assets/Screenshot 2026-07-08 140850.jpg" alt=""><figcaption></figcaption></figure>

1. Κλικ στο Κουμπί Προσθήκης
   * Κάντε κλικ στο κουμπί "Προσθήκη Ομάδας Τύπου" ή κλικ στη γραμμή ομάδας για επεξεργασία.
2. Συμπλήρωση Πληροφοριών

| Πεδίο      | Περιγραφή              | Παράδειγμα   | Υποχρεωτικό |
| ---------- | ---------------------- | ------------ | ----------- |
| **ΟΝΟΜΑ**  | Όνομα της ομάδας τύπου | Luxury Rooms | ✓           |
| **ΕΝΕΡΓΟ** | Ενεργοποίηση           | ΝΑΙ          | -           |

3. Αποθήκευση
   * Κάντε κλικ στο κουμπί "ΔΗΜΙΟΥΡΓΙΑ ΟΜΑΔΑΣ"

### Διαγραφή Ομάδας Τύπων Δωματίων

1. **Άνοιγμα Μενού Ενεργειών**
   * Κάντε κλικ στο κουμπί ενεργειών δίπλα στην ομάδα
2. **Επιλογή Διαγραφής**
   * Επιλέξτε "Διαγραφή" από το μενού
3. **Επιβεβαίωση Διαγραφής**
   * Επιβεβαιώστε τη διαγραφή
