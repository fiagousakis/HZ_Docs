# Τύποι Δωματίων

Η ενότητα **Τύποι Δωματίων (Room Types)** επιτρέπει στους διαχειριστές να ορίζουν και να διαχειρίζονται τις κατηγορίες δωματίων. Κάθε τύπος δωματίου αντιπροσωπεύει μια κατηγορία με συγκεκριμένα χαρακτηριστικά (π.χ. Classic Double, Deluxe, Suite), όπως χωρητικότητα, παροχές και τιμολόγηση. Μπορείτε επίσης να δημιουργείτε και να διαχειρίζεστε τα δωμάτια που ανήκουν σε κάθε τύπο.&#x20;

#### Λίστα Τύπων Δωματίων

| Στήλη                    | Περιγραφή                     | Τύπος          |
| ------------------------ | ----------------------------- | -------------- |
| **ΟΝΟΜΑ**                | Όνομα του τύπου δωματίου      | Text           |
| **ΣΥΝΤΟΜΟ ΟΝΟΜΑ**        | Σύντομη αναφορά (π.χ. CDGV)   | Text           |
| **ROOM TYPE GROUP**      | Ομάδα τύπου δωματίου          | Text           |
| **ΔΙΑΘΕΣΙΜΟΤΗΤΑ**        | Αριθμός διαθέσιμων δωματίων   | Number         |
| **ONLINE ΔΙΑΘΕΣΙΜΟΤΗΤΑ** | Αριθμός διαθέσιμων online     | Number         |
| **ΧΩΡΗΤΙΚΟΤΗΤΑ**         | Μέγιστη χωρητικότητα          | Number         |
| **ΕΝΕΡΓΟ**               | Κατάσταση ενεργοποίησης       | Toggle/Boolean |
| **PUBLIC**               | Δημόσια εμφάνιση              | Toggle/Boolean |
| **EXTERNAL CODE**        | Κωδικός εξωτερικού συστήματος | Text           |
| **ΕΝΕΡΓΕΙΕΣ**            | Κουμπί ενεργειών              | Menu           |

| Στοιχείο                    | Περιγραφή                                 |
| --------------------------- | ----------------------------------------- |
| **TOTAL ROOM TYPES**        | Σύνολο τύπων δωματίων (π.χ. 8)            |
| **Σελίδα**                  | Τρέχουσα σελίδα                           |
| **Αποτελέσματα ανά σελίδα** | Επιλογή αριθμού αποτελεσμάτων (10 / page) |

**Πεδίο Αναζήτησης**

| Στοιχείο              | Περιγραφή                     | Λειτουργία                         |
| --------------------- | ----------------------------- | ---------------------------------- |
| **Πεδίο Αναζήτησης**  | "Αναζήτηση τύπου δωματίου..." | Αναζήτηση τύπων δωματίων ανά όνομα |
| **Κουμπί Αναζήτησης** | Εικονίδιο αναζήτησης          | Εκτέλεση αναζήτησης                |

**Κουμπί Προσθήκης**

| Κουμπί                      | Περιγραφή | Λειτουργία                     |
| --------------------------- | --------- | ------------------------------ |
| **Προσθήκη Τύπου Δωματίου** | Button    | Δημιουργία νέου τύπου δωματίου |

Κάθε γραμμή τύπου δωματίου στον πίνακα έχει ένα κουμπί ενεργειών (τρεις τελείες) που ανοίγει ένα μενού με τις ακόλουθες επιλογές:

| Ενέργεια                 | Περιγραφή                      | Λειτουργία                                                      |
| ------------------------ | ------------------------------ | --------------------------------------------------------------- |
| **Επεξεργασία**          | Ανοίγει τη σελίδα λεπτομερειών | Επεξεργασία όλων των πεδίων του τύπου δωματίου                  |
| **Γρήγορη Επεξεργασία**  | Ανοίγει inline editor          | Γρήγορη τροποποίηση βασικών πεδίων χωρίς να φύγετε από τη λίστα |
| **Add room**             | Δημιουργία νέου δωματίου       | Προσθήκη ενός νέου δωματίου σε αυτό τον τύπο                    |
| **Δημιουργήστε δωμάτια** | Δημιουργία πολλαπλών δωματίων  | Δημιουργία πολλών δωματίων ταυτόχρονα με αυτοματοποίηση         |
| **Διαγραφή**             | Διαγραφή τύπου δωματίου        | Αφαίρεση του τύπου δωματίου από το σύστημα                      |



#### Δημιουργία Νέου Τύπου Δωματίου

<figure><img src="../../../.gitbook/assets/Screenshot 2026-04-08 152552 (1).jpg" alt=""><figcaption></figcaption></figure>

**Βήματα**

1. **Κλικ στο Κουμπί Προσθήκης**

* Κάντε κλικ στο κουμπί "Προσθήκη Τύπου Δωματίου"
* Ανοίγει η σελίδα δημιουργίας νέου τύπου δωματίου

1.  **Συμπλήρωση Βασικών Πληροφοριών**

    | Πεδίο               | Περιγραφή                | Υποχρεωτικό |
    | ------------------- | ------------------------ | ----------- |
    | **ΟΝΟΜΑ**           | Όνομα του τύπου δωματίου | ✓           |
    | **ΣΥΝΤΟΜΟ ΟΝΟΜΑ**   | Σύντομη αναφορά          | ✓           |
    | **ROOM TYPE GROUP** | Ομάδα τύπου δωματίου     | ✓           |
    | **ΠΕΡΙΓΡΑΦΗ**       | Περιγραφή του τύπου      | -           |
2.  **Συμπλήρωση Χωρητικότητας**

    | Πεδίο                   | Περιγραφή                 | Παράδειγμα |
    | ----------------------- | ------------------------- | ---------- |
    | **ΕΛΑΧΙΣΤΑ ΑΤΟΜΑ**      | Ελάχιστος αριθμός ατόμων  | 1          |
    | **ΜΕΓΙΣΤΑ ΑΤΟΜΑ**       | Μέγιστος αριθμός ατόμων   | 2          |
    | **ΜΕΓΙΣΤΟΙ ΕΝΗΛΙΚΕΣ**   | Μέγιστος αριθμός ενηλίκων | 2          |
    | **ΜΕΓΙΣΤΑ ΒΡΕΦΗ**       | Μέγιστος αριθμός βρεφών   | 1          |
    | **ΕΠΙΤΡΕΠΟΝΤΑΙ ΠΑΙΔΙΑ** | Επιτρέπονται παιδιά       | ΝΑΙ        |
3.  **Συμπλήρωση Επιπλέον Πληροφοριών**

    | Πεδίο                     | Περιγραφή                     |
    | ------------------------- | ----------------------------- |
    | **ΔΙΑΤΑΞΗ**               | Διάταξη δωματίου              |
    | **ΜΕΓΕΘΟΣ**               | Μέγεθος δωματίου (τ.μ.)       |
    | **ΣΥΝΥΠΟΛΟΓΙΣΜΟΣ ΒΡΕΦΩΝ** | Συνυπολογισμός βρεφών         |
    | **ΠΡΟΚΑΘΟΡΙΣΜΕΝΟ**        | Προκαθορισμένος τύπος         |
    | **WEBSITE**               | Εμφάνιση στο website          |
    | **IMAGE URL**             | URL εικόνας δωματίου          |
    | **EXTERNAL CODE**         | Κωδικός εξωτερικού συστήματος |
    | **ΧΡΩΜΑ**                 | Χρώμα εμφάνισης               |

Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΤΥΠΟΥ ΔΩΜΑΤΙΟΥ"

#### Επεξεργασία Τύπου Δωματίου

**Βήματα**

1. **Άνοιγμα Τύπου Δωματίου**

* Κάντε κλικ στο όνομα του τύπου δωματίου στη λίστα
* Ανοίγει η σελίδα λεπτομερειών

1. **Τροποποίηση Πληροφοριών**

* Τροποποιήστε τα πεδία που θέλετε
* Π.χ. όνομα, περιγραφή, χωρητικότητα

1. **Αποθήκευση Αλλαγών**

* Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΤΥΠΟΥ ΔΩΜΑΤΙΟΥ"

#### Διαγραφή Τύπου Δωματίου

**Βήματα**

1. **Άνοιγμα Μενού Ενεργειών**

* Κάντε κλικ στο κουμπί ενεργειών (τρεις τελείες) δίπλα στον τύπο δωματίου

1. **Επιλογή Διαγραφής**

* Επιλέξτε "Διαγραφή" από το μενού

1. **Επιβεβαίωση Διαγραφής**

* Επιβεβαιώστε τη διαγραφή στο παράθυρο διαλόγου

#### Γρήγορη Επεξεργασία

**Βήματα**

1. **Άνοιγμα Μενού Ενεργειών**

* Κάντε κλικ στο κουμπί ενεργειών (τρεις τελείες) δίπλα στον τύπο δωματίου

1. **Επιλογή Γρήγορης Επεξεργασίας**

* Επιλέξτε "Γρήγορη Επεξεργασία" από το μενού

1. **Τροποποίηση Πεδίων**

* Τροποποιήστε τα πεδία inline
* Π.χ. όνομα, σύντομο όνομα, κατάσταση

1. **Αποθήκευση**

* Κάντε κλικ στο κουμπί "ΑΠΟΘΗΚΕΥΣΗ"



### Καρτέλα Δωματίων (Rooms Tab)

Όταν ανοίξετε ένα τύπο δωματίου, μπορείτε να δείτε δύο καρτέλες:

* **ΕΠΙΣΚΟΠΙΣΗ** - Βασικές πληροφορίες του τύπου δωματίου
* **ΔΩΜΑΤΙΑ** - Λίστα όλων των δωματίων που ανήκουν σε αυτό τον τύπο

#### Row Action Menu στα Δωμάτια

Κάθε σειρά δωματίου έχει ένα κουμπί ενεργειών που ανοίγει ένα μενού με τις ακόλουθες επιλογές:

| Ενέργεια                | Περιγραφή                      | Λειτουργία                               |
| ----------------------- | ------------------------------ | ---------------------------------------- |
| **Επεξεργασία**         | Ανοίγει τη σελίδα λεπτομερειών | Επεξεργασία όλων των πεδίων του δωματίου |
| **Γρήγορη Επεξεργασία** | Ανοίγει inline editor          | Γρήγορη τροποποίηση βασικών πεδίων       |
| **Διαγραφή**            | Διαγραφή δωματίου              | Αφαίρεση του δωματίου από το σύστημα     |

### F.A.Q. - Συχνές Ερωτήσεις

#### Ερώτηση: Πώς δημιουργώ ένα νέο τύπο δωματίου;

**Απάντηση:**

1. Κάντε κλικ στο κουμπί "Προσθήκη Τύπου Δωματίου"
2. Συμπληρώστε τα απαιτούμενα πεδία
3. Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΤΥΠΟΥ ΔΩΜΑΤΙΟΥ"

#### Ερώτηση: Πώς δημιουργώ δωμάτια για ένα τύπο δωματίου;

**Απάντηση:**

1. Ανοίξτε τον τύπο δωματίου
2. Πλοηγηθείτε στην καρτέλα "ΔΩΜΑΤΙΑ"
3. Κάντε κλικ στο κουμπί "Προσθήκη Δωματίου" ή "Δημιουργήστε δωμάτια"
4. Συμπληρώστε τα απαιτούμενα πεδία
5. Κάντε κλικ στο κουμπί "ΔΗΜΙΟΥΡΓΙΑ ΔΩΜΑΤΙΟΥ"

#### Ερώτηση: Πώς διαγράφω ένα τύπο δωματίου;

**Απάντηση:**

1. Κάντε κλικ στο κουμπί ενεργειών δίπλα στον τύπο δωματίου
2. Επιλέξτε "Διαγραφή"
3. Επιβεβαιώστε τη διαγραφή

#### Ερώτηση: Πώς διαγράφω ένα δωμάτιο;

**Απάντηση:**

1. Ανοίξτε τον τύπο δωματίου
2. Πλοηγηθείτε στην καρτέλα "ΔΩΜΑΤΙΑ"
3. Κάντε κλικ στο κουμπί ενεργειών δίπλα στο δωμάτιο
4. Επιλέξτε "Διαγραφή"
5. Επιβεβαιώστε τη διαγραφή
