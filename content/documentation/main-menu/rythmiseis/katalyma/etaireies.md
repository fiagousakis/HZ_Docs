# Εταιρείες

Η ενότητα **Εταιρείες** αποτελεί το σημείο διαχείρισης των νομικών οντοτήτων που συνδέονται με το κατάλυμα. Οι πληροφορίες που καταχωρούνται εδώ είναι απαραίτητες για την ορθή έκδοση παραστατικών και την τιμολόγηση των πελατών, καθώς διασφαλίζουν ότι όλα τα φορολογικά στοιχεία της επιχείρησης είναι επικαιροποιημένα.

## Λίστα Εταιρειών

Στην κεντρική οθόνη των Εταιρειών εμφανίζεται ένας πίνακας με όλες τις καταχωρημένες οντότητες. Οι στήλες του πίνακα περιλαμβάνουν:

* **ΟΝΟΜΑ:** Η επωνυμία της εταιρείας.
* **ΔΡΑΣΤΗΡΙΟΤΗΤΑ:** Το αντικείμενο εργασιών της επιχείρησης.
* **ΧΩΡΑ:** Η χώρα στην οποία εδρεύει η εταιρεία.
* **ΠΟΛΗ:** Η πόλη της έδρας.
* **ΕΝΕΡΓΟ:** Ένδειξη (ΝΑΙ/ΟΧΙ) για το αν η εταιρεία είναι ενεργή στο σύστημα.

### Βασικές Ενέργειες

* **Αναζήτηση:** Πεδίο αναζήτησης στο πάνω μέρος για γρήγορη εύρεση εταιρείας βάσει ονόματος.
* **Φίλτρα:** Κουμπί φιλτραρίσματος για περιορισμό των αποτελεσμάτων.
* **+Add Property Company:** Κουμπί για τη δημιουργία μιας νέας εταιρείας.

### Μενού Ενεργειών (Action Menu)

Στο δεξί μέρος κάθε γραμμής του πίνακα, το εικονίδιο με τις τρεις τελείες αποκαλύπτει τις διαθέσιμες ενέργειες για τη συγκεκριμένη εταιρεία:

* **Edit property company:** Επιτρέπει την επεξεργασία των στοιχείων της εταιρείας. Επιλέγοντας αυτή την ενέργεια, ο χρήστης μεταφέρεται στη φόρμα επεξεργασίας όπου μπορεί να τροποποιήσει οποιοδήποτε πεδίο.
* **Delete property company:** Χρησιμοποιείται για την οριστική διαγραφή της εταιρείας από το σύστημα. Απαιτείται προσοχή, καθώς η ενέργεια αυτή μπορεί να επηρεάσει συνδεδεμένα παραστατικά ή αναφορές.

## Δημιουργία Νέας Εταιρείας

Πατώντας το κουμπί **+Add Property Company**, μεταφέρεστε στη φόρμα δημιουργίας, η οποία χωρίζεται στις εξής ενότητες:

### 1. Πληροφορίες Εφορίας

Αυτά τα στοιχεία είναι κρίσιμα για τη δημιουργία τιμολογίων:

* **NON VAT:** Διακόπτης (Switch) για εταιρείες που δεν υπόκεινται σε ΦΠΑ.
* **ΑΦΜ:** Ο Αριθμός Φορολογικού Μητρώου της εταιρείας.
* **ΔΟΥ:** Η αρμόδια Δημόσια Οικονομική Υπηρεσία.
* **Υποκατάστημα:** Ο αριθμός ή η ονομασία του υποκαταστήματος.
* **ΦΟΡΟΛΟΓΙΚΟΣ ΚΩΔΙΚΟΣ (ΓΕΜΗ):** Ο αριθμός Γενικού Εμπορικού Μητρώου.

### 2. Basic Details

Βασικά στοιχεία αναγνώρισης της εταιρείας:

* **ΟΝΟΜΑ:** Η επίσημη επωνυμία (υποχρεωτικό πεδίο).
* **Διακριτικός τίτλος:** Η εμπορική ονομασία της εταιρείας.
* **ΔΡΑΣΤΗΡΙΟΤΗΤΑ:** Περιγραφή της δραστηριότητας.
* **ΕΝΕΡΓΟ:** Διακόπτης για την ενεργοποίηση ή απενεργοποίηση της εταιρείας.

### 3. Στοιχεία Επικοινωνίας & Διεύθυνσης

* **ΔΙΕΥΘΥΝΣΗ / Τ.Κ.:** Η οδός, ο αριθμός και ο Ταχυδρομικός Κώδικας.
* **ΧΩΡΑ / ΠΕΡΙΟΧΗ / ΤΟΠΟΘΕΣΙΑ:** Γεωγραφικά στοιχεία της έδρας.
* **WEBSITE / Logo URL:** Ηλεκτρονική διεύθυνση και σύνδεσμος για το λογότυπο της εταιρείας.
* **ΤΗΛΕΦΩΝΟ / ΚΙΝΗΤΟ / EMAIL / FAX:** Στοιχεία για την άμεση επικοινωνία.

### 4. Default Details (Λογιστικές Ρυθμίσεις)

Ρυθμίσεις που αφορούν τη διασύνδεση με λογιστικά συστήματα:

* **ACCOUNTING DEFAULT CUSTOMER CODE:** Προεπιλεγμένος κωδικός πελάτη για το λογιστήριο.
* **CUSTOMER CODE:** Μοναδικός κωδικός πελάτη.
* **ACCOUNTING DEFAULT BUSINESS CODE:** Κωδικοί για εγχώριες, ενδοκοινοτικές ή συναλλαγές εξωτερικού.
* **ACCOUNTING CODE PREFIX / NEXT VALUE / SUFFIX DIGITS:** Ρυθμίσεις για την αυτόματη παραγωγή λογιστικών κωδικών.
* **ACC CODE COUNTER ENABLED:** Ενεργοποίηση του μετρητή κωδικών.

Στο τέλος της φόρμας, το κουμπί **CREATE COMPANY** οριστικοποιεί την καταχώρηση.
