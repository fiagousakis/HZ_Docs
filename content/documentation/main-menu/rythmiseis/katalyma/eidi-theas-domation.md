# Είδη Θέας Δωματίων

Η ενότητα **Είδη Θέας Δωματίων (Room View Types)** επιτρέπει τη δημιουργία και διαχείριση ειδών θέας δωματίων. Τα είδη χρησιμοποιούνται για την κατηγοριοποίηση των δωματίων ανάλογα με τη θέα τους (π.χ. Sea View, City View, Park View).

#### Πεδίο Αναζήτησης

| Στοιχείο              | Περιγραφή                  | Λειτουργία          |
| --------------------- | -------------------------- | ------------------- |
| **Πεδίο Αναζήτησης**  | "Αναζήτηση είδους θέας..." | Αναζήτηση ανά όνομα |
| **Κουμπί Αναζήτησης** | Εικονίδιο αναζήτησης       | Εκτέλεση αναζήτησης |

#### Κουμπί Προσθήκης

| Κουμπί              | Περιγραφή | Λειτουργία                  |
| ------------------- | --------- | --------------------------- |
| **Προσθήκη Είδους** | Button    | Δημιουργία νέου είδους θέας |

#### Λίστα Ειδών Θέας

| Στήλη         | Περιγραφή                        | Τύπος  |
| ------------- | -------------------------------- | ------ |
| **ΟΝΟΜΑ**     | Όνομα του είδους (π.χ. Sea View) | Text   |
| **ΕΝΕΡΓΟ**    | Κατάσταση ενεργοποίησης          | Status |
| **ΕΝΕΡΓΕΙΕΣ** | Κουμπί ενεργειών                 | Menu   |

Κάθε σειρά στον πίνακα έχει ένα κουμπί ενεργειών που ανοίγει ένα μενού με τις ακόλουθες επιλογές:

* **Γρήγορη Επεξεργασία** - Ανοίγει inline editor
* **Επεξεργασία** - Ανοίγει τη σελίδα λεπτομερειών
* **Διαγραφή** - Αφαίρεση του είδους

### Δημιουργία / Επεξεργασία Νέου Είδους Θέας

#### Βήματα

1. Κάντε κλικ στο κουμπί "Προσθήκη θέας" ή στη γραμμή θέας για επεξεργασία.
2. Συμπλήρωση Πληροφοριών

| Πεδίο      | Περιγραφή        | Παράδειγμα  | Υποχρεωτικό |
| ---------- | ---------------- | ----------- | ----------- |
| **ΟΝΟΜΑ**  | Όνομα του είδους | Sunset View | ✓           |
| **ΕΝΕΡΓΟ** | Ενεργοποίηση     | ΝΑΙ         | -           |

3. Αποθήκευση
   * Κάντε κλικ στο κουμπί "ΔΗΜΙΟΥΡΓΙΑ"  ή "ΕΝΗΜΕΡΩΣΗ".
