# Seasons

Κάθε **Περίοδος Λειτουργίας (Season)** αντιπροσωπεύει μια χρονική περίοδο (π.χ. Season 2027) με συγκεκριμένες ημερομηνίες έναρξης και λήξης, και κατάσταση (OPEN/CLOSED). Οι περίοδοι χρησιμοποιούνται για τη διαχείριση της διαθεσιμότητας και των τιμών και to εύκολο φιλτράρισμα σε πολλά σημεία και λειτουργίες.

#### Πεδίο Αναζήτησης

| Στοιχείο              | Περιγραφή                           | Λειτουργία                   |
| --------------------- | ----------------------------------- | ---------------------------- |
| **Πεδίο Αναζήτησης**  | "Αναζήτηση για περίοδο λειτουργίας" | Αναζήτηση περιόδων ανά όνομα |
| **Κουμπί Αναζήτησης** | Εικονίδιο αναζήτησης                | Εκτέλεση αναζήτησης          |

#### Κουμπί Προσθήκης

| Κουμπί                            | Περιγραφή | Λειτουργία                           |
| --------------------------------- | --------- | ------------------------------------ |
| **Προσθήκη περιόδου λειτουργίας** | Button    | Δημιουργία νέας περιόδου λειτουργίας |

#### Λίστα Περιόδων Λειτουργίας

| Στήλη         | Περιγραφή                             | Τύπος  |
| ------------- | ------------------------------------- | ------ |
| **ΟΝΟΜΑ**     | Όνομα της περιόδου (π.χ. Season 2027) | Text   |
| **ΕΝΑΡΞΗ**    | Ημερομηνία έναρξης της περιόδου       | Date   |
| **ΛΗΞΗ**      | Ημερομηνία λήξης της περιόδου         | Date   |
| **ΚΑΤΑΣΤΑΣΗ** | Κατάσταση της περιόδου (OPEN/CLOSED)  | Status |
| **ΕΝΕΡΓΕΙΕΣ** | Κουμπί ενεργειών                      | Menu   |

Κάθε σειρά στον πίνακα έχει ένα κουμπί ενεργειών (τρεις τελείες) που ανοίγει ένα μενού με τις ακόλουθες επιλογές:

* **Γρήγορη Επεξεργασία** - Ανοίγει inline editor για γρήγορη τροποποίηση βασικών πεδίων χωρίς να φύγετε από τη λίστα
* **Κλείσιμο περιόδου** - Κλείνει την περίοδο λειτουργίας (αλλάζει κατάσταση σε CLOSED)
* **Αποστολή διαθεσιμότητας** - Αποστέλλει τα δεδομένα διαθεσιμότητας σε εξωτερικά συστήματα
* **Διαγραφή** - Αφαίρεση της περιόδου λειτουργίας από το σύστημα

### Δημιουργία / Επεξεργασία Περιόδου Λειτουργίας

<figure><img src="../../../.gitbook/assets/Screenshot 2026-07-08 140604.jpg" alt=""><figcaption></figcaption></figure>

1. Κάντε κλικ στο κουμπί "Προσθήκη περιόδου λειτουργίας"
2. Συμπλήρωση Πληροφοριών

| Πεδίο         | Περιγραφή               | Παράδειγμα  | Υποχρεωτικό |
| ------------- | ----------------------- | ----------- | ----------- |
| **ΟΝΟΜΑ**     | Όνομα της περιόδου      | Season 2028 | ✓           |
| **ΕΝΑΡΞΗ**    | Ημερομηνία έναρξης      | 01/01/2028  | ✓           |
| **ΛΗΞΗ**      | Ημερομηνία λήξης        | 31/12/2028  | ✓           |
| **ΚΑΤΑΣΤΑΣΗ** | Κατάσταση (OPEN/CLOSED) | OPEN        | ✓           |

3. Κάντε κλικ στο κουμπί "ΔΗΜΙΟΥΡΓΙΑ ΠΕΡΙΟΔΟΥ" ή "ΕΝΗΜΕΡΩΣΗ"

### Διαγραφή Περιόδου Λειτουργίας

#### Βήματα

1. **Άνοιγμα Μενού Ενεργειών**
   * Κάντε κλικ στο κουμπί ενεργειών (τρεις τελείες) δίπλα στην περίοδο
2. **Επιλογή Διαγραφής**
   * Επιλέξτε "Διαγραφή" από το μενού
3. **Επιβεβαίωση Διαγραφής**
   * Επιβεβαιώστε τη διαγραφή στο παράθυρο διαλόγου

### Γρήγορη Επεξεργασία

#### Βήματα

1. **Άνοιγμα Μενού Ενεργειών**
   * Κάντε κλικ στο κουμπί ενεργειών (τρεις τελείες) δίπλα στην περίοδο
2. **Επιλογή Γρήγορης Επεξεργασίας**
   * Επιλέξτε "Γρήγορη Επεξεργασία" από το μενού
3. **Τροποποίηση Πεδίων**
   * Τροποποιήστε τα πεδία inline
   * Π.χ. όνομα, ημερομηνίες
4. **Αποθήκευση**
   * Κάντε κλικ στο κουμπί "ΑΠΟΘΗΚΕΥΣΗ"

### Κλείσιμο Περιόδου Λειτουργίας

#### Βήματα

1. **Άνοιγμα Μενού Ενεργειών**
   * Κάντε κλικ στο κουμπί ενεργειών (τρεις τελείες) δίπλα στην περίοδο
2. **Επιλογή Κλεισίματος**
   * Επιλέξτε "Κλείσιμο περιόδου" από το μενού
3. **Επιβεβαίωση**
   * Επιβεβαιώστε το κλείσιμο
   * Η κατάσταση αλλάζει σε CLOSED

### Αποστολή Διαθεσιμότητας

#### Βήματα

1. **Άνοιγμα Μενού Ενεργειών**
   * Κάντε κλικ στο κουμπί ενεργειών (τρεις τελείες) δίπλα στην περίοδο
2. **Επιλογή Αποστολής**
   * Επιλέξτε "Αποστολή διαθεσιμότητας" από το μενού
3. **Επιβεβαίωση**
   * Επιβεβαιώστε την αποστολή
   * Τα δεδομένα αποστέλλονται σε εξωτερικά συστήματα





## F.A.Q.

### Ερώτηση: Τι είναι μια περίοδος λειτουργίας;

**Απάντηση:** Μια περίοδος λειτουργίας είναι μια χρονική περίοδος που ορίζει τη διαθεσιμότητα και τις τιμές του ξενοδοχείου. Π.χ. Season 2027 από 01/01/2027 έως 31/12/2027.

### Ερώτηση: Πώς δημιουργώ μια νέα περίοδο λειτουργίας;

**Απάντηση:**

1. Κάντε κλικ στο κουμπί "Προσθήκη περιόδου λειτουργίας"
2. Συμπληρώστε τα απαιτούμενα πεδία
3. Κάντε κλικ στο κουμπί "ΔΗΜΙΟΥΡΓΙΑ ΠΕΡΙΟΔΟΥ"

### Ερώτηση: Ποια είναι η διαφορά μεταξύ OPEN και CLOSED;

**Απάντηση:** OPEN σημαίνει ότι η περίοδος είναι ανοιχτή για κρατήσεις, ενώ CLOSED σημαίνει ότι η περίοδος είναι κλειστή και δεν δέχεται νέες κρατήσεις.

### Ερώτηση: Πώς κλείνω μια περίοδο λειτουργίας;

**Απάντηση:**

1. Κάντε κλικ στο κουμπί ενεργειών δίπλα στην περίοδο
2. Επιλέξτε "Κλείσιμο περιόδου"
3. Επιβεβαιώστε το κλείσιμο

### Ερώτηση: Πώς αποστέλλω τη διαθεσιμότητα σε εξωτερικά συστήματα;

**Απάντηση:**

1. Κάντε κλικ στο κουμπί ενεργειών δίπλα στην περίοδο
2. Επιλέξτε "Αποστολή διαθεσιμότητας"
3. Επιβεβαιώστε την αποστολή
