# Preferences

Η ενότητα **Προτιμήσεις (Preferences)** επιτρέπει τη δημιουργία και διαχείριση προτιμήσεων πελατών που εμφανίζονται σε διάφορα σημεία του συστήματος (Online Check-in, Housekeeping, Meal Plans, Emails). Οι προτιμήσεις χρησιμοποιούνται για την συλλογή και αποθήκευση πληροφοριών πελατών (π.χ. τύπος κρεβατιού, θέση δωματίου, ειδικές απαιτήσεις).

Κάθε σειρά στον πίνακα έχει ένα κουμπί ενεργειών που ανοίγει ένα μενού με τις ακόλουθες επιλογές:

* **Γρήγορη Επεξεργασία** - Ανοίγει inline editor για γρήγορη τροποποίηση βασικών πεδίων
* **Επεξεργασία** - Ανοίγει τη σελίδα λεπτομερειών για πλήρη επεξεργασία
* **Διαγραφή** - Αφαίρεση της προτίμησης από το σύστημα

| Τύπος               | Περιγραφή                               |

### Δημιουργία Νέας Προτίμησης

1. **Κλικ στο Κουμπί Προσθήκης**

* Κάντε κλικ στο κουμπί "Add Preference"
* Ανοίγει ένα modal με τη φόρμα δημιουργίας

1. **Επιλογή Τύπου Πεδίου**

* Κάντε κλικ στο dropdown "FIELD TYPE"
* Επιλέξτε τον κατάλληλο τύπο (TEXT, RADIO, SELECT, κ.λπ.)

1. **Συμπλήρωση Βασικών Λεπτομερειών**

| Πεδίο             | Παράδειγμα                            | Υποχρεωτικό |
| ----------------- | ------------------------------------- | ----------- |
| **ΟΝΟΜΑ**         | Bed Type selection                    | ✓           |
| **ΣΥΝΤΟΜΟ ΟΝΟΜΑ** | bed\_type                             | -           |
| **ΠΕΡΙΓΡΑΦΗ**     | Please select the bed type you prefer | -           |

1. **Ρύθμιση Επιλογών Εμφάνισης**

* Ενεργοποιήστε τα toggle για τις θέσεις όπου θέλετε να εμφανίζεται
* Π.χ. DISPLAY AT MEAL PLANS = ΝΑΙ

1. **Ρύθμιση Πρόσθετων Ρυθμίσεων**

* Εισάγετε τη σειρά εμφάνισης (ΔΙΑΤΑΞΗ)
* Εισάγετε εξωτερικό κωδικό αν χρειάζεται (EXTERNAL CODE)

1. **Αποθήκευση**

* Κάντε κλικ στο κουμπί "CREATE PREFERENCE"

#### Επεξεργασία Προτίμησης

**Βήματα**

1. **Άνοιγμα Προτίμησης**

* Κάντε κλικ στο όνομα της προτίμησης ή επιλέξτε "Επεξεργασία" από το μενού ενεργειών
* Ανοίγει η σελίδα λεπτομερειών

1. **Τροποποίηση Πληροφοριών**

* Τροποποιήστε τα πεδία που θέλετε
* Προσθέστε ή αφαιρέστε επιλογές (αν είναι RADIO/SELECT/CHECKBOXES)

1. **Αποθήκευση Αλλαγών**

* Κάντε κλικ στο κουμπί "UPDATE PREFERENCE" ή "SAVE"

#### Διαγραφή Προτίμησης

**Βήματα**

1. **Άνοιγμα Μενού Ενεργειών**

* Κάντε κλικ στο κουμπί ενεργειών δίπλα στην προτίμηση

1. **Επιλογή Διαγραφής**

* Επιλέξτε "Διαγραφή" από το μενού

1. **Επιβεβαίωση Διαγραφής**

* Επιβεβαιώστε τη διαγραφή στο παράθυρο διαλόγου

Οι προτιμήσεις μπορούν να εμφανίζονται σε:

* **Online Check-in** - Κατά τη διαδικασία online check-in του πελάτη
* **Housekeeping** - Για το τμήμα καθαριότητας
* **Meal Plans** - Για το τμήμα διατροφής
* **Emails** - Σε ηλεκτρονικά μηνύματα προς τον πελάτη



### F.A.Q. - Συχνές Ερωτήσεις

#### Ερώτηση: Τι είναι μια προτίμηση;

**Απάντηση:** Μια προτίμηση είναι ένα πεδίο που συλλέγει πληροφορίες από τους πελάτες (π.χ. τύπος κρεβατιού, business or plesure, κτλ.) και μπορεί να εμφανίζεται σε διάφορα σημεία του συστήματος.

#### Ερώτηση: Πώς δημιουργώ μια νέα προτίμηση;

**Απάντηση:**

1. Κάντε κλικ στο κουμπί "Add Preference"
2. Επιλέξτε τον τύπο πεδίου
3. Συμπληρώστε τα απαιτούμενα πεδία
4. Κάντε κλικ στο κουμπί "CREATE PREFERENCE"

#### Ερώτηση: Πώς κάνω μια προτίμηση υποχρεωτική;

**Απάντηση:**

1. Ανοίξτε την προτίμηση για επεξεργασία
2. Ενεργοποιήστε το toggle "IS REQUIRED"
3. Κάντε κλικ στο κουμπί "SAVE"

#### Ερώτηση: Πώς εμφανίζω μια προτίμηση μόνο στο Online Check-in;

**Απάντηση:**

1. Ανοίξτε την προτίμηση για επεξεργασία
2. Ενεργοποιήστε το toggle "DISPLAY AT ONLINE CHECKIN"
3. Απενεργοποιήστε τα άλλα toggles (HOUSEKEEPING, MEAL PLANS, EMAILS)
4. Κάντε κλικ στο κουμπί "SAVE"
