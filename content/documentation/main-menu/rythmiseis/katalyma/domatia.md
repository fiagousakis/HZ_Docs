# Δωμάτια

Η ενότητα **Δωμάτια (Rooms)** επιτρέπει τη διαχείριση όλων των ατομικών δωματίων του ξενοδοχείου. Κάθε δωμάτιο αντιπροσωπεύει ένα φυσικό δωμάτιο με συγκεκριμένα χαρακτηριστικά, κατάσταση και σχέσεις με τύπους δωματίων και ομάδες. Από εδώ μπορείτε να δημιουργήσετε, να επεξεργαστείτε και να διαχειριστείτε τα δωμάτια του ξενοδοχείου.

#### Πληροφορίες Σελιδοποίησης

| Στοιχείο                    | Περιγραφή                                 |
| --------------------------- | ----------------------------------------- |
| **TOTAL ROOMS**             | Σύνολο δωματίων (π.χ. 55)                 |
| **Σελίδα**                  | Τρέχουσα σελίδα                           |
| **Αποτελέσματα ανά σελίδα** | Επιλογή αριθμού αποτελεσμάτων (10 / page) |

Κάθε σειρά στον πίνακα έχει ένα κουμπί ενεργειών (τρεις τελείες) που ανοίγει ένα μενού με τις ακόλουθες επιλογές:

* **Επεξεργασία** - Ανοίγει τη σελίδα λεπτομερειών για επεξεργασία όλων των πεδίων του δωματίου
* **Γρήγορη Επεξεργασία** - Ανοίγει inline editor για γρήγορη τροποποίηση βασικών πεδίων χωρίς να φύγετε από τη λίστα
* **Διαγραφή** - Αφαίρεση του δωματίου από το σύστημα

### Επεξεργασία Δωματίου

1. **Άνοιγμα Δωματίου**
   * Κάντε κλικ στο όνομα του δωματίου στη λίστα
   * Ανοίγει η σελίδα λεπτομερειών
2. **Τροποποίηση Πληροφοριών**
   * Τροποποιήστε τα πεδία που θέλετε
   * Π.χ. όνομα, κατάσταση, χρώμα
3. **Αποθήκευση Αλλαγών**
   * Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΔΩΜΑΤΙΟΥ"

### Διαγραφή Δωματίου

1. **Άνοιγμα Μενού Ενεργειών**
   * Κάντε κλικ στο κουμπί ενεργειών (τρεις τελείες) δίπλα στο δωμάτιο
2. **Επιλογή Διαγραφής**
   * Επιλέξτε "Διαγραφή" από το μενού
3. **Επιβεβαίωση Διαγραφής**
   * Επιβεβαιώστε τη διαγραφή στο παράθυρο διαλόγου

### Γρήγορη Επεξεργασία

1. **Άνοιγμα Μενού Ενεργειών**
   * Κάντε κλικ στο κουμπί ενεργειών (τρεις τελείες) δίπλα στο δωμάτιο
2. **Επιλογή Γρήγορης Επεξεργασίας**
   * Επιλέξτε "Γρήγορη Επεξεργασία" από το μενού
3. **Τροποποίηση Πεδίων**
   * Τροποποιήστε τα πεδία inline
   * Π.χ. όνομα, κατάσταση, ενεργό
4. **Αποθήκευση**
   * Κάντε κλικ στο κουμπί "ΑΠΟΘΗΚΕΥΣΗ"



### F.A.Q. - Συχνές Ερωτήσεις

#### Ερώτηση: Πώς δημιουργώ ένα νέο δωμάτιο;

**Απάντηση:**

1. Κάντε κλικ στο κουμπί "Προσθήκη Δωματίου"
2. Συμπληρώστε τα απαιτούμενα πεδία
3. Κάντε κλικ στο κουμπί "ΔΗΜΙΟΥΡΓΙΑ ΔΩΜΑΤΙΟΥ"

#### Ερώτηση: Πώς επεξεργάζομαι ένα δωμάτιο;

**Απάντηση:**

1. Κάντε κλικ στο δωμάτιο που θέλετε να επεξεργαστείτε
2. Τροποποιήστε τα πεδία
3. Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΔΩΜΑΤΙΟΥ"

#### Ερώτηση: Πώς διαγράφω ένα δωμάτιο;

**Απάντηση:**

1. Κάντε κλικ στο κουμπί ενεργειών δίπλα στο δωμάτιο
2. Επιλέξτε "Διαγραφή"
3. Επιβεβαιώστε τη διαγραφή

#### Ερώτηση: Τι είναι ένα εικονικό δωμάτιο;

**Απάντηση:** Ένα εικονικό δωμάτιο είναι ένα δωμάτιο που δεν υπάρχει φυσικά αλλά δημιουργείται στο σύστημα για λόγους διαχείρισης (π.χ. δωμάτια που δημιουργούνται δυναμικά από τη σύνδεση άλλων δωματίων).

#### Ερώτηση: Πώς αναζητώ ένα δωμάτιο;

**Απάντηση:**

1. Πληκτρολογήστε τον αριθμό ή το όνομα του δωματίου στο πεδίο αναζήτησης
2. Η αναζήτηση εκτελείται αυτόματα

## Ροή Εργασιών

### Σενάριο: Δημιουργία Νέου Δωματίου

1. **Πλοήγηση στη Σελίδα**
   * Κάντε κλικ στο "Δωμάτια" από το μενού Ρυθμίσεων
2. **Δημιουργία Δωματίου**
   * Κάντε κλικ στο κουμπί "Προσθήκη Δωματίου"
   * Όνομα: "201"
   * Τύπος Δωματίου: "Deluxe Room"
   * Κατάσταση: "Clean"
   * Ενεργό: "ΝΑΙ"
   * Κάντε κλικ στο κουμπί "ΔΗΜΙΟΥΡΓΙΑ ΔΩΜΑΤΙΟΥ"
3. **Επαλήθευση**
   * Ελέγξτε ότι το δωμάτιο 201 εμφανίζεται στη λίστα
   * Ελέγξτε ότι η κατάσταση είναι "Clean"
