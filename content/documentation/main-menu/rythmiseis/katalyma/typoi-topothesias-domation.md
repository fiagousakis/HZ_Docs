# Τύποι Τοποθεσίας Δωματίων

Η ενότητα **Τύποι Τοποθεσίας Δωματίων (Room Location Types)** επιτρέπει τη δημιουργία και διαχείριση τύπων τοποθεσίας δωματίων. Οι τύποι χρησιμοποιούνται για την κατηγοριοποίηση των δωματίων ανάλογα με τη θέση τους (π.χ. Garden View, Sea View, City View).

#### Πεδίο Αναζήτησης

| Στοιχείο              | Περιγραφή                       | Λειτουργία          |
| --------------------- | ------------------------------- | ------------------- |
| **Πεδίο Αναζήτησης**  | "Αναζήτηση τύπου τοποθεσίας..." | Αναζήτηση ανά όνομα |
| **Κουμπί Αναζήτησης** | Εικονίδιο αναζήτησης            | Εκτέλεση αναζήτησης |

#### Κουμπί Προσθήκης

| Κουμπί             | Περιγραφή | Λειτουργία            |
| ------------------ | --------- | --------------------- |
| **Προσθήκη Τύπου** | Button    | Δημιουργία νέου τύπου |

#### Πίνακας Τύπων Τοποθεσίας

**Στήλες Πίνακα**

| Στήλη     | Περιγραφή                          | Τύπος |
| --------- | ---------------------------------- | ----- |
| **ΟΝΟΜΑ** | Όνομα του τύπου (π.χ. Garden View) | Text  |

Κάθε σειρά στον πίνακα έχει ένα κουμπί ενεργειών που ανοίγει ένα μενού με τις ακόλουθες επιλογές:

* **Επεξεργασία** - Ανοίγει τη σελίδα λεπτομερειών
* **Διαγραφή** - Αφαίρεση του τύπου

### Δημιουργία Νέου Τύπου Τοποθεσίας

1. Κάντε κλικ στο κουμπί "Προσθήκη Τύπου"
2. Συμπλήρωση Πληροφοριών

| Πεδίο     | Περιγραφή       | Παράδειγμα    | Υποχρεωτικό |
| --------- | --------------- | ------------- | ----------- |
| **ΟΝΟΜΑ** | Όνομα του τύπου | Mountain View | ✓           |

3. Κάντε κλικ στο κουμπί "ΔΗΜΙΟΥΡΓΙΑ"
