# Όροφοι Δωματίων

Η ενότητα **Όροφοι Δωματίων (Room Floors)** επιτρέπει τη δημιουργία και διαχείριση των ορόφων του ξενοδοχείου. Κάθε όροφος αντιπροσωπεύει ένα φυσικό επίπεδο του κτιρίου (π.χ. Floor 1, Floor 2) και χρησιμοποιείται για την οργάνωση των δωματίων.

<figure><img src="../../../.gitbook/assets/Screenshot 2026-07-08 140952.jpg" alt=""><figcaption></figcaption></figure>

#### Πεδίο Αναζήτησης

| Στοιχείο              | Περιγραφή             | Λειτουργία                 |
| --------------------- | --------------------- | -------------------------- |
| **Πεδίο Αναζήτησης**  | "Αναζήτηση ορόφου..." | Αναζήτηση ορόφων ανά όνομα |
| **Κουμπί Αναζήτησης** | Εικονίδιο αναζήτησης  | Εκτέλεση αναζήτησης        |

#### Κουμπί Προσθήκης

| Κουμπί              | Περιγραφή | Λειτουργία             |
| ------------------- | --------- | ---------------------- |
| **Προσθήκη Ορόφου** | Button    | Δημιουργία νέου ορόφου |

#### Λίστα Ορόφων

| Στήλη         | Περιγραφή                       | Τύπος  |
| ------------- | ------------------------------- | ------ |
| **ΟΝΟΜΑ**     | Όνομα του ορόφου (π.χ. Floor 1) | Text   |
| **ΕΝΕΡΓΟ**    | Κατάσταση ενεργοποίησης         | Status |
| **ΕΝΕΡΓΕΙΕΣ** | Κουμπί ενεργειών                | Menu   |

Κάθε σειρά στον πίνακα έχει ένα κουμπί ενεργειών που ανοίγει ένα μενού με τις ακόλουθες επιλογές:

* **Γρήγορη Επεξεργασία** - Ανοίγει inline editor για γρήγορη τροποποίηση
* **Επεξεργασία** - Ανοίγει τη σελίδα λεπτομερειών
* **Διαγραφή** - Αφαίρεση του ορόφου

### Δημιουργία / Επεξεργασία Νέου Ορόφου

<figure><img src="../../../.gitbook/assets/Screenshot 2026-07-08 141005.jpg" alt=""><figcaption></figcaption></figure>

1. Κάντε κλικ στο κουμπί "Προσθήκη Ορόφου" ή κλικ στη γραμμή του ορόφου για επεξεργασία.
2. Συμπλήρωση Πληροφοριών

| Πεδίο      | Περιγραφή        | Παράδειγμα | Υποχρεωτικό |
| ---------- | ---------------- | ---------- | ----------- |
| **ΟΝΟΜΑ**  | Όνομα του ορόφου | Floor 3    | ✓           |
| **ΕΝΕΡΓΟ** | Ενεργοποίηση     | ΝΑΙ        | -           |

3. Κάντε κλικ στο κουμπί "ΔΗΜΙΟΥΡΓΙΑ ΟΡΌΦΟΥ" ή "ΕΝΗΜΕΡΩΣΗ".

### Διαγραφή Ορόφου

1. **Άνοιγμα Μενού Ενεργειών**
   * Κάντε κλικ στο κουμπί ενεργειών
2. **Επιλογή Διαγραφής**
   * Επιλέξτε "Διαγραφή"
3. **Επιβεβαίωση**
   * Επιβεβαιώστε τη διαγραφή
