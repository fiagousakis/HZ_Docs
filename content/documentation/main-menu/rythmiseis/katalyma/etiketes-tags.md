# Ετικέτες (Tags)

Η ενότητα **Ετικέτες (Tags)** επιτρέπει τη δημιουργία και διαχείριση ετικετών που χρησιμοποιούνται για την κατηγοριοποίηση και οργάνωση διαφόρων στοιχείων του συστήματος (π.χ. δωμάτια, πελάτες, κρατήσεις). Οι ετικέτες βοηθούν στην οπτική αναγώριση, στη γρήγορη αναζήτηση και στο φιλτράρισμα.

<figure><img src="../../../.gitbook/assets/Screenshot 2026-07-08 141440.jpg" alt=""><figcaption></figcaption></figure>

#### Πεδίο Αναζήτησης

| Στοιχείο              | Περιγραφή               | Λειτουργία          |
| --------------------- | ----------------------- | ------------------- |
| **Πεδίο Αναζήτησης**  | "Αναζήτηση ετικέτας..." | Αναζήτηση ανά όνομα |
| **Κουμπί Αναζήτησης** | Εικονίδιο αναζήτησης    | Εκτέλεση αναζήτησης |

#### Κουμπί Προσθήκης

| Κουμπί                | Περιγραφή | Λειτουργία               |
| --------------------- | --------- | ------------------------ |
| **Προσθήκη Ετικέτας** | Button    | Δημιουργία νέας ετικέτας |

#### Λίστα Ετικετών

| Στήλη         | Περιγραφή                     | Τύπος  |
| ------------- | ----------------------------- | ------ |
| **ΟΝΟΜΑ**     | Όνομα της ετικέτας (π.χ. VIP) | Text   |
| **ΧΡΩΜΑ**     | Χρώμα της ετικέτας            | Color  |
| **ΕΝΕΡΓΟ**    | Κατάσταση ενεργοποίησης       | Status |
| **ΕΝΕΡΓΕΙΕΣ** | Κουμπί ενεργειών              | Menu   |

Κάθε σειρά στον πίνακα έχει ένα κουμπί ενεργειών που ανοίγει ένα μενού με τις ακόλουθες επιλογές:

* **Γρήγορη Επεξεργασία** - Ανοίγει inline editor
* **Επεξεργασία** - Ανοίγει τη σελίδα λεπτομερειών
* **Διαγραφή** - Αφαίρεση της ετικέτας



### Δημιουργία / Επεξεργασία Νέας Ετικέτας

<figure><img src="../../../.gitbook/assets/Screenshot 2026-07-08 141455.jpg" alt=""><figcaption></figcaption></figure>

1. Κάντε κλικ στο κουμπί "Προσθήκη Ετικέτας" ή κλικ στη γραμμή ετικέτας για επεξεργασία.
2. Συμπλήρωση Πληροφοριών

| Πεδίο      | Περιγραφή          | Παράδειγμα    | Υποχρεωτικό |
| ---------- | ------------------ | ------------- | ----------- |
| **ΟΝΟΜΑ**  | Όνομα της ετικέτας | Premium Guest | ✓           |
| **ΧΡΩΜΑ**  | Χρώμα της ετικέτας | Χρυσό         | -           |
| **ΕΝΕΡΓΟ** | Ενεργοποίηση       | ΝΑΙ           | -           |

3. Αποθήκευση
   * Κάντε κλικ στο κουμπί "ΔΗΜΙΟΥΡΓΙΑ" ή "ΕΝΗΜΕΡΩΣΗ".

### Διαγραφή Ετικέτας

1. **Άνοιγμα Μενού Ενεργειών**
   * Κάντε κλικ στο κουμπί ενεργειών
2. **Επιλογή Διαγραφής**
   * Επιλέξτε "Διαγραφή"
3. **Επιβεβαίωση**
   * Επιβεβαιώστε τη διαγραφή
