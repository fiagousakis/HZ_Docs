# Χρήστες

Η ενότητα **Χρήστες** (Users) σας επιτρέπει να δημιουργήσετε και να διαχειριστείτε τους λογαριασμούς των χρηστών που έχουν πρόσβαση στο σύστημα Hotelizer. Κάθε χρήστης έχει τα δικά του στοιχεία σύνδεσης, γλώσσα προτίμησης, και δικαιώματα πρόσβασης. Μπορείτε να ελέγχετε τις δραστηριότητες του κάθε χρήστη και να ορίσετε περιορισμούς πρόσβασης.

#### Κουμπιά Ενεργειών

* **Filter:** Κουμπί φιλτραρίσματος
* **Προσθήκη Χρήστη:** Δημιουργία νέου χρήστη

### Λίστα Χρηστών

| Στήλη                 | Περιγραφή                              | Τύπος Δεδομένων |
| --------------------- | -------------------------------------- | --------------- |
| **ΟΝΟΜΑ**             | Το όνομα του χρήστη (συντομογραφία)    | Text            |
| **EMAIL**             | Η διεύθυνση email του χρήστη           | Email           |
| **ΓΛΩΣΣΑ**            | Η γλώσσα προτίμησης του χρήστη         | Text            |
| **ΟΜΑΔΑ ΧΡΗΣΤΩΝ**     | Η ομάδα δικαιωμάτων του χρήστη         | Text            |
| **ΤΕΛΕΥΤΑΙΑ ΣΥΝΔΕΣΗ** | Ημερομηνία και ώρα τελευταίας σύνδεσης | DateTime        |
| **Action Menu**       | Ενέργειες (Edit/Delete)                | Dropdown        |

#### Action Menu (Τρεις Τελείες)

Κάθε γραμμή στον πίνακα διαθέτει ένα action menu που περιέχει:

* **Επεξεργασία:** Ανοίγει τη φόρμα επεξεργασίας του χρήστη
* **Διαγραφή:** Διαγράφει τον χρήστη (με επιβεβαίωση)

### Δημιουργία/Επεξεργασία Χρήστη

Η φόρμα επεξεργασίας χρήστη περιέχει τις ακόλουθες ενότητες:

1. **Βασικές Πληροφορίες (Basic Information)**
2. **Επιλογές και Δικαιώματα (Permissions and Rights)**
3. **Αλλαγή Κωδικού (Password Change)**

#### Βασικές Πληροφορίες

| Πεδίο                      | Περιγραφή                         | Τύπος          | Υποχρεωτικό              | Παράδειγμα                               |
| -------------------------- | --------------------------------- | -------------- | ------------------------ | ---------------------------------------- |
| **ΟΝΟΜΑΤΕΠΩΝΥΜΟ**          | Το πλήρες όνομα του χρήστη        | Text Input     | **ΝΑΙ**                  | "Alex Fiag", "Maria Papadopoulou"        |
| **EMAIL**                  | Η διεύθυνση email του χρήστη      | Email Input    | **ΝΑΙ**                  | "afiag@managinng.com", "maria@hotel.com" |

| **ΕΠΑΝΑΛΗΨΗ ΝΕΟΥ ΚΩΔΙΚΟΥ** | Επανάληψη κωδικού για επιβεβαίωση | Password Input | **ΝΑΙ** (για νέο χρήστη) | -                                        |

#### Επιλογές και Δικαιώματα

| Πεδίο              | Περιγραφή                             | Τύπος         | Υποχρεωτικό | Παράδειγμα                                 |
| ------------------ | ------------------------------------- | ------------- | ----------- | ------------------------------------------ |
| **ΔΙΚΑΙΩΜΑΤΑ**     | Ομάδα δικαιωμάτων του χρήστη          | Dropdown      | Όχι         | "Property Owner", "Demo account", "Custom" |
| **ΕΝΕΡΓΟ**         | Κατάσταση ενεργοποίησης του χρήστη    | Toggle Switch | Όχι         | ΝΑΙ / ΟΧΙ                                  |
| **ΜΠΛΟΚΑΡΙΣΜΕΝΟΣ** | Κατάσταση αποκλεισμού του χρήστη      | Toggle Switch | Όχι         | ΝΑΙ / ΟΧΙ                                  |
| **ALLOWED IPS**    | Λίστα IP διευθύνσεων που επιτρέπονται | Text Input    | Όχι         | "192.168.1.1", "10.0.0.0/8"                |

#### Αλλαγή Κωδικού (Μόνο για Επεξεργασία)

Αυτή η ενότητα εμφανίζεται μόνο κατά την επεξεργασία υπάρχοντος χρήστη.

| Πεδίο                      | Περιγραφή                | Τύπος          | Υποχρεωτικό | Παράδειγμα |
| -------------------------- | ------------------------ | -------------- | ----------- | ---------- |
| **ΝΕΟΣ ΚΩΔΙΚΟΣ**           | Ο νέος κωδικός πρόσβασης | Password Input | Όχι         | -          |
| **ΕΠΑΝΑΛΗΨΗ ΝΕΟΥ ΚΩΔΙΚΟΥ** | Επανάληψη νέου κωδικού   | Password Input | Όχι         | -          |

### Κουμπιά Ενεργειών

* **ΔΗΜΙΟΥΡΓΙΑ ΧΡΗΣΤΗ:** Δημιουργία νέου χρήστη (εμφανίζεται μόνο σε νέα εγγραφή)
* **ΕΝΗΜΕΡΩΣΗ ΧΡΗΣΤΗ:** Αποθήκευση αλλαγών σε υπάρχον χρήστη (εμφανίζεται μόνο σε επεξεργασία)
* **ΚΛΕΙΣΙΜΟ:** Ακύρωση αλλαγών και επιστροφή στη λίστα

### Λειτουργίες & Ενέργειες

#### Αναζήτηση Χρήστη

1. Πληκτρολογήστε το όνομα ή το email του χρήστη στο πεδίο αναζήτησης
2. Το σύστημα φιλτράρει αυτόματα τα αποτελέσματα

#### Φιλτράρισμα Χρηστών

1. Κάντε κλικ στο κουμπί "Filter"
2. Επιλέξτε τα κριτήρια φιλτραρίσματος (π.χ. Ενεργοί χρήστες, Ομάδα δικαιωμάτων)
3. Εφαρμόστε τα φίλτρα

#### Δημιουργία Νέου Χρήστη

1. Κάντε κλικ στο κουμπί "Προσθήκη Χρήστη"
2. Συμπληρώστε τα υποχρεωτικά πεδία (ΟΝΟΜΑΤΕΠΩΝΥΜΟ, EMAIL, ΚΩΔΙΚΟΣ)
3. Επιλέξτε τη γλώσσα και τη ζώνη ώρας (προαιρετικά)
4. Επιλέξτε την ομάδα δικαιωμάτων (προαιρετικά)
5. Ενεργοποιήστε ή απενεργοποιήστε τον χρήστη (προαιρετικά)
6. Κάντε κλικ στο κουμπί "ΔΗΜΙΟΥΡΓΙΑ ΧΡΗΣΤΗ"

#### Επεξεργασία Υπάρχοντος Χρήστη

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Τροποποιήστε τα επιθυμητά πεδία
4. Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΧΡΗΣΤΗ"

#### Αλλαγή Κωδικού Χρήστη

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Κάντε κύλιση προς τα κάτω στην ενότητα "Αλλαγή Κωδικού"
4. Εισάγετε τον νέο κωδικό και την επανάληψή του
5. Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΧΡΗΣΤΗ"

#### Ενεργοποίηση/Απενεργοποίηση Χρήστη

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Χρησιμοποιήστε το toggle **ΕΝΕΡΓΟ** για να ενεργοποιήσετε ή να απενεργοποιήσετε τον χρήστη
4. Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΧΡΗΣΤΗ"

#### Αποκλεισμός Χρήστη

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Χρησιμοποιήστε το toggle **ΜΠΛΟΚΑΡΙΣΜΕΝΟΣ** για να αποκλείσετε τον χρήστη
4. Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΧΡΗΣΤΗ"

#### Περιορισμός Πρόσβασης με IP

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Εισάγετε τις IP διευθύνσεις που επιτρέπονται στο πεδίο "ALLOWED IPS"
4. Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΧΡΗΣΤΗ"

#### Διαγραφή Χρήστη

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Delete"
3. Επιβεβαιώστε τη διαγραφή
