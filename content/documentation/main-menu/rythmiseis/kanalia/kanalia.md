# Κανάλια

Η ενότητα **Κανάλια** (Channels) σας επιτρέπει να διαχειριστείτε τα κανάλια διανομής που συνδέονται με το σύστημα Hotelizer. Κάθε κανάλι αντιπροσωπεύει ένα εξωτερικό σύστημα (όπως Booking.com, Airbnb, κλπ.) που χρησιμοποιείται για τη λήψη κρατήσεων και τη διαχείριση της διαθεσιμότητας. Μπορείτε να ενεργοποιήσετε ή να απενεργοποιήσετε κανάλια, καθώς και να διαχειριστείτε τα διαπιστευτήρια σύνδεσης για κάθε κανάλι.

#### Λίστα Καναλιών

| Στήλη           | Περιγραφή                            | Τύπος Δεδομένων   |
| --------------- | ------------------------------------ | ----------------- |
| **ΟΝΟΜΑ**       | Το όνομα του καναλιού                | Text              |
| **ΕΝΕΡΓΟ**      | Κατάσταση ενεργοποίησης του καναλιού | Boolean (ΝΑΙ/ΟΧΙ) |
| **Action Menu** | Ενέργειες (Edit/Delete)              | Dropdown          |

#### Action Menu (...)

Κάθε γραμμή στον πίνακα διαθέτει ένα action menu που περιέχει:

* **Edit:** Ανοίγει τη φόρμα επεξεργασίας του καναλιού

### Λειτουργίες & Ενέργειες

#### Αναζήτηση Καναλιού

1. Πληκτρολογήστε το όνομα του καναλιού στο πεδίο αναζήτησης
2. Το σύστημα φιλτράρει αυτόματα τα αποτελέσματα

#### Επεξεργασία Καναλιού

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Τροποποιήστε τα διαπιστευτήρια (USERNAME, PASSWORD, CODE)
4. Ενεργοποιήστε ή απενεργοποιήστε το κανάλι
5. Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΚΑΝΑΛΙΟΥ"

#### Ενεργοποίηση/Απενεργοποίηση Καναλιού

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Χρησιμοποιήστε το toggle **ΕΝΕΡΓΟ** για να ενεργοποιήσετε ή να απενεργοποιήσετε το κανάλι
4. Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΚΑΝΑΛΙΟΥ"
