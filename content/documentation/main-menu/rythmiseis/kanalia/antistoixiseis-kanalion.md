# Αντιστοιχίσεις Καναλιών

Η ενότητα **Αντιστοιχίσεις Καναλιών** (Channel Mappings) σας επιτρέπει να αντιστοιχίσετε τις οντότητες του Hotelizer (όπως δωμάτια, τιμές, κλπ.) με τις αντίστοιχες οντότητες των εξωτερικών καναλιών. Αυτή η αντιστοίχιση είναι απαραίτητη για τη σωστή συγχρονισμό δεδομένων μεταξύ του Hotelizer και των εξωτερικών καναλιών.

<figure><img src="../../../.gitbook/assets/image (44).png" alt=""><figcaption></figcaption></figure>

#### Κουμπιά Ενεργειών

* **Filter:** Κουμπί φιλτραρίσματος
* **Προσθήκη Αντιστοίχισης:** Δημιουργία νέας αντιστοίχισης

### Λίστα Αντιστοιχίσεων

| Στήλη                 | Περιγραφή                                         | Τύπος Δεδομένων |
| --------------------- | ------------------------------------------------- | --------------- |
| **Checkbox**          | Επιλογή πολλαπλών αντιστοιχίσεων                  | Checkbox        |
| **ΟΝΤΟΤΗΤΑ**          | Τύπος οντότητας (Property, RoomType, Rate, Extra) | Text            |
| **ΟΝΤΟΤΗΤΑ ΚΑΝΑΛΙΟΥ** | Το όνομα ή το ID της οντότητας στο κανάλι         | Text            |
| **ΕΝΕΡΓΟ**            | Κατάσταση ενεργοποίησης της αντιστοίχισης         | Toggle Switch   |
| **Action Menu**       | Ενέργειες (Edit/Delete)                           | Dropdown        |

### Action Menu (Τρεις Τελείες)

Κάθε γραμμή στον πίνακα διαθέτει ένα action menu που περιέχει:

* **Edit:** Ανοίγει τη φόρμα επεξεργασίας της αντιστοίχισης
* **Delete:** Διαγράφει την αντιστοίχιση (με επιβεβαίωση)

## Λειτουργίες & Ενέργειες

### Αναζήτηση Αντιστοίχισης

1. Πληκτρολογήστε το όνομα ή το ID της αντιστοίχισης στο πεδίο αναζήτησης
2. Το σύστημα φιλτράρει αυτόματα τα αποτελέσματα

### Επεξεργασία Αντιστοίχισης

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Τροποποιήστε το πεδίο "ΟΝΤΟΤΗΤΑ ΚΑΝΑΛΙΟΥ"
4. Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΑΝΤΙΣΤΟΙΧΙΣΗΣ"

### Ενεργοποίηση/Απενεργοποίηση Αντιστοίχισης

1. Κάντε κλικ στο toggle **ΕΝΕΡΓΟ** στη γραμμή της αντιστοίχισης
2. Η αντιστοίχιση ενεργοποιείται ή απενεργοποιείται αμέσως
