# Maison Accounts

Η ενότητα **Λογαριασμοί Maison (Maison Accounts)** σας επιτρέπει να δημιουργήσετε και να διαχειριστείτε τους λογαριασμούς που χρησιμοποιούνται για την παρακολούθηση των χρεώσεων και των συναλλαγών. Οι λογαριασμοί Maison χρησιμοποιούνται για την παρακολούθηση των δαπανών των επισκεπτών (π.χ. mini bar, room service, κ.λπ.) και την ενοποίηση τους στο τελικό τιμολόγιο.

#### Κουμπιά Ενεργειών

* **Filter:** Κουμπί φιλτραρίσματος
* **Add Maison Account:** Δημιουργία νέου λογαριασμού Maison

### Λίστα Λογαριασμών Maison

| Στήλη           | Περιγραφή                   | Τύπος Δεδομένων |
| --------------- | --------------------------- | --------------- |
| **ΠΕΡΙΓΡΑΦΗ**   | Η περιγραφή του λογαριασμού | Text            |
| **TITLE**       | Το όνομα του λογαριασμού    | Text            |
| **ΚΩΔΙΚΟΣ**     | Ο κωδικός του λογαριασμού   | Text            |
| **CONTACT**     | Το όνομα της επαφής         | Text            |
| **CHECK IN**    | Ημερομηνία check-in         | Date            |
| **CHECK OUT**   | Ημερομηνία check-out        | Date            |
| **ΕΝΕΡΓΟ**      | Κατάσταση ενεργοποίησης     | Boolean         |
| **Action Menu** | Ενέργειες (Edit/Delete)     | Dropdown        |

#### Action Menu (...)

Κάθε γραμμή στον πίνακα διαθέτει ένα action menu που περιέχει:

* **Edit:** Ανοίγει τη φόρμα επεξεργασίας του λογαριασμού
* **Delete:** Διαγράφει τον λογαριασμό (με επιβεβαίωση)

### Λειτουργίες & Ενέργειες

#### Αναζήτηση Λογαριασμού Maison

1. Πληκτρολογήστε το όνομα ή τον κωδικό του λογαριασμού στο πεδίο αναζήτησης
2. Το σύστημα φιλτράρει αυτόματα τα αποτελέσματα

#### Δημιουργία Νέου Λογαριασμού Maison

1. Κάντε κλικ στο κουμπί "Add Maison Account"
2. Συμπληρώστε τα πεδία:
   * NAME (προαιρετικό)
   * TITLE (προαιρετικό)
   * CODE (προαιρετικό)
   * CHECK IN (προαιρετικό)
   * CHECK OUT (προαιρετικό)
   * CONTACT (προαιρετικό)
3. Κάντε κλικ στο κουμπί "CREATE MAISON ACCOUNT"

#### Επεξεργασία Υπάρχοντος Λογαριασμού Maison

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Τροποποιήστε τα πεδία
4. Κάντε κλικ στο κουμπί "CREATE MAISON ACCOUNT"

#### Προσθήκη Επαφής

1. Κάντε κλικ στο action menu του λογαριασμού
2. Επιλέξτε "Edit"
3. Κάντε κλικ στο πεδίο "CONTACT SEARCH"
4. Αναζητήστε την επαφή ή κάντε κλικ στο κουμπί "Δημιουργία" για να δημιουργήσετε νέα επαφή
5. Κάντε κλικ στο κουμπί "CREATE MAISON ACCOUNT"

#### Ενεργοποίηση/Απενεργοποίηση Λογαριασμού

1. Κάντε κλικ στο toggle "ACTIVE" στη γραμμή του λογαριασμού
2. Ο λογαριασμός ενεργοποιείται ή απενεργοποιείται αμέσως

#### Διαγραφή Λογαριασμού Maison

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Delete"
3. Επιβεβαιώστε τη διαγραφή

#### Προβολή Παραγγελιών

1. Κάντε κλικ στο action menu του λογαριασμού
2. Επιλέξτε "Edit"
3. Κάντε κλικ στη tab "ORDERS"
4. Δείτε όλες τις παραγγελίες του λογαριασμού
