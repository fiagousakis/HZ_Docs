# POS Tables

Η ενότητα **POS Tables** (Τραπέζια POS) σας επιτρέπει να διαχειριστείτε τα τραπέζια ενός σημείου POS. Κάθε τραπέζι αντιπροσωπεύει μια φυσική τοποθεσία όπου κάθονται οι πελάτες (π.χ. τραπέζι 1, τραπέζι 2, κλπ.). Μπορείτε να δημιουργήσετε νέα τραπέζια, να τα επεξεργαστείτε, και να τα διαγράψετε. Κάθε τραπέζι έχει ρυθμίσεις για το σχήμα, τις διαστάσεις και τη θέση του.

#### Κουμπιά Ενεργειών

* **Filter:** Κουμπί φιλτραρίσματος
* **Προσθήκη Τραπεζιού POS:** Δημιουργία νέου τραπεζιού POS

### Λίστα Τραπεζιών POS

| Στήλη           | Περιγραφή                             | Τύπος Δεδομένων   |
| --------------- | ------------------------------------- | ----------------- |
| **ONOMA**       | Το όνομα του τραπεζιού                | Text              |
| **TABLE NO**    | Ο αριθμός του τραπεζιού               | Text              |
| **SECTION**     | Η ενότητα που ανήκει το τραπέζι       | Text              |
| **ORDERING**    | Η σειρά εμφάνισης του τραπεζιού       | Number            |
| **COLOR**       | Το χρώμα του τραπεζιού                | Color             |
| **ΕΝΕΡΓΟ**      | Κατάσταση ενεργοποίησης του τραπεζιού | Boolean (ΝΑΙ/ΟΧΙ) |
| **Action Menu** | Ενέργειες (Edit/Delete)               | Dropdown          |

Στο κάτω μέρος της λίστας εμφανίζεται ο συνολικός αριθμός των POS Tables

### Action Menu (...)

Κάθε γραμμή στον πίνακα διαθέτει ένα action menu που περιέχει:

* **Edit:** Ανοίγει τη φόρμα επεξεργασίας του τραπεζιού POS
* **Delete:** Διαγράφει το τραπέζι POS (με επιβεβαίωση)

## Λειτουργίες & Ενέργειες

### Αναζήτηση Τραπεζιού POS

1. Πληκτρολογήστε το όνομα του τραπεζιού POS στο πεδίο αναζήτησης
2. Το σύστημα φιλτράρει αυτόματα τα αποτελέσματα

### Δημιουργία Νέου Τραπεζιού POS

1. Κάντε κλικ στο κουμπί "Add POS Table"
2. Συμπληρώστε τα υποχρεωτικά πεδία:
   * ΟΝΟΜΑ
   * SECTION
3. Συμπληρώστε τα προαιρετικά πεδία (TABLE NO, SHAPE, WIDTH, HEIGHT, κλπ.)
4. Κάντε κλικ στο κουμπί "UPDATE POS TABLE"

### Επεξεργασία Υπάρχοντος Τραπεζιού POS

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Τροποποιήστε τα πεδία
4. Κάντε κλικ στο κουμπί "UPDATE POS TABLE"

### Ενεργοποίηση/Απενεργοποίηση Τραπεζιού POS

1. Κάντε κλικ στο toggle **ΕΝΕΡΓΟ** στη γραμμή του τραπεζιού
2. Το τραπέζι ενεργοποιείται ή απενεργοποιείται αμέσως

### Διαγραφή Τραπεζιού POS

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Delete"
3. Επιβεβαιώστε τη διαγραφή



## Παράδειγμα Ροής Εργασίας

### Δημιουργία Νέου Τραπεζιού POS

1. **Δημιουργία Τραπεζιού POS**
   * Κάντε κλικ στο κουμπί "Add POS Table"
   * Συμπληρώστε:
     * ΟΝΟΜΑ: "R1"
     * TABLE NO: "R1"
     * SECTION: "Restaurant"
   * Επιλέξτε:
     * SHAPE: "Square"
   * Κάντε κλικ στο κουμπί "UPDATE POS TABLE"
2. **Ορισμός Διαστάσεων**
   * Κάντε κλικ στο action menu του τραπεζιού
   * Επιλέξτε "Edit"
   * Ορίστε:
     * WIDTH: 100
     * HEIGHT: 100
     * X DIMENSION: 50
     * Y DIMENSION: 50
   * Κάντε κλικ στο κουμπί "UPDATE POS TABLE"
3. **Ενεργοποίηση Τραπεζιού**
   * Κάντε κλικ στο toggle ΕΝΕΡΓΟ
   * Το τραπέζι είναι τώρα ενεργό
4. **Χρήση Τραπεζιού**
   * Το τραπέζι είναι τώρα έτοιμο για χρήση
   * Μπορείτε να κάνετε πωλήσεις μέσω αυτού του τραπεζιού
