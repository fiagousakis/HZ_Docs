# Products

Η ενότητα **Products** (Προϊόντα) σας επιτρέπει να διαχειριστείτε τα προϊόντα που πωλούνται μέσω του POS. Κάθε προϊόν αντιπροσωπεύει ένα αντικείμενο ή υπηρεσία που μπορεί να πωληθεί (π.χ. ποτά, φαγητό, υπηρεσία μασάζ, κλπ.). Μπορείτε να δημιουργήσετε νέα προϊόντα, να τα επεξεργαστείτε, και να τα διαγράψετε. Κάθε προϊόν έχει ρυθμίσεις για τιμολόγηση, φόρους, σημείο πώλησης και άλλες πληροφορίες.

#### Κουμπιά Ενεργειών

* **Filter:** Κουμπί φιλτραρίσματος
* **Report:** Κουμπί εξαγωγής αναφοράς
* **Προσθήκη Προϊόντος:** Δημιουργία νέου προϊόντος

### Λϊστα Προϊόντων

| Στήλη               | Περιγραφή                             | Τύπος Δεδομένων   |
| ------------------- | ------------------------------------- | ----------------- |
| **ONOMA**           | Το όνομα του προϊόντος                | Text              |
| **SERVICE**         | Η υπηρεσία που ανήκει το προϊόν       | Text              |
| **CATEGORY**        | Η κατηγορία του προϊόντος             | Text              |
| **ΤΙΜΗ**            | Η τιμή του προϊόντος                  | Currency          |
| **ΦΟΡΟΙ**           | Οι φόροι που εφαρμόζονται             | Text              |
| **TAKE AWAY PRICE** | Η τιμή για παραλαβή                   | Currency          |
| **TAKE AWAY TAXES** | Οι φόροι για παραλαβή                 | Text              |
| **ΕΝΕΡΓΟ**          | Κατάσταση ενεργοποίησης του προϊόντος | Boolean (ΝΑΙ/ΟΧΙ) |
| **Action Menu**     | Ενέργειες (Edit/Delete)               | Dropdown          |

Στο footer της λίστας εμφανίζεται ο συνολικός αριθμός προϊόντων (π.χ. "TOTAL PRODUCTS 35")

### Action Menu (...)

Κάθε γραμμή στον πίνακα διαθέτει ένα action menu που περιέχει:

* **Edit:** Ανοίγει τη φόρμα επεξεργασίας του προϊόντος
* **Delete:** Διαγράφει το προϊόν (με επιβεβαίωση)

## Λειτουργίες & Ενέργειες

### Αναζήτηση Προϊόντος

1. Πληκτρολογήστε το όνομα του προϊόντος στο πεδίο αναζήτησης
2. Το σύστημα φιλτράρει αυτόματα τα αποτελέσματα

### Δημιουργία Νέου Προϊόντος

1. Κάντε κλικ στο κουμπί "Add Product"
2. Συμπληρώστε το υποχρεωτικό πεδίο ΟΝΟΜΑ
3. Συμπληρώστε το υποχρεωτικό πεδίο ΤΙΜΗ
4. Συμπληρώστε τα προαιρετικά πεδία (ΚΑΤΗΓΟΡΙΑ, ΥΠΗΡΕΣΙΑ, ΦΟΡΟΙ, κλπ.)
5. Κάντε κλικ στο κουμπί "UPDATE PRODUCT"

### Επεξεργασία Υπάρχοντος Προϊόντος

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Τροποποιήστε τα πεδία
4. Κάντε κλικ στο κουμπί "UPDATE PRODUCT"

### Ενεργοποίηση/Απενεργοποίηση Προϊόντος

1. Κάντε κλικ στο toggle **ΕΝΕΡΓΟ** στη γραμμή του προϊόντος
2. Το προϊόν ενεργοποιείται ή απενεργοποιείται αμέσως

### Διαγραφή Προϊόντος

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Delete"
3. Επιβεβαιώστε τη διαγραφή

### Φιλτραρισμα Προϊόντων

1. Κάντε κλικ στο κουμπί "Filter"
2. Επιλέξτε τα κριτήρια φιλτραρίσματος:
   * Κατηγορία
   * Υπηρεσία
   * Κατάσταση (Ενεργό/Απενεργοποιημένο)
3. Κάντε κλικ στο κουμπί "Apply"

### Εξαγωγή Αναφοράς

1. Κάντε κλικ στο κουμπί "Report"
2. Επιλέξτε τη μορφή εξαγωγής (PDF, Excel, κλπ.)
3. Κάντε κλικ στο κουμπί "Export"

### Ροή Δημιουργίας Νέου Προϊόντος

1. **Δημιουργία Προϊόντος**
   * Κάντε κλικ στο κουμπί "Add Product"
   * Συμπληρώστε:
     * ΟΝΟΜΑ: "Espresso Coffee"
     * ΤΙΜΗ: 3,50 €
   * Επιλέξτε:
     * ΚΑΤΗΓΟΡΙΑ: "Hot Drinks"
     * ΥΠΗΡΕΣΙΑ: "Beverage"
     * ΦΟΡΟΙ: "ΦΠΑ 13%"
   * Κάντε κλικ στο κουμπί "UPDATE PRODUCT"
2. **Ορισμός Τιμής Παραλαβής**
   * Κάντε κλικ στο action menu του προϊόντος
   * Επιλέξτε "Edit"
   * Ορίστε:
     * TAKEAWAY PRICE: 2,50 €
   * Κάντε κλικ στο κουμπί "UPDATE PRODUCT"
3. **Ενεργοποίηση Προϊόντος**
   * Κάντε κλικ στο toggle ΕΝΕΡΓΟ
   * Το προϊόν είναι τώρα ενεργό
4. **Χρήση Προϊόντος**
   * Το προϊόν είναι τώρα έτοιμο για πώληση
   * Μπορείτε να το προσθέσετε σε παραγγελίες
