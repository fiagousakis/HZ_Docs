# Product Categories

Η ενότητα **Product Categories** (Κατηγορίες Προϊόντων ) σας επιτρέπει να διαχειριστείτε τις κατηγορίες προϊόντων που χρησιμοποιούνται στο POS. Κάθε κατηγορία αντιπροσωπεύει μια ομάδα προϊόντων (π.χ. Ποτά, Φαγητό, Σαλάτες, κλπ.). Μπορείτε να δημιουργήσετε νέες κατηγορίες, να τις επεξεργαστείτε, και να τις διαγράψετε. Κάθε κατηγορία μπορεί να έχει modifier sets που προσθέτουν επιλογές στα προϊόντα.

#### Κουμπιά Ενεργειών

* **Προσθήκη Κατηγορίας:** Δημιουργία νέας κατηγορίας έξτρα

### Λίστα Κατηγοριών Έξτρα

| Στήλη           | Περιγραφή               | Τύπος Δεδομένων |
| --------------- | ----------------------- | --------------- |
| **ΟΝΟΜΑ**       | Το όνομα της κατηγορίας | Text            |
| **Action Menu** | Ενέργειες (Edit/Delete) | Dropdown        |

### Action Menu (...)

Κάθε γραμμή στον πίνακα διαθέτει ένα action menu που περιέχει:

* **Edit:** Ανοίγει τη φόρμα επεξεργασίας της κατηγορίας
* **Delete:** Διαγράφει την κατηγορία (με επιβεβαίωση)

## Δημιουργία/Επεξεργασία Κατηγορίας Προϊόντος

Η φόρμα επεξεργασίας κατηγορίας έξτρα περιέχει τις ακόλουθες ενότητες:

#### Βασικές Πληροφορίες

| Πεδίο       | Περιγραφή                            | Τύπος        | Υποχρεωτικό | Παράδειγμα                             |
| ----------- | ------------------------------------ | ------------ | ----------- | -------------------------------------- |
| **ΟΝΟΜΑ**   | Το όνομα της κατηγορίας              | Text Input   | **ΝΑΙ**     | "Coffees", "Main Dishes", "Salads"     |
| **ΓΟΝΕΑΣ**  | Η γονική κατηγορία (για ιεραρχία)    | Dropdown     | Όχι         | "Food", "Beverages"                    |
| **SECTION** | Η ενότητα POS που ανήκει η κατηγορία | Multi-select | Όχι         | "Pool Bar", "Restaurant", "Kiosk cafe" |

#### Product Category Modifier Sets

| Πεδίο        | Περιγραφή                 | Τύπος  | Υποχρεωτικό |
| ------------ | ------------------------- | ------ | ----------- |
| **NAME**     | Το όνομα του modifier set | Text   | Όχι         |
| **REQUIRED** | Αν είναι υποχρεωτικό      | Toggle | Όχι         |
| **ΔΙΑΤΑΞΗ**  | Η σειρά εμφάνισης         | Number | Όχι         |

#### Κουμπιά Ενεργειών

* **ΕΝΗΜΕΡΩΣΗ ΚΑΤΗΓΟΡΙΑΣ:** Αποθήκευση αλλαγών στην κατηγορία



## Λειτουργίες & Ενέργειες

### Αναζήτηση Κατηγορίας Έξτρα

1. Πληκτρολογήστε το όνομα της κατηγορίας στο πεδίο αναζήτησης
2. Το σύστημα φιλτράρει αυτόματα τα αποτελέσματα

### Δημιουργία Νέας Κατηγορίας Έξτρα

1. Κάντε κλικ στο κουμπί "Προσθήκη Κατηγορίας"
2. Συμπληρώστε το υποχρεωτικό πεδίο ΟΝΟΜΑ
3. Επιλέξτε τις ενότητες POS (προαιρετικό)
4. Προσθέστε modifier sets (προαιρετικό)
5. Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΚΑΤΗΓΟΡΙΑΣ"

### Επεξεργασία Υπάρχουσας Κατηγορίας Έξτρα

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Τροποποιήστε τα πεδία
4. Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΚΑΤΗΓΟΡΙΑΣ"

### Προσθήκη Modifier Set σε Κατηγορία

1. Κάντε κλικ στο action menu της κατηγορίας
2. Επιλέξτε "Edit"
3. Κάντε κλικ στο κουμπί "Add item" στην ενότητα "Product Category Modifier Sets"
4. Επιλέξτε το modifier set από τη λίστα
5. Ορίστε αν είναι υποχρεωτικό (REQUIRED)
6. Ορίστε τη σειρά εμφάνισης (ΔΙΑΤΑΞΗ)
7. Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΚΑΤΗΓΟΡΙΑΣ"

### Διαγραφή Κατηγορίας Έξτρα

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Delete"
3. Επιβεβαιώστε τη διαγραφή

### Ροή Δημιουργίας Νέας Κατηγορίας με Modifier Sets

1. **Δημιουργία Κατηγορίας**
   * Κάντε κλικ στο κουμπί "Προσθήκη Κατηγορίας"
   * Συμπληρώστε:
     * ΟΝΟΜΑ: "Hot Drinks"
   * Επιλέξτε:
     * SECTION: "Restaurant", "Pool Bar"
   * Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΚΑΤΗΓΟΡΙΑΣ"
2. **Προσθήκη Modifier Sets**
   * Κάντε κλικ στο action menu της κατηγορίας
   * Επιλέξτε "Edit"
   * Κάντε κλικ στο κουμπί "Add item"
   * Επιλέξτε:
     * NAME: "Επιλογή ζάχαρης"
     * REQUIRED: ΝΑΙ
     * ΔΙΑΤΑΞΗ: 0
   * Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΚΑΤΗΓΟΡΙΑΣ"
3. **Προσθήκη Δεύτερου Modifier Set**
   * Κάντε κλικ στο κουμπί "Add item" ξανά
   * Επιλέξτε:
     * NAME: "Επιλογή μεγέθους"
     * REQUIRED: ΟΧΙ
     * ΔΙΑΤΑΞΗ: 1
   * Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΚΑΤΗΓΟΡΙΑΣ"
4. **Χρήση Κατηγορίας**
   * Η κατηγορία είναι τώρα έτοιμη για χρήση
   * Μπορείτε να δημιουργήσετε προϊόντα που ανήκουν σε αυτή την κατηγορία
