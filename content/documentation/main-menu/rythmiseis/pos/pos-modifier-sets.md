# POS Modifier Sets

Η ενότητα **Σύνολα Τροποποιητών POS (POS Modifier Sets)** σας επιτρέπει να δημιουργήσετε και να διαχειριστείτε τις επιλογές τροποποίησης προϊόντων. Οι τροποποιητές είναι επιπλέον επιλογές που οι πελάτες μπορούν να κάνουν όταν παραγγέλνουν ένα προϊόν (π.χ. επιλογή ζάχαρης στον καφέ, επιλογή ψησίματος για το κρέας, κ.λπ.).

#### Κουμπιά Ενεργειών

* **Filter:** Κουμπί φιλτραρίσματος
* **Add POS Modifier Set:** Δημιουργία νέου συνόλου τροποποιήσεων

### Λίστα Συνόλων Τροποποιήσεων POS

| Στήλη             | Περιγραφή                                          | Τύπος Δεδομένων |
| ----------------- | -------------------------------------------------- | --------------- |
| **ONOMA**         | Το όνομα του συνόλου τροποποιήσεων                 | Text            |
| **MODIFIER TYPE** | Ο τύπος τροποποιήσης (One Option, Several Options) | Text            |
| **MIN**           | Ελάχιστος αριθμός επιλογών                         | Number          |
| **MAX**           | Μέγιστος αριθμός επιλογών                          | Number          |
| **ALL SELECTED**  | Αν όλες οι επιλογές είναι προεπιλεγμένες           | Boolean         |
| **ORDER**         | Η σειρά εμφάνισης                                  | Number          |
| **Action Menu**   | Ενέργειες (Edit/Delete)                            | Dropdown        |

Στο footer της λίστας εμφανίζεται ο συνολικός αριθμός των Συνόλων Τροποποιήτών

### Action Menu (...)

Κάθε γραμμή στον πίνακα διαθέτει ένα action menu που περιέχει:

* **Edit:** Ανοίγει τη φόρμα επεξεργασίας του συνόλου τροποποιήσεων
* **Delete:** Διαγράφει το σύνολο τροποποιήσεων (με επιβεβαίωση)

#### POS Modifier Set Ingredients

| Πεδίο                           | Περιγραφή                                    | Τύπος        | Υποχρεωτικό |
| ------------------------------- | -------------------------------------------- | ------------ | ----------- |
| **ΟΝΟΜΑ**                       | Το όνομα της επιλογής                        | Text Input   | **ΝΑΙ**     |
| **ΤΙΜΗ**                        | Η πρόσθετη τιμή της επιλογής                 | Number Input | Όχι         |
| **IS SELECTED**                 | Αν η επιλογή είναι προεπιλεγμένη             | Toggle       | Όχι         |
| **ΟΝΟΜΑ (Enable Modifier Set)** | Το όνομα του modifier set που ενεργοποιείται | Dropdown     | Όχι         |

#### Τύποι Τροποποιητών

Υπάρχουν δύο τύποι τροποποιητών:

1. **One Option:** Ο πελάτης μπορεί να επιλέξει μόνο μία επιλογή από το σύνολο (π.χ. επιλογή ζάχαρης - Ολίγη, Μέτριος, Γλυκός ή Σκέτος).
2. **Several Options:** Ο πελάτης μπορεί να επιλέξει περισσότερες από μία επιλογές (π.χ. επιλογή extras/toppings).

#### Ελάχιστος και Μέγιστος Αριθμός Επιλογών

* **MIN:** Ο ελάχιστος αριθμός επιλογών που πρέπει να γίνουν. Αν είναι 0, ο πελάτης δεν υποχρεούται να επιλέξει κάτι.
* **MAX:** Ο μέγιστος αριθμός επιλογών που μπορούν να γίνουν. Αν είναι 0, δεν υπάρχει περιορισμός.

#### Κουμπιά Ενεργειών

* **UPDATE POS MODIFIER SET:** Αποθήκευση αλλαγών στο σύνολο τροποποιήσεων



### Λειτουργίες & Ενέργειες

#### Αναζήτηση Συνόλου Τροποποιήσεων

1. Πληκτρολογήστε το όνομα του συνόλου τροποποιήσεων στο πεδίο αναζήτησης
2. Το σύστημα φιλτράρει αυτόματα τα αποτελέσματα

#### Δημιουργία Νέου Συνόλου Τροποποιήσεων

1. Κάντε κλικ στο κουμπί "Add POS Modifier Set"
2. Συμπληρώστε τα υποχρεωτικά πεδία:
   * ΟΝΟΜΑ
   * MODIFIER TYPE
3. Προσθέστε επιλογές (ingredients) κάνοντας κλικ στο κουμπί "Add item"
4. Κάντε κλικ στο κουμπί "UPDATE POS MODIFIER SET"

#### Επεξεργασία Υπάρχοντος Συνόλου Τροποποιήσεων

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Τροποποιήστε τα πεδία
4. Κάντε κλικ στο κουμπί "UPDATE POS MODIFIER SET"

#### Προσθήκη Επιλογής (Ingredient)

1. Κάντε κλικ στο action menu του συνόλου τροποποιήσεων
2. Επιλέξτε "Edit"
3. Κάντε κλικ στο κουμπί "Add item" στην ενότητα "POS Modifier Set Ingredients"
4. Συμπληρώστε:
   * ΟΝΟΜΑ: Το όνομα της επιλογής
   * ΤΙΜΗ: Η πρόσθετη τιμή (προαιρετικό)
5. Κάντε κλικ στο κουμπί "UPDATE POS MODIFIER SET"

#### Διαγραφή Συνόλου Τροποποιήσεων

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Delete"
3. Επιβεβαιώστε τη διαγραφή

#### Ροή Δημιουργίας Νέου Συνόλου Τροποποιητή

1. **Δημιουργία Συνόλου**
   * Κάντε κλικ στο κουμπί "Add POS Modifier Set"
   * Συμπληρώστε:
     * ΟΝΟΜΑ: "Επιλογή μεγέθους"
     * MODIFIER TYPE: "One Option"
   * Κάντε κλικ στο κουμπί "UPDATE POS MODIFIER SET"
2. **Προσθήκη Επιλογών**
   * Κάντε κλικ στο action menu του συνόλου
   * Επιλέξτε "Edit"
   * Κάντε κλικ στο κουμπί "Add item"
   * Προσθέστε:
     * ΟΝΟΜΑ: "Μικρό"
     * ΤΙΜΗ: 0
   * Κάντε κλικ στο κουμπί "UPDATE POS MODIFIER SET"
3. **Προσθήκη Δεύτερης Επιλογής**
   * Κάντε κλικ στο κουμπί "Add item" ξανά
   * Προσθέστε:
     * ΟΝΟΜΑ: "Μεσαίο"
     * ΤΙΜΗ: 0
   * Κάντε κλικ στο κουμπί "UPDATE POS MODIFIER SET"
4. **Προσθήκη Τρίτης Επιλογής**
   * Κάντε κλικ στο κουμπί "Add item" ξανά
   * Προσθέστε:
     * ΟΝΟΜΑ: "Μεγάλο"
     * ΤΙΜΗ: 2.00
   * Κάντε κλικ στο κουμπί "UPDATE POS MODIFIER SET"
5. **Χρήση Συνόλου**
   * Το σύνολο είναι τώρα έτοιμο για χρήση
   * Μπορείτε να το προσθέσετε σε κατηγορίες ή προϊόντα
