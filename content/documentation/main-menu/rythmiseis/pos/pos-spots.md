# POS Spots

Η ενότητα **POS Spots** (Σημεία POS) σας επιτρέπει να διαχειριστείτε τα σημεία πώλησης (POS) του ξενοδοχείου. Κάθε σημείο POS αντιπροσωπεύει μια τοποθεσία όπου γίνονται πωλήσεις (π.χ. εστιατόριο, μπαρ, spa, κλπ.). Μπορείτε να δημιουργήσετε νέα σημεία POS, να τα επεξεργαστείτε, και να τα διαγράψετε.

#### Κουμπιά Ενεργειών

* **Filter:** Κουμπί φιλτραρίσματος
* **Προσθήκη Σημείου POS:** Δημιουργία νέου σημείου POS

### Λίστα Σημείων POS

| Στήλη           | Περιγραφή                                      | Τύπος Δεδομένων   |
| --------------- | ---------------------------------------------- | ----------------- |
| **ΟΝΟΜΑ**       | Το όνομα του σημείου POS                       | Text              |
| **Address**     | Η διεύθυνση του σημείου POS                    | Text              |
| **ΠΟΛΗ**        | Η πόλη του σημείου POS                         | Text              |
| **POSTAL**      | Ο ταχυδρομικός κώδικας                         | Text              |
| **ΕΤΑΙΡΙΑ**     | Η εταιρία που διαχειρίζεται το σημείο POS      | Text              |
| **ΧΡΩΜΑ**       | Το χρώμα του σημείου POS (για οπτική διάκριση) | Color             |
| **ΕΝΕΡΓΟ**      | Κατάσταση ενεργοποίησης του σημείου POS        | Boolean (ΝΑΙ/ΟΧΙ) |
| **Action Menu** | Ενέργειες (Edit/Delete)                        | Dropdown          |

Στο κάτω μέρος της λίστας εμφανίζεται ο συνολικός αριθμός των Σημείων POS

### Action Menu (...)

Κάθε γραμμή στον πίνακα διαθέτει ένα action menu που περιέχει:

* **Edit:** Ανοίγει τη φόρμα επεξεργασίας του σημείου POS
* **Delete:** Διαγράφει το σημείο POS (με επιβεβαίωση)

## Λειτουργίες & Ενέργειες

### Αναζήτηση Σημείου POS

1. Πληκτρολογήστε το όνομα του σημείου POS στο πεδίο αναζήτησης
2. Το σύστημα φιλτράρει αυτόματα τα αποτελέσματα

### Δημιουργία Νέου Σημείου POS

1. Κάντε κλικ στο κουμπί "Add POS Spot"
2. Συμπληρώστε το υποχρεωτικό πεδίο ΟΝΟΜΑ
3. Συμπληρώστε τα προαιρετικά πεδία (ΤΑΧΥΔΡΟΜΙΚΟΣ ΚΩΔΙΚΑΣ, ΠΟΛΗ, ΔΙΕΥΘΥΝΣΗ, κλπ.)
4. Επιλέξτε ένα χρώμα (προαιρετικά)
5. Κάντε κλικ στο κουμπί "UPDATE POS SPOT"

### Επεξεργασία Υπάρχοντος Σημείου POS

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Τροποποιήστε τα πεδία
4. Κάντε κλικ στο κουμπί "UPDATE POS SPOT"

### Ενεργοποίηση/Απενεργοποίηση Σημείου POS

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Χρησιμοποιήστε το toggle **ΕΝΕΡΓΟ** για να ενεργοποιήσετε ή να απενεργοποιήσετε το σημείο POS
4. Κάντε κλικ στο κουμπί "UPDATE POS SPOT"

### Διαγραφή Σημείου POS

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Delete"
3. Επιβεβαιώστε τη διαγραφή

### Δημιουργία Νέου Σημείου POS

1. **Δημιουργία Σημείου POS**
   * Κάντε κλικ στο κουμπί "Add POS Spot"
   * Συμπληρώστε:
     * ΟΝΟΜΑ: "Pool Bar"
   * Συμπληρώστε (προαιρετικά):
     * ΤΑΧΥΔΡΟΜΙΚΟΣ ΚΩΔΙΚΑΣ: "45221"
     * ΠΟΛΗ: "Ioannina"
     * ΔΙΕΥΘΥΝΣΗ: "Pool Area"
   * Επιλέξτε:
     * ΧΡΩΜΑ: "#00d6ff" (Μπλε)
   * Κάντε κλικ στο κουμπί "UPDATE POS SPOT"
2. **Ενεργοποίηση Σημείου POS**
   * Κάντε κλικ στο toggle ΕΝΕΡΓΟ
   * Το σημείο POS είναι τώρα ενεργό
3. **Δημιουργία Ενοτήτων και Τραπεζιών**
   * Δημιουργήστε ενότητες (sections) για το σημείο POS
   * Δημιουργήστε τραπέζια (tables) για κάθε ενότητα
4. **Χρήση Σημείου POS**
   * Το σημείο POS είναι τώρα έτοιμο για χρήση
   * Μπορείτε να κάνετε πωλήσεις μέσω αυτού του σημείου POS
