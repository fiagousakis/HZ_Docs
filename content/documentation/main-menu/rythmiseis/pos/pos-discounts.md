# POS Discounts

Η ενότητα **POS Discounts** (Εκπτώσεις POS) σας επιτρέπει να διαχειριστείτε τις διαθέσιμες εκπτώσεις που μπορείτε να εφαρμόσετε στις παραγγελίες POS. Κάθε εκπτώση αντιπροσωπεύει ένα σύνολο κανόνων για την εφαρμογή μιας έκπτώσης (π.χ. "Employee" με 25% εκπτώση, "Happy Hour" με 10% εκπτώση).&#x20;

<figure><img src="../../../.gitbook/assets/image (36).png" alt=""><figcaption></figcaption></figure>

#### Κουμπιά Ενεργειών

* **Filter:** Κουμπί φιλτραρίσματος
* **Add Pos Discount:** Δημιουργία νέας εκπτώσης

### Λίστα Εκπτώσεων POS

| Στήλη               | Περιγραφή                                                | Τύπος Δεδομένων |
| ------------------- | -------------------------------------------------------- | --------------- |
| **NAME**            | Το όνομα της εκπτώσης                                    | Text            |
| **DISCOUNT TYPE**   | Ο τύπος της εκπτώσης (Complimentary, Agreement, Generic) | Text            |
| **DISCOUNT METHOD** | Η μέθοδος εφαρμογής (Complimentary, Agreement, Generic)  | Text            |
| **ΠΟΣΟ**            | Το ποσό ή ποσοστό της εκπτώσης                           | Number          |
| **ΕΝΕΡΓΟ**          | Κατάσταση ενεργοποίησης της εκπτώσης                     | Boolean         |
| **Action Menu**     | Ενέργειες (Edit/Delete)                                  | Dropdown        |

Στο footer της λίστας εμφανίζεται ο συνολικός αριθμός των Συνόλων Τροποποιήτών

#### Action Menu (...)

Κάθε γραμμή στον πίνακα διαθέτει ένα action menu που περιέχει:

* **Edit:** Ανοίγει τη φόρμα επεξεργασίας της εκπτώσης
* **Delete:** Διαγράφει την εκπτώση (με επιβεβαίωση)

#### Τύποι Εκπτώσεων

Υπάρχουν τρεις τύποι εκπτώσεων:

1. **Complimentary:** Εκπτώσεις που δίνονται δωρεάν (π.χ. δωρεάν ποτό για VIP πελάτη).
2. **Agreement:** Εκπτώσεις που βασίζονται σε συμφωνίες (π.χ. εκπτώσεις συνεργατών).
3. **Generic:** Γενικές εκπτώσεις που μπορούν να εφαρμοστούν σε οποιαδήποτε παραγγελία (π.χ. εκπτώσεις υπαλλήλων, εκπτώσεις διευθυντή).

#### Μέθοδοι Έκπτωσης

Υπάρχουν δύο μέθοδοι εφαρμογής εκπτώσεων:

1. **Percentage:** Η έκπτωση εφαρμόζεται ως ποσοστό του συνολικού ποσού της παραγγελίας (π.χ. 10% έκπτωση).
2. **Fixed Amount:** Η έκπτωση εφαρμόζεται ως σταθερό ποσό (π.χ. €5 έκπτωση).

### Λειτουργίες & Ενέργειες

#### Αναζήτηση Εκπτώσης

1. Πληκτρολογήστε το όνομα της εκπτώσης στο πεδίο αναζήτησης
2. Το σύστημα φιλτράρει αυτόματα τα αποτελέσματα

#### Δημιουργία Νέας Εκπτώσης

1. Κάντε κλικ στο κουμπί "Add Pos Discount"
2. Συμπληρώστε τα υποχρεωτικά πεδία:
   * NAME
   * DISCOUNT TYPE
   * DISCOUNT METHOD
   * ΠΟΣΟ
3. Κάντε κλικ στο κουμπί "UPDATE POS DISCOUNT"

#### Επεξεργασία Υπάρχουσας Εκπτώσης

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Τροποποιήστε τα πεδία
4. Κάντε κλικ στο κουμπί "UPDATE POS DISCOUNT"

#### Ενεργοποίηση/Απενεργοποίηση Εκπτώσης

1. Κάντε κλικ στο toggle **ACTIVE** στη γραμμή της εκπτώσης
2. Η εκπτώση ενεργοποιείται ή απενεργοποιείται αμέσως

#### Διαγραφή Εκπτώσης

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Delete"
3. Επιβεβαιώστε τη διαγραφή

#### Ροή Διαχείρισης Εκπτώσης

1. **Δημιουργία Εκπτώσης**
   * Κάντε κλικ στο κουμπί "Add Pos Discount"
   * Συμπληρώστε:
     * NAME: "Student Discount"
     * DISCOUNT TYPE: "Generic"
     * DISCOUNT METHOD: "Percentage"
     * ΠΟΣΟ: 15
   * Κάντε κλικ στο κουμπί "UPDATE POS DISCOUNT"
2. **Ενεργοποίηση Εκπτώσης**
   * Κάντε κλικ στο toggle "ACTIVE"
   * Η εκπτώση είναι τώρα ενεργή
3. **Χρήση Εκπτώσης**
   * Η εκπτώση είναι τώρα έτοιμη για χρήση
   * Μπορείτε να την εφαρμόσετε σε παραγγελίες
4. **Τροποποίηση Εκπτώσης**
   * Κάντε κλικ στο action menu της εκπτώσης
   * Επιλέξτε "Edit"
   * Αλλάξτε το ποσό σε 20
   * Κάντε κλικ στο κουμπί "UPDATE POS DISCOUNT"
5. **Απενεργοποίηση Εκπτώσης**
   * Κάντε κλικ στο toggle "ACTIVE"
   * Η εκπτώση είναι τώρα απενεργή
