# POS Sections

Η ενότητα **POS Sections** (Ενότητες POS) σας επιτρέπει να διαχειριστείτε τις ενότητες ενός σημείου POS. Κάθε ενότητα αντιπροσωπεύει μια περιοχή ή ένα τμήμα του σημείου POS (π.χ. εστιατόριο, μπαρ, κουζίνα, κλπ.). Μπορείτε να δημιουργήσετε νέες ενότητες, να τις επεξεργαστείτε, και να τις διαγράψετε. Κάθε ενότητα έχει ρυθμίσεις για τιμολόγηση, εκτύπωση και ολοκλήρωση παραγγελιών.

#### Κουμπιά Ενεργειών

* **Filter:** Κουμπί φιλτραρίσματος
* **Προσθήκη Ενότητας POS:** Δημιουργία νέας ενότητας POS

### Λίστα Ενοτήτων POS

| Στήλη           | Περιγραφή                                   | Τύπος Δεδομένων   |
| --------------- | ------------------------------------------- | ----------------- |
| **ΟΝΟΜΑ**       | Το όνομα της ενότητας POS                   | Text              |
| **INTEGRATION** | Ο τύπος ολοκλήρωσης (printer, κλπ.)         | Text              |
| **ΔΙΑΤΑΞΗ**     | Η σειρά εμφάνισης της ενότητας              | Number            |
| **ΧΡΩΜΑ**       | Το χρώμα της ενότητας (για οπτική διάκριση) | Color             |
| **ΕΝΕΡΓΟ**      | Κατάσταση ενεργοποίησης της ενότητας        | Boolean (ΝΑΙ/ΟΧΙ) |
| **Action Menu** | Ενέργειες (Edit/Delete)                     | Dropdown          |

Στο κάτω μέρος της λίστας εμφανίζεται ο συνολικός αριθμός των POS Sections

### Action Menu (...)

Κάθε γραμμή στον πίνακα διαθέτει ένα action menu που περιέχει:

* **Edit:** Ανοίγει τη φόρμα επεξεργασίας της ενότητας POS
* **Delete:** Διαγράφει την ενότητα POS (με επιβεβαίωση)

## Λειτουργίες & Ενέργειες

### Αναζήτηση Ενότητας POS

1. Πληκτρολογήστε το όνομα της ενότητας POS στο πεδίο αναζήτησης
2. Το σύστημα φιλτράρει αυτόματα τα αποτελέσματα

### Δημιουργία Νέας Ενότητας POS

1. Κάντε κλικ στο κουμπί "Add POS Section"
2. Συμπληρώστε το υποχρεωτικό πεδίο ΟΝΟΜΑ
3. Συμπληρώστε τα προαιρετικά πεδία (τύποι τιμολογίων, ρυθμίσεις, κλπ.)
4. Επιλέξτε ένα χρώμα (προαιρετικά)
5. Κάντε κλικ στο κουμπί "UPDATE POS SECTION"

### Επεξεργασία Υπάρχουσας Ενότητας POS

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Τροποποιήστε τα πεδία
4. Κάντε κλικ στο κουμπί "UPDATE POS SECTION"

### Ενεργοποίηση/Απενεργοποίηση Ενότητας POS

1. Κάντε κλικ στο toggle **ΕΝΕΡΓΟ** στη γραμμή της ενότητας
2. Η ενότητα ενεργοποιείται ή απενεργοποιείται αμέσως

### Διαγραφή Ενότητας POS

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Delete"
3. Επιβεβαιώστε τη διαγραφή

### Ροή Δημιουργία Νέας Ενότητας POS για Εστιατόριο

1. **Δημιουργία Ενότητας POS**
   * Κάντε κλικ στο κουμπί "Add POS Section"
   * Συμπληρώστε:
     * ΟΝΟΜΑ: "Main Restaurant"
   * Επιλέξτε:
     * ΤΥΠΟΣ ΤΙΜΟΛΟΓΙΟΥ: "ΔΕΛΤΙΟ ΠΑΡΑΓΓΕΛΙΑΣ"
     * FINAL INVOICE TYPE: "Απόδειξη Λιανικής Πώλησης"
     * ΧΡΩΜΑ: "#9fff00" (Κίτρινο)
   * Κάντε κλικ στο κουμπί "UPDATE POS SECTION"
2. **Ρύθμιση Εκτύπωσης**
   * Κάντε κλικ στο action menu της ενότητας
   * Επιλέξτε "Edit"
   * Ενεργοποιήστε:
     * PRINT INVOICES: ΝΑΙ
     * PRINT TICKETS: ΝΑΙ
   * Επιλέξτε τους εκτυπωτές
   * Κάντε κλικ στο κουμπί "UPDATE POS SECTION"
3. **Ρύθμιση Ταμείου**
   * Κάντε κλικ στο action menu της ενότητας
   * Επιλέξτε "Edit"
   * Επιλέξτε:
     * CASHIER: "Restaurant Cashier"
     * PAYMENT OPTIONS: "Μετρητά", "Mellon EFT/POS", "VIVA EFT/POS"
   * Κάντε κλικ στο κουμπί "UPDATE POS SECTION"
4. **Δημιουργία Τραπεζιών**
   * Δημιουργήστε τραπέζια για αυτή την ενότητα
   * Κάθε τραπέζι ανήκει σε αυτή την ενότητα
5. **Χρήση Ενότητας POS**
   * Η ενότητα POS είναι τώρα έτοιμη για χρήση
   * Μπορείτε να κάνετε πωλήσεις μέσω αυτής της ενότητας
