# POS Table Sessions

Η ενότητα **POS Table Sessions** (Συνεδρίες Τραπεζιών POS) σας επιτρέπει να δείτε τις συνεδρίες των τραπεζιών. Κάθε συνεδρία αντιπροσωπεύει μια περίοδο χρήσης ενός τραπεζιού (π.χ. από τις 12:00 έως τις 13:00). Μπορείτε να δείτε βασικές πληροφορίες όπως το τραπέζι, το pos section, την ώρα έναρξης και λήξης, τον τύπο παραστατικού και τον πελάτη που έγινε η χρέωση.  Αυτή η ενότητα είναι κυρίως για ανάγνωση δεδομένων και δεν επιτρέπει τη δημιουργία ή τη διαγραφή συνεδριών.

#### Κουμπιά Ενεργειών

* **Filter:** Κουμπί φιλτραρίσματος
* Δεν υπάρχει κουμπί δημιουργίας (οι συνεδρίες δημιουργούνται αυτόματα)

### Λίστα Συνεδριών Τραπεζιών POS

| Στήλη                 | Περιγραφή                               | Τύπος Δεδομένων |
| --------------------- | --------------------------------------- | --------------- |
| **TABLE NO**          | Ο αριθμός του τραπεζιού                 | Text            |
| **POS SECTION**       | Η ενότητα που ανήκει το τραπέζι         | Text            |
| **SESSION START**     | Η ώρα έναρξης της συνεδρίας             | DateTime        |
| **SESSION END**       | Η ώρα λήξης της συνεδρίας               | DateTime        |
| **ΤΥΠΟΣ ΠΑΡΑΓΓΕΛΙΑΣ** | Ο τύπος της παραγγελίας (ΑΛΠ, ΤΠ, κλπ.) | Text            |
| **CUSTOMER CHARGE**   | Τα στοιχεία του πελάτη ή του δωματίου   | Text            |

Στο κάτω μέρος της λίστας εμφανίζεται ο συνολικός αριθμός των POS Table Sessions.

Δεν υπάρχουν action menus για τις συνεδρίες.

Οι συνεδρίες δημιουργούνται και κλείνονται αυτόματα.
