# Έξτρα

Η ενότητα **Έξτρα (Extras)** χρησιμοποιείται για τον ορισμό και τη διαχείριση των extras που μπορούν να προστεθούν σε μια κράτηση. Τα έξτρα είναι προαιρετικές υπηρεσίες που οι επισκέπτες μπορούν να προσθέσουν στη δική τους κράτηση (π.χ., μεταφορές, ποτά, πρωινό, κλπ.).

<figure><img src="../../../.gitbook/assets/image (82).png" alt=""><figcaption></figcaption></figure>

| Στήλη               | Περιγραφή                                         | Τύπος     |
| ------------------- | ------------------------------------------------- | --------- |
| **ΟΝΟΜΑ**           | Όνομα του έξτρα                                   | Κείμενο   |
| **ΤΙΜΗ**            | Τιμή του έξτρα                                    | Νόμισμα   |
| **ΤΥΠΟΣ ΤΙΜΗΣ**     | Τύπος χρέωσης (Ποσότητα, Ανά Επισκέπτη Ανά Νύχτα) | Κατηγορία |
| **ΚΑΤΗΓΟΡΙΑ ΕΞΤΡΑ** | Κατηγορία που ανήκει το έξτρα                     | Κατηγορία |
| **ΥΠΗΡΕΣΙΑ**        | Υπηρεσία που ανήκει το έξτρα                      | Κατηγορία |
| **ΕΝΕΡΓΟ**          | Κατάσταση ενεργοποίησης                           | Boolean   |

### Κουμπί Ενημέρωσης

* **ΕΝΗΜΕΡΩΣΗ ΕΞΤΡΑ**: Αποθήκευση των αλλαγών



## Ροή Εργασίας

### Δημιουργία Νέου Έξτρα

1. Κάντε κλικ στο κουμπί **"Προσθήκη Έξτρα"** στη σελίδα λίστας
2. Συμπληρώστε τα υποχρεωτικά πεδία:
   * ΟΝΟΜΑ (π.χ., "Spa Treatment")
   * ΤΙΜΗ (π.χ., "50,00 €")
   * ΥΠΗΡΕΣΙΑ (π.χ., "Room")
   * ΤΥΠΟΣ ΧΡΕΩΣΗΣ (π.χ., "Ποσότητα")
   * ΤΥΠΟΣ (π.χ., "Δωμάτιο")
3. Προαιρετικά, συμπληρώστε:
   * ΠΕΡΙΓΡΑΦΗ
   * ΜΕΓΙΣΤΗ ΠΟΣΟΤΗΤΑ
   * ΠΡΟΜΗΘΕΙΑ
   * Φόρους
   * Λογιστικές πληροφορίες
4. Κάντε κλικ στο κουμπί **"ΕΝΗΜΕΡΩΣΗ ΕΞΤΡΑ"** για αποθήκευση

### Επεξεργασία Υπάρχοντος Έξτρα

1. Κάντε κλικ στο κουμπί ενέργειας (⋮) δίπλα στο έξτρα που θέλετε να επεξεργαστείτε
2. Τροποποιήστε τα απαιτούμενα πεδία
3. Κάντε κλικ στο κουμπί **"ΕΝΗΜΕΡΩΣΗ ΕΞΤΡΑ"** για αποθήκευση

### Διαγραφή Έξτρα

1. Κάντε κλικ στο κουμπί ενέργειας (⋮) δίπλα στο έξτρα που θέλετε να διαγράψετε
2. Επιλέξτε την επιλογή διαγραφής από το μενού
