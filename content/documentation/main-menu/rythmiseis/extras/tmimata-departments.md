# Τμήματα (Departments)

Η ενότητα **Τμήματα (Departments)** χρησιμοποιείται για τον καθορισμο και τη διαχείριση των τμημάτων του ξενοδοχείου και για την ομαδοποίηση των υπηρεσιών και των εξόδων για λογιστικούς σκοπούς.

<figure><img src="../../../.gitbook/assets/image (78).png" alt=""><figcaption></figcaption></figure>

## Λίστα Τμημάτων

| Στήλη               | Περιγραφή                                          | Τύπος     |
| ------------------- | -------------------------------------------------- | --------- |
| **ΟΝΟΜΑ**           | Όνομα του τμήματος                                 | Κείμενο   |
| **DEPARTMENT TYPE** | Τύπος τμήματος (Distributed, Undistributed, Other) | Κατηγορία |
| **ΚΩΔΙΚΟΣ**         | Κωδικός αναφοράς του τμήματος                      | Αριθμός   |
| **ΔΙΑΤΑΞΗ**         | Σειρά εμφάνισης                                    | Αριθμός   |

## Φόρμα Δημιουργίας/Επεξεργασίας Τμήματος

<figure><img src="../../../.gitbook/assets/image (79).png" alt=""><figcaption></figcaption></figure>

| Πεδίο               | Τύπος    | Υποχρεωτικό | Περιγραφή                                         |
| ------------------- | -------- | ----------- | ------------------------------------------------- |
| **ΟΝΟΜΑ**           | Κείμενο  | ✓ Ναι       | Όνομα του τμήματος (π.χ., "ROOMS DEPARTMENT")     |
| **ΚΩΔΙΚΟΣ**         | Αριθμός  | ✓ Ναι       | Κωδικός αναφοράς (π.χ., "1")                      |
| **ΔΙΑΤΑΞΗ**         | Αριθμός  | ✗ Όχι       | Σειρά εμφάνισης του τμήματος (προεπιλογή: 0)      |
| **DEPARTMENT TYPE** | Dropdown | ✓ Ναι       | Τύπος τμήματος: Distributed, Undistributed, Other |
| **ΓΟΝΕΑΣ**          | Dropdown | ✗ Όχι       | Γονικό τμήμα (για ιεραρχία τμημάτων)              |

### Τύποι Τμημάτων

* **Distributed**: Το τμήμα θα αποτυπώνεται στα έσοδα του budget (Income Budget)
* **Undistributed**: Το τμήμα θα αποτυπώνεται στα εξοδα του budget (expenses budget)
* **Other**: Το τμήμα θα αποτυπώνεται στα έσοδα του budget (income budget)

### Κουμπί Ενημέρωσης

* **UPDATE DEPARTMENTS**: Αποθήκευση των αλλαγών



## Ροή Εργασίας

### Δημιουργία Νέου Τμήματος

1. Κάντε κλικ στο κουμπί **"Add Department"** στη σελίδα λίστας
2. Συμπληρώστε τα υποχρεωτικά πεδία:
   * ΟΝΟΜΑ (π.χ., "KITCHEN DEPARTMENT")
   * ΚΩΔΙΚΟΣ (π.χ., "7")
   * DEPARTMENT TYPE (επιλέξτε Distributed, Undistributed ή Other)
3. Προαιρετικά, ορίστε:
   * ΔΙΑΤΑΞΗ (σειρά εμφάνισης)
   * ΓΟΝΕΑΣ (γονικό τμήμα)
4. Κάντε κλικ στο κουμπί **"UPDATE DEPARTMENTS"** για αποθήκευση

### Επεξεργασία Υπάρχοντος Τμήματος

1. Κάντε κλικ στο κουμπί ενέργειας (⋮) δίπλα στο τμήμα που θέλετε να επεξεργαστείτε
2. Τροποποιήστε τα απαιτούμενα πεδία
3. Κάντε κλικ στο κουμπί **"UPDATE DEPARTMENTS"** για αποθήκευση

### Διαγραφή Τμήματος

1. Κάντε κλικ στο κουμπί ενέργειας (⋮) δίπλα στο τμήμα που θέλετε να διαγράψετε
2. Επιλέξτε την επιλογή διαγραφής από το μενού
