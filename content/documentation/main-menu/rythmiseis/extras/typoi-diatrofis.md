# Τύποι Διατροφής

Η ενότητα **Τύποι Διατροφής (Board Types)** χρησιμοποιείται για τον ορισμό και τη διαχείριση των διαφόρων τύπων διατροφής που προσφέρονται στο ξενοδοχείο (π.χ., μόνο δωμάτιο, με πρωινό, με όλα τα γεύματα, κλπ.).

<figure><img src="../../../.gitbook/assets/image (84).png" alt=""><figcaption></figcaption></figure>

### Λίστας Τύπων Διατροφής

| Στήλη       | Περιγραφή                            | Τύπος   |
| ----------- | ------------------------------------ | ------- |
| **ONOMA**   | Όνομα του τύπου διατροφής            | Κείμενο |
| **ΚΩΔΙΚΟΣ** | Κωδικός αναφοράς του τύπου διατροφής | Κείμενο |

### Φόρμα Δημιουργίας/Επεξεργασίας Τύπου Διατροφής

<figure><img src="../../../.gitbook/assets/image (85).png" alt=""><figcaption></figcaption></figure>

| Πεδίο       | Τύπος   | Υποχρεωτικό | Περιγραφή                                     |
| ----------- | ------- | ----------- | --------------------------------------------- |
| **ΟΝΟΜΑ**   | Κείμενο | ✓ Ναι       | Όνομα του τύπου διατροφής (π.χ., "Room only") |

Κουμπί: ΕΝΗΜΕΡΩΣΗ ΤΥΠΟΥ ΔΙΑΤΡΟΦΗΣ: Αποθήκευση των αλλαγών

### Προσθήκη έξτρα διατροφής

<figure><img src="../../../.gitbook/assets/image (91).png" alt=""><figcaption></figcaption></figure>

Προσθέτετε την εξτρα διατροφή και το ποσοστό ή το ποσό που αναλογεί από την συνολική τιμή.

### Δημιουργία Νέου Τύπου Διατροφής

1. Κάντε κλικ στο κουμπί **"Προσθήκη Τύπου Διατροφής"** στη σελίδα λίστας
2. Συμπληρώστε τα υποχρεωτικά πεδία:
   * ΟΝΟΜΑ (π.χ., "Breakfast & Dinner")
   * ΚΩΔΙΚΟΣ (π.χ., "BD")
3. Προαιρετικά, προσθέστε έξτρα υπηρεσίες:
   * Κάντε κλικ στο κουμπί **"Προσθήκη Έξτρα Διατροφής"**
   * Επιλέξτε τα έξτρα που θέλετε να προσθέσετε
4. Κάντε κλικ στο κουμπί **"ΕΝΗΜΕΡΩΣΗ ΤΥΠΟΥ ΔΙΑΤΡΟΦΗΣ"** για αποθήκευση

### Επεξεργασία Υπάρχοντος Τύπου Διατροφής

1. Κάντε κλικ στο κουμπί ενέργειας (⋮) δίπλα στον τύπο διατροφής που θέλετε να επεξεργαστείτε
2. Τροποποιήστε τα απαιτούμενα πεδία
3. Προσθέστε ή αφαιρέστε έξτρα υπηρεσίες κατά ανάγκη
4. Κάντε κλικ στο κουμπί **"ΕΝΗΜΕΡΩΣΗ ΤΥΠΟΥ ΔΙΑΤΡΟΦΗΣ"** για αποθήκευση

### Διαγραφή Τύπου Διατροφής

1. Κάντε κλικ στο κουμπί ενέργειας (⋮) δίπλα στον τύπο διατροφής που θέλετε να διαγράψετε
2. Επιλέξτε την επιλογή διαγραφής από το μενού
