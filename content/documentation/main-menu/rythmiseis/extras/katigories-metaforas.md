# Κατηγορίες Μεταφοράς

Η ενότητα **Κατηγορίες Μεταφοράς (Transfer Categories)** χρησιμοποιείται για τον ορισμό και τη διαχείριση των κατηγοριών μεταφορών που προσφέρονται στο ξενοδοχείο. Οι κατηγορίες μεταφοράς ταξινομούν τις διαφορετικές υπηρεσίες μεταφοράς (π.χ., μεταφορές από/προς αεροδρόμιο, μεταφορές που διαρρυθμίζονται μέσω ταξιδιωτικών γραφείων, κλπ.).

### Λίστα Κατηγοριών Μεταφοράς

| Στήλη         | Περιγραφή                       | Τύπος     |
| ------------- | ------------------------------- | --------- |
| **ONOMA**     | Όνομα της κατηγορίας μεταφοράς  | Κείμενο   |
| **ΠΕΡΙΓΡΑΦΗ** | Περιγραφή της κατηγορίας        | Κείμενο   |
| **SERVICE**   | Υπηρεσία που ανήκει η κατηγορία | Κατηγορία |
| **ΕΝΕΡΓΟ**    | Κατάσταση ενεργοποίησης         | Boolean   |

### Φόρμα Δημιουργίας/Επεξεργασίας Κατηγορίας Μεταφοράς

<figure><img src="../../../.gitbook/assets/image (87).png" alt=""><figcaption></figcaption></figure>

| Πεδίο         | Τύπος      | Υποχρεωτικό | Περιγραφή                                                                         |
| ------------- | ---------- | ----------- | --------------------------------------------------------------------------------- |
| **ΟΝΟΜΑ**     | Κείμενο    | ✓ Ναι       | Όνομα της κατηγορίας μεταφοράς (π.χ., "TA Transfer")                              |
| **ENEΡΓΟ**    | Toggle     | ✗ Όχι       | Ενεργοποίηση/Απενεργοποίηση της κατηγορίας (προεπιλογή: ΝΑΙ)                      |
| **ΠΕΡΙΓΡΑΦΗ** | Textarea   | ✗ Όχι       | Λεπτομερής περιγραφή της κατηγορίας (π.χ., "Transfer arranged via Travel Agency") |
| **ΥΠΗΡΕΣΙΑ**  | Dropdown   | ✓ Ναι       | Υπηρεσία που ανήκει η κατηγορία (π.χ., "Ξενοδοχειακές Υπηρεσίες")                 |
| **ΦΟΡΟΙ**     | Checkboxes | ✗ Όχι       | Φόροι που ισχύουν για την κατηγορία (π.χ., "ΦΠΑ 24%", "Δημοτικός Φόρος")          |

Κουμπί: ΕΝΗΜΕΡΩΣΗ ΚΑΤΗΓΟΡΙΑΣ: Αποθήκευση των αλλαγών



### Δημιουργία Νέας Κατηγορίας Μεταφοράς

1. Κάντε κλικ στο κουμπί **"Προσθήκη Κατηγορίας"** στη σελίδα λίστας
2. Συμπληρώστε τα υποχρεωτικά πεδία:
   * ΟΝΟΜΑ (π.χ., "Airport Transfer")
   * ΥΠΗΡΕΣΙΑ (π.χ., "Ξενοδοχειακές Υπηρεσίες")
3. Προαιρετικά, συμπληρώστε:
   * ΠΕΡΙΓΡΑΦΗ (π.χ., "Transfer from/to airport")
   * ΦΟΡΟΙ (επιλέξτε τους κατάλληλους φόρους)
4. Κάντε κλικ στο κουμπί **"ΕΝΗΜΕΡΩΣΗ ΚΑΤΗΓΟΡΙΑΣ"** για αποθήκευση

### Επεξεργασία Υπάρχουσας Κατηγορίας Μεταφοράς

1. Κάντε κλικ στο κουμπί ενέργειας (⋮) δίπλα στην κατηγορία που θέλετε να επεξεργαστείτε
2. Τροποποιήστε τα απαιτούμενα πεδία
3. Κάντε κλικ στο κουμπί **"ΕΝΗΜΕΡΩΣΗ ΚΑΤΗΓΟΡΙΑΣ"** για αποθήκευση

### Διαγραφή Κατηγορίας Μεταφοράς

1. Κάντε κλικ στο κουμπί ενέργειας (⋮) δίπλα στην κατηγορία που θέλετε να διαγράψετε
2. Επιλέξτε την επιλογή διαγραφής από το μενού
