# Υπηρεσίες

Η ενότητα **Υπηρεσίες (Services)** χρησιμοποιείται για τον ορισμό και τη διαχείριση των υπηρεσιών του ξενοδοχείου. Οι υπηρεσίες είναι προϊόντα ή υπηρεσίες που προσφέρονται στους επισκέπτες (π.χ., δωμάτιο, πρωινό, ποτά, κλπ.).

<figure><img src="../../../.gitbook/assets/image (80).png" alt=""><figcaption></figcaption></figure>

| Στήλη                   | Περιγραφή                                                         | Τύπος     |
| ----------------------- | ----------------------------------------------------------------- | --------- |
| **ID**                  | Αναγνωριστικό της υπηρεσίας                                       | Αριθμός   |
| **ΟΝΟΜΑ**               | Όνομα της υπηρεσίας                                               | Κείμενο   |
| **ΤΜΗΜΑ**               | Τμήμα που ανήκει η υπηρεσία                                       | Κατηγορία |
| **ΤΥΠΟΣ**               | Τύπος εσόδων (FBRevenue, StayRevenue, FeesRevenue, ExtrasRevenue) | Κατηγορία |
| **ACCOUNTING CATEGORY** | Κατηγορία λογιστικής                                              | Κατηγορία |
| **ΕΝΕΡΓΟ**              | Κατάσταση ενεργοποίησης                                           | Boolean   |

## Φόρμα Δημιουργίας/Επεξεργασίας Υπηρεσίας

<figure><img src="../../../.gitbook/assets/image (81).png" alt=""><figcaption></figcaption></figure>

| Πεδίο                                 | Τύπος    | Υποχρεωτικό | Περιγραφή                                                   |
| ------------------------------------- | -------- | ----------- | ----------------------------------------------------------- |
| **ΟΝΟΜΑ**                             | Κείμενο  | ✓ Ναι       | Όνομα της υπηρεσίας (π.χ., "Beverage")                      |
| **ENEΡΓΟ**                            | Toggle   | ✗ Όχι       | Ενεργοποίηση/Απενεργοποίηση της υπηρεσίας (προεπιλογή: ΝΑΙ) |
| **ΠΕΡΙΓΡΑΦΗ**                         | Κείμενο  | ✗ Όχι       | Περιγραφή της υπηρεσίας                                     |
| **DEPARTMENT**                        | Dropdown | ✓ Ναι       | Τμήμα που ανήκει η υπηρεσία                                 |
| **REVENUE TYPE**                      | Dropdown | ✓ Ναι       | Τύπος εσόδων (FB, Stay, Fees, Extras)                       |
| **ACCOUNTING CATEGORY**               | Dropdown | ✗ Όχι       | Κατηγορία λογιστικής                                        |
| **ACCOUNTING COMPLIMENTARY CATEGORY** | Dropdown | ✗ Όχι       | Κατηγορία λογιστικής για δωρεάν υπηρεσίες                   |
| **FISCAL CODE**                       | Κείμενο  | ✗ Όχι       | Κωδικός φορολογίας                                          |

| **ΔΙΑΤΑΞΗ**                           | Αριθμός  | ✗ Όχι       | Σειρά εμφάνισης (προεπιλογή: 0)                             |

### Κουμπί Ενημέρωσης

* **ΕΝΗΜΕΡΩΣΗ ΥΠΗΡΕΣΙΑΣ**: Αποθήκευση των αλλαγών

## Ροή Εργασίας

### Δημιουργία Νέας Υπηρεσίας

1. Κάντε κλικ στο κουμπί **"Προσθήκη Υπηρεσίας"** στη σελίδα λίστας
2. Συμπληρώστε τα υποχρεωτικά πεδία:
   * ΟΝΟΜΑ (π.χ., "Spa Services")
   * DEPARTMENT (π.χ., "OTHER OPERATING DEPARTMENTS")
   * REVENUE TYPE (π.χ., "Extras")
   * SERVICE TYPE (π.χ., "Services")
3. Προαιρετικά, συμπληρώστε:
   * ΠΕΡΙΓΡΑΦΗ
   * ACCOUNTING CATEGORY
   * FISCAL CODE
   * EXTERNAL CODE
4. Κάντε κλικ στο κουμπί **"ΕΝΗΜΕΡΩΣΗ ΥΠΗΡΕΣΙΑΣ"** για αποθήκευση

### Επεξεργασία Υπάρχουσας Υπηρεσίας

1. Κάντε κλικ στο κουμπί ενέργειας (⋮) δίπλα στην υπηρεσία που θέλετε να επεξεργαστείτε
2. Τροποποιήστε τα απαιτούμενα πεδία
3. Κάντε κλικ στο κουμπί **"ΕΝΗΜΕΡΩΣΗ ΥΠΗΡΕΣΙΑΣ"** για αποθήκευση

### Διαγραφή Υπηρεσίας

1. Κάντε κλικ στο κουμπί ενέργειας (⋮) δίπλα στην υπηρεσία που θέλετε να διαγράψετε
2. Επιλέξτε την επιλογή διαγραφής από το μενού
