### Γενικές παρατηρήσεις

{% hint style="danger" %}
Τα περισσότερα τερματικά απαιτούν την **σύνδεση στο MIDDLEWARE** ώστε να μπορέσουν να δεχθούν συναλλαγή από το ERP
{% endhint %}

{% hint style="info" %}
Κατά την αρχική παραμετροποίηση τα τερματικά πολλές φορές χρειάζονται εντολή από το ERP ώστε να συνεχίσουν. Στην περίπτωση αυτή δημιουργούμε μια πληρωμή.
{% endhint %}
