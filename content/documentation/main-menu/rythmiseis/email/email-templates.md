# Email Templates

## Περιγραφή Ενότητας

Η ενότητα **Email Templates** σας επιτρέπει να δημιουργήσετε και να διαχειριστείτε τα πρότυπα email που αποστέλλονται στους πελάτες σας. Κάθε πρότυπο email μπορεί να προσαρμοστεί με διαφορετικές γλώσσες, περιεχόμενο και ρυθμίσεις αποστολής. Τα πρότυπα email χωρίζονται σε δύο κατηγορίες: **Transactional** που στέλνονται μετά από κάποια ενέργεια του χρήστη και Scheduled που είναι προγραμματισμένα να στέλνονται αυτόματα σε προκαθορισμένο χρόνο σε σχέση με την κράτηση.&#x20;

<figure><img src="../../../.gitbook/assets/image (72).png" alt=""><figcaption></figcaption></figure>

### Λίστα Email Templates

| Στήλη           | Περιγραφή                                   | Τύπος Δεδομένων           |
| --------------- | ------------------------------------------- | ------------------------- |
| **EMAIL TYPE**  | Όνομα και περιγραφή του προτύπου email      | Text                      |
| **SCHEDULE**    | Τύπος αποστολής (Transactional ή Scheduled) | Text                      |
| **ΕΝΕΡΓΟ**      | Κατάσταση ενεργοποίησης                     | Boolean (ACTIVE/INACTIVE) |
| **Action Menu** | Ενέργειες (Edit/Delete)                     | Dropdown                  |

Σύνολο Εγγραφών: Εμφανίζεται στο κάτω μέρος (π.χ. "TOTAL EMAILS: 12")

Κάθε γραμμή στον πίνακα διαθέτει ένα action menu που περιέχει:

* **Edit:** Ανοίγει τη φόρμα επεξεργασίας του προτύπου
* **Delete:** Διαγράφει το πρότυπο (με επιβεβαίωση)

## Φόρμα Δημιουργίας/Επεξεργασίας Email Template

Η φόρμα περιέχει πολλές ενότητες και επιλογές:

1. **Βασικές Πληροφορίες (Basic Details)**
2. **Περιεχόμενο Email (Email Content)**
3. **Επιπλέον Πληροφορίες (Extra Details)**
4. **Προγραμματισμένο Email (Scheduled Email)** - Για Scheduled emails

{% hint style="info" %}
Το κάθε email template μπορεί να έχει κάποια επιπλέον πεδία ρύθμισης ανά ενότητα όπως για παράδειγμα τίτλο, υπότιτλο, ρυθμίσεις εφαρμογής και άλλα. Τα πεδία αυτά έχουν προστεθεί από την ομάδα υλοποίησης του hotelizer.
{% endhint %}

## Κατηγορίες Email Templates

### Transactional Emails

Αποστέλλονται αμέσως ως απόκριση σε μια ενέργεια του χρήστη.

| Email                           | Περιγραφή                | Πότε Αποστέλλεται                    |
| ------------------------------- | ------------------------ | ------------------------------------ |
| **Booking Confirmation**        | Επιβεβαίωση κράτησης     | Αμέσως μετά τη δημιουργία κράτησης   |
| **Booking Pre-confirmation**    | Προ-επιβεβαίωση κράτησης | Αμέσως μετά τη δημιουργία κράτησης   |
| **Cancellation Email**          | Επιβεβαίωση ακύρωσης     | Αμέσως μετά την ακύρωση κράτησης     |
| **Invoice email**               | Τιμολόγιο                | Όταν αποστέλλεται τιμολόγιο          |
| **Offer email**                 | Email προσφοράς          | Όταν αποστέλλεται προσφορά           |
| **Payment Link**                | Σύνδεσμος πληρωμής       | Όταν αποστέλλεται σύνδεσμος πληρωμής |
| **Payment transaction receipt** | Απόδειξη πληρωμής        | Αμέσως μετά τη πληρωμή               |

### Scheduled Emails

Αποστέλλονται σε προγραμματισμένη ώρα πριν ή μετά από ένα συμβάν.

| Email               | Περιγραφή       | Πότε Αποστέλλεται                 |
| ------------------- | --------------- | --------------------------------- |
| **Online check-in** | Online check-in | 1 ημέρα πριν την άφιξη            |
| **Pre-arrival**     | Προ-άφιξης      | Πριν την άφιξη (προσαρμόσιμο)     |
| **Post-stay**       | Μετα-διαμονής   | Μετά την αναχώρηση (προσαρμόσιμο) |

## Λειτουργίες & Ενέργειες

### Αναζήτηση Email Template

1. Πληκτρολογήστε το όνομα του προτύπου στο πεδίο αναζήτησης
2. Το σύστημα φιλτράρει αυτόματα τα αποτελέσματα

### Επεξεργασία Email Template

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Τροποποιήστε τα επιθυμητά πεδία
4. Κάντε κλικ στο κουμπί "UPDATE EMAIL"

### Προσθήκη Merge Tag

1. Τοποθετήστε τον κέρσορα στο σημείο όπου θέλετε να προσθέσετε το merge tag
2. Κάντε κλικ στο κουμπί "Insert merge tag"
3. Επιλέξτε το merge tag από τη λίστα
4. Το merge tag θα προστεθεί στο περιεχόμενο

### Προσθήκη Γλώσσας

1. Κάντε κλικ στο κουμπί "+" δίπλα στις γλώσσες
2. Επιλέξτε τη γλώσσα που θέλετε να προσθέσετε
3. Συμπληρώστε το SUBJECT και ΠΕΡΙΕΧΟΜΕΝΟ για τη νέα γλώσσα
4. Κάντε κλικ στο κουμπί "UPDATE EMAIL"

### Αφαίρεση Γλώσσας

1. Κάντε κλικ στο κουμπί "X" δίπλα στη γλώσσα που θέλετε να αφαιρέσετε
2. Επιβεβαιώστε την αφαίρεση
3. Κάντε κλικ στο κουμπί "UPDATE EMAIL"

### Ενεργοποίηση/Απενεργοποίηση Email Template

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Χρησιμοποιήστε το toggle **ΕΝΕΡΓΟ** για να ενεργοποιήσετε ή να απενεργοποιήσετε το πρότυπο
4. Κάντε κλικ στο κουμπί "UPDATE EMAIL"

### Διαγραφή Email Template

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Delete"
3. Επιβεβαιώστε τη διαγραφή
