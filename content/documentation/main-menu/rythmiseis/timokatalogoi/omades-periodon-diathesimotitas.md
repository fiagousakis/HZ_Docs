# Ομάδες Περιόδων Διαθεσιμότητας

Η ενότητα **Ομάδες Περιόδων Διαθεσιμότητας** (Availability Period Groups) σας επιτρέπει να δημιουργήσετε και να διαχειριστείτε ομάδες περιόδων διαθεσιμότητας. Κάθε ομάδα είναι μια συλλογή περιόδων διαθεσιμότητας που χρησιμοποιούνται για την οργάνωση και τη διαχείριση της διαθεσιμότητας δωματίων.

<figure><img src="../../../.gitbook/assets/Screenshot 2026-05-13 132347.jpg" alt=""><figcaption></figcaption></figure>

**Κουμπιά Ενεργειών**

* **Filter:** Κουμπί φιλτραρίσματος
* **Προσθήκη Ομάδας:** Δημιουργία νέας ομάδας περιόδων διαθεσιμότητας

#### Λίστα Ομάδων Περιόδων Διαθεσιμότητας

| Στήλη              | Περιγραφή                      | Τύπος Δεδομένων   |
| ------------------ | ------------------------------ | ----------------- |
| **ΟΝΟΜΑ**          | Το όνομα της ομάδας            | Text              |
| **ΠΡΟΚΑΘΟΡΙΣΜΕΝΟ** | Ορισμός ως προεπιλεγμένη ομάδα | Boolean (ΝΑΙ/ΟΧΙ) |
| **ΕΝΕΡΓΟ**         | Κατάσταση ενεργοποίησης        | Boolean (ΝΑΙ/ΟΧΙ) |
| **Action Menu**    | Ενέργειες (Edit/Delete)        | Dropdown          |

Στο κάτω μέρος της λίστας εμφανίζεται ο συνολικός αριθμός των ομάδων περιοδως διαθεσιμότητας (TOTAL AVAILABILITY PERIOD GROUPS).

Κάθε γραμμή στον πίνακα διαθέτει ένα action menu που περιέχει:

* **Edit:** Ανοίγει τη φόρμα επεξεργασίας της ομάδας
* **Delete:** Διαγράφει την ομάδα (με επιβεβαίωση)

### Φόρμα Δημιουργίας/Επεξεργασίας Ομάδας Περιόδων Διαθεσιμότητας

| Πεδίο              | Περιγραφή                      | Τύπος         | Υποχρεωτικό | Παράδειγμα                              |
| ------------------ | ------------------------------ | ------------- | ----------- | --------------------------------------- |

#### Κουμπιά Ενεργειών

* **ΕΝΗΜΕΡΩΣΗ ΟΜΑΔΑΣ:** Αποθήκευση αλλαγών σε υπάρχουσα ομάδα
* **ΔΗΜΙΟΥΡΓΙΑ ΟΜΑΔΑΣ:** Δημιουργία νέας ομάδας (εμφανίζεται μόνο σε νέα εγγραφή)

***

### Λειτουργίες & Ενέργειες

#### Αναζήτηση Ομάδας Περιόδων Διαθεσιμότητας

1. Πληκτρολογήστε το όνομα της ομάδας στο πεδίο αναζήτησης
2. Το σύστημα φιλτράρει αυτόματα τα αποτελέσματα

#### Φιλτράρισμα

1. Κάντε κλικ στο κουμπί "Filter"
2. Επιλέξτε τα κριτήρια φιλτραρίσματος (π.χ. Ενεργές ομάδες, Προεπιλεγμένες)
3. Εφαρμόστε τα φίλτρα

#### Δημιουργία Νέας Ομάδας Περιόδων Διαθεσιμότητας

1. Κάντε κλικ στο κουμπί "Προσθήκη Ομάδας"
2. Συμπληρώστε το **ΟΝΟΜΑ** της ομάδας
3. Ενεργοποιήστε ή απενεργοποιήστε τα toggles **ΕΝΕΡΓΟ** και **ΠΡΟΚΑΘΟΡΙΣΜΕΝΟ**
4. Κάντε κλικ στο κουμπί "ΔΗΜΙΟΥΡΓΙΑ ΟΜΑΔΑΣ"

#### Επεξεργασία Υπάρχουσας Ομάδας Περιόδων Διαθεσιμότητας

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Τροποποιήστε τα επιθυμητά πεδία
4. Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΟΜΑΔΑΣ"

#### Διαγραφή Ομάδας Περιόδων Διαθεσιμότητας

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Delete"
3. Επιβεβαιώστε τη διαγραφή

#### Ενεργοποίηση/Απενεργοποίηση Ομάδας

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Χρησιμοποιήστε το toggle **ΕΝΕΡΓΟ** για να ενεργοποιήσετε ή να απενεργοποιήσετε την ομάδα
4. Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΟΜΑΔΑΣ"

#### Ορισμός ως Προεπιλεγμένη Ομάδα

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Ενεργοποιήστε το toggle **ΠΡΟΚΑΘΟΡΙΣΜΕΝΟ**
4. Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΟΜΑΔΑΣ"

### Σημαντικές Σημειώσεις

* **Μοναδικότητα Ονόματος:** Κάθε ομάδα περιόδων διαθεσιμότητας πρέπει να έχει ένα μοναδικό όνομα
* **Υποχρεωτικά Πεδία:** ΟΝΟΜΑ
* **Προεπιλεγμένη Ομάδα:** Μόνο μια ομάδα μπορεί να είναι προεπιλεγμένη
* **Ενεργές Ομάδες:** Μόνο οι ενεργές ομάδες εμφανίζονται κατά τη δημιουργία περιόδων διαθεσιμότητας
* **Σχέση με Περιόδους:** Κάθε περίοδος διαθεσιμότητας ανήκει σε μια ομάδα
* **Διαγραφή:** Δεν μπορείτε να διαγράψετε μια ομάδα εάν περιέχει ενεργές περιόδους διαθεσιμότητας

### Συχνές Ερωτήσεις

#### Ερώτηση: Τι είναι η διαφορά μεταξύ ομάδων περιόδων και περιόδων διαθεσιμότητας;

**Απάντηση:** Οι ομάδες περιόδων είναι συλλογές που χρησιμοποιούνται για την οργάνωση των περιόδων διαθεσιμότητας, ενώ οι περίοδοι διαθεσιμότητας είναι ατομικές περίοδοι που ορίζουν τη διαθεσιμότητα για ένα συγκεκριμένο τύπο δωματίου.

#### Ερώτηση: Μπορώ να αλλάξω το όνομα μιας ομάδας μετά τη δημιουργία;

**Απάντηση:** Ναι, μπορείτε να αλλάξετε το όνομα επεξεργάζοντας την ομάδα.

#### Ερώτηση: Τι συμβαίνει αν διαγράψω μια ομάδα που περιέχει περιόδους;

**Απάντηση:** Δεν θα μπορέσετε να διαγράψετε την ομάδα εάν περιέχει ενεργές περιόδους διαθεσιμότητας. Θα πρέπει πρώτα να διαγράψετε ή να τροποποιήσετε τις περιόδους.

#### Ερώτηση: Τι είναι η προεπιλεγμένη ομάδα;

**Απάντηση:** Η προεπιλεγμένη ομάδα είναι η ομάδα που επιλέγεται αυτόματα κατά τη δημιουργία νέας περιόδου διαθεσιμότητας. Αυτό απλοποιεί τη διαδικασία δημιουργίας.

### Παράδειγμα Ροής Δημιουργίας

#### Βήμα 1: Δημιουργία Ομάδας Περιόδων Διαθεσιμότητας

1. Κάντε κλικ στο κουμπί "Προσθήκη Ομάδας"
2. Συμπληρώστε το όνομα: "PMS Availability"
3. Ενεργοποιήστε τα toggles **ΕΝΕΡΓΟ** και **ΠΡΟΚΑΘΟΡΙΣΜΕΝΟ**
4. Κάντε κλικ στο κουμπί "ΔΗΜΙΟΥΡΓΙΑ ΟΜΑΔΑΣ"

#### Βήμα 2: Δημιουργία Περιόδων Διαθεσιμότητας

1. Πηγαίνετε στην ενότητα "Περίοδοι Διαθεσιμότητας"
2. Κάντε κλικ στο κουμπί "Προσθήκη Περιόδου"
3. Συμπληρώστε τα στοιχεία της περιόδου
4. Επιλέξτε την ομάδα "PMS Availability"
5. Κάντε κλικ στο κουμπί "ΔΗΜΙΟΥΡΓΙΑ ΠΕΡΙΟΔΟΥ"

#### Βήμα 3: Χρήση σε Σχέδια Τιμών

1. Πηγαίνετε στην ενότητα "Σχέδια Τιμών"
2. Δημιουργήστε ή επεξεργαστείτε ένα σχέδιο τιμών
3. Επιλέξτε την ομάδα "PMS Availability"
4. Αποθηκεύστε το σχέδιο τιμών
