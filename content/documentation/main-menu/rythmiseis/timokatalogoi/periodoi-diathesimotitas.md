# Περίοδοι Διαθεσιμότητας

Η ενότητα **Περίοδοι Διαθεσιμότητας** (Availability Periods) σας επιτρέπει να δημιουργήσετε και να διαχειριστείτε περιόδους διαθεσιμότητας για κάθε τύπο δωματίου. Κάθε περίοδος διαθεσιμότητας καθορίζει τον αριθμό των διαθέσιμων δωματίων για ένα συγκεκριμένο τύπο δωματίου και μια συγκεκριμένη χρονική περίοδο.

**Κουμπιά Ενεργειών**

* **Προσθήκη Περιόδου:** Δημιουργία νέας περιόδου διαθεσιμότητας

#### Λίστα Περιόδων Διαθεσιμότητας

| Στήλη              | Περιγραφή                            | Τύπος Δεδομένων |
| ------------------ | ------------------------------------ | --------------- |
| **ΟΝΟΜΑ**          | Το όνομα της περιόδου διαθεσιμότητας | Text            |
| **ΤΥΠΟΣ ΔΩΜΑΤΙΟΥ** | Ο τύπος δωματίου                     | Text            |
| **ΔΙΑΘΕΣΙΜΟΤΗΤΑ**  | Ο αριθμός των διαθέσιμων δωματίων    | Number          |
| **ΕΝΕΡΓΟ**         | Κατάσταση ενεργοποίησης              | Boolean         |
| **Action Menu**    | Ενέργειες (Edit/Delete)              | Dropdown        |

Κάθε γραμμή στον πίνακα διαθέτει ένα action menu που περιέχει:

* **Edit:** Ανοίγει τη φόρμα επεξεργασίας της περιόδου διαθεσιμότητας
* **Delete:** Διαγράφει την περίοδο διαθεσιμότητας (με επιβεβαίωση)

### Λειτουργίες & Ενέργειες

#### Αναζήτηση Περιόδου Διαθεσιμότητας

1. Πληκτρολογήστε το όνομα της περιόδου στο πεδίο αναζήτησης
2. Το σύστημα φιλτράρει αυτόματα τα αποτελέσματα

#### Δημιουργία Νέας Περιόδου Διαθεσιμότητας

1. Κάντε κλικ στο κουμπί "Προσθήκη Περιόδου"
2. Συμπληρώστε τα υποχρεωτικά πεδία (ΟΝΟΜΑ, ΤΥΠΟΣ ΔΩΜΑΤΙΟΥ, ΟΜΑΔΑ ΠΕΡΙΟΔΩΝ)
3. Ορίστε τις ημερομηνίες ισχύος
4. Κάντε κλικ στο κουμπί "ΔΗΜΙΟΥΡΓΙΑ ΠΕΡΙΟΔΟΥ"

#### Επεξεργασία Υπάρχουσας Περιόδου Διαθεσιμότητας

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Τροποποιήστε τα επιθυμητά πεδία
4. Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΠΕΡΙΟΔΟΥ"

#### Διαγραφή Περιόδου Διαθεσιμότητας

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Delete"
3. Επιβεβαιώστε τη διαγραφή

#### Ενεργοποίηση/Απενεργοποίηση Περιόδου

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Χρησιμοποιήστε το toggle **ΕΝΕΡΓΟ** για να ενεργοποιήσετε ή να απενεργοποιήσετε την περίοδο
4. Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΠΕΡΙΟΔΟΥ"

### Συχνές Ερωτήσεις

#### Ερώτηση: Τι είναι η διαφορά μεταξύ περιόδων διαθεσιμότητας και ομάδων περιόδων;

**Απάντηση:** Οι περίοδοι διαθεσιμότητας είναι ατομικές περίοδοι που ορίζουν τη διαθεσιμότητα για ένα συγκεκριμένο τύπο δωματίου, ενώ οι ομάδες περιόδων είναι συλλογές περιόδων που χρησιμοποιούνται για την οργάνωση.

#### Ερώτηση: Μπορώ να αλλάξω τον τύπο δωματίου μετά τη δημιουργία;

**Απάντηση:** Ναι, μπορείτε να αλλάξετε τον τύπο δωματίου επεξεργάζοντας την περίοδο διαθεσιμότητας.

#### Ερώτηση: Τι συμβαίνει αν δεν ορίσω ημερομηνίες;

**Απάντηση:** Εάν δεν ορίσετε ημερομηνίες, η περίοδος διαθεσιμότητας θα ισχύει για όλο το έτος.

#### Ερώτηση: Πόσες περίοδοι διαθεσιμότητας μπορώ να δημιουργήσω;

**Απάντηση:** Δεν υπάρχει όριο στον αριθμό των περιόδων διαθεσιμότητας που μπορείτε να δημιουργήσετε.
