# Rate Types

Η ενότητα **Τύποι Τιμών** (Rate Types) σας επιτρέπει να δημιουργήσετε και να διαχειριστείτε διαφορετικούς τύπους τιμοκαταλόγων. Κάθε τύπος τιμών αποτελεί μια κατηγορία που χρησιμοποιείται για την ταξινόμηση των σχεδίων τιμών (π.χ. Contracts, Offline rates, Day use).

<figure><img src="../../../.gitbook/assets/Screenshot 2026-05-13 130922.jpg" alt=""><figcaption></figcaption></figure>

**Κουμπιά Ενεργειών**

* **Add Rate Type:** Δημιουργία νέου τύπου τιμών

#### Λίστα Τύπων Τιμών

| Στήλη                   | Περιγραφή                | Τύπος Δεδομένων   |
| ----------------------- | ------------------------ | ----------------- |
| **ΟΝΟΜΑ**               | Το όνομα του τύπου τιμών | Text              |
| **ΤΥΠΟΣ ΤΙΜΟΚΑΤΑΛΟΓΟΥ** | Η κατηγορία του τύπου    | Text              |
| **ΕΝΕΡΓΟ**              | Κατάσταση ενεργοποίησης  | Boolean (ΝΑΙ/ΟΧΙ) |
| **Action Menu**         | Ενέργειες (Edit/Delete)  | Dropdown          |

Στο κάτω μέρας της λίστας εμφανίζεται το Σύνολο Εγγραφών (π.χ. "Σύνολο 25 τύποι")

Κάθε γραμμή στον πίνακα διαθέτει ένα action menu που περιέχει:

* **Edit:** Ανοίγει τη φόρμα επεξεργασίας του τύπου τιμών
* **Delete:** Διαγράφει τον τύπο τιμών (με επιβεβαίωση)

### Φόρμα Δημιουργίας/Επεξεργασίας Τύπου Τιμών

<figure><img src="../../../.gitbook/assets/Screenshot 2026-05-13 131025.jpg" alt=""><figcaption></figcaption></figure>

#### Ενότητα: Βασικές Πληροφορίες

| Πεδίο                   | Περιγραφή                         | Τύπος         | Υποχρεωτικό | Παράδειγμα                              |
| ----------------------- | --------------------------------- | ------------- | ----------- | --------------------------------------- |
| **ΟΝΟΜΑ**               | Το όνομα του τύπου τιμών          | Text Input    | **ΝΑΙ**     | "Contracts", "Offline rates", "Day use" |
| **ΤΥΠΟΣ ΤΙΜΟΚΑΤΑΛΟΓΟΥ** | Η κατηγορία του τύπου (read-only) | Dropdown      | **ΝΑΙ**     | "contracts", "offline", "other"         |
| **ΕΝΕΡΓΟ**              | Κατάσταση ενεργοποίησης           | Toggle Switch | Όχι         | ΝΑΙ / ΟΧΙ                               |

#### Κουμπιά Ενεργειών

* **UPDATE RATE TYPE:** Αποθήκευση αλλαγών σε υπάρχοντα τύπο τιμών
* **CREATE RATE TYPE:** Δημιουργία νέου τύπου τιμών (εμφανίζεται μόνο σε νέα εγγραφή)

### Λειτουργίες & Ενέργειες

#### Αναζήτηση Τύπου Τιμών

1. Πληκτρολογήστε το όνομα του τύπου τιμών στο πεδίο αναζήτησης
2. Το σύστημα φιλτράρει αυτόματα τα αποτελέσματα

#### Δημιουργία Νέου Τύπου Τιμών

1. Κάντε κλικ στο κουμπί "Add Rate Type"
2. Συμπληρώστε το **ΟΝΟΜΑ** του τύπου τιμών
3. Επιλέξτε τον **ΤΥΠΟΣ ΤΙΜΟΚΑΤΑΛΟΓΟΥ** από τη λίστα
4. Ενεργοποιήστε ή απενεργοποιήστε το toggle **ΕΝΕΡΓΟ**
5. Κάντε κλικ στο κουμπί "CREATE RATE TYPE"

#### Επεξεργασία Υπάρχοντος Τύπου Τιμών

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Τροποποιήστε τα επιθυμητά πεδία
4. Κάντε κλικ στο κουμπί "UPDATE RATE TYPE"

#### Διαγραφή Τύπου Τιμών

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Delete"
3. Επιβεβαιώστε τη διαγραφή

#### Ενεργοποίηση/Απενεργοποίηση Τύπου Τιμών

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Χρησιμοποιήστε το toggle **ΕΝΕΡΓΟ** για να ενεργοποιήσετε ή να απενεργοποιήσετε τον τύπο
4. Κάντε κλικ στο κουμπί "UPDATE RATE TYPE"
