# Housekeeping Maids

Η ενότητα **Υπαλλήλοι Καθαριότητας** (Housekeeping Maids) σας επιτρέπει να δημιουργήσετε και να διαχειριστείτε τα προφίλ των υπαλλήλων καθαριότητας που εργάζονται στο ξενοδοχείο. Κάθε υπάλληλος καθαριότητας μπορεί να εκχωρηθεί σε σχέδια καθαριότητας και να εκτελέσει τις υπηρεσίες καθαριότητας.

**Κουμπιά Ενεργειών**

* **Filter:** Κουμπί φιλτραρίσματος
* **Add Housekeeping Maid:** Δημιουργία νέου υπαλλήλου καθαριότητας

#### Λίστα Υπαλλήλων Καθαριότητας

| Στήλη           | Περιγραφή                           | Τύπος Δεδομένων |
| --------------- | ----------------------------------- | --------------- |
| **ΟΝΟΜΑ**       | Το όνομα του υπαλλήλου καθαριότητας | Text            |
| **Action Menu** | Ενέργειες (Edit/Delete)             | Dropdown        |

Κάθε γραμμή στον πίνακα διαθέτει ένα action menu που περιέχει:

* **Edit:** Ανοίγει τη φόρμα επεξεργασίας του υπαλλήλου
* **Delete:** Διαγράφει τον υπάλληλο (με επιβεβαίωση)

### Φόρμα Δημιουργίας/Επεξεργασίας Υπαλλήλου Καθαριότητας

<figure><img src="../../../.gitbook/assets/Screenshot 2026-05-13 150857.jpg" alt=""><figcaption></figcaption></figure>

| Πεδίο       | Περιγραφή                                         | Τύπος           | Υποχρεωτικό | Παράδειγμα                |
| ----------- | ------------------------------------------------- | --------------- | ----------- | ------------------------- |
| **ΟΝΟΜΑ**   | Το όνομα του υπαλλήλου καθαριότητας               | Text Input      | **ΝΑΙ**     | "Maid 1", "Maria", "John" |
| **ΕΝΕΡΓΟ**  | Κατάσταση ενεργοποίησης                           | Toggle Switch   | Όχι         | ΝΑΙ / ΟΧΙ                 |
| **ΧΡΗΣΤΗΣ** | Χρήστης συστήματος που σχετίζεται με τον υπάλληλο | Dropdown Search | Όχι         | "User 1", "Maria User"    |

#### Κουμπιά Ενεργειών

* **UPDATE MAID:** Αποθήκευση αλλαγών σε υπάρχον υπάλληλο
* **CREATE MAID:** Δημιουργία νέου υπαλλήλου (εμφανίζεται μόνο σε νέα εγγραφή)

### Λειτουργίες & Ενέργειες

#### Αναζήτηση Υπαλλήλου Καθαριότητας

1. Πληκτρολογήστε το όνομα του υπαλλήλου στο πεδίο αναζήτησης
2. Το σύστημα φιλτράρει αυτόματα τα αποτελέσματα

#### Φιλτράρισμα

1. Κάντε κλικ στο κουμπί "Filter"
2. Επιλέξτε τα κριτήρια φιλτραρίσματος (π.χ. Ενεργοί υπάλληλοι)
3. Εφαρμόστε τα φίλτρα

#### Δημιουργία Νέου Υπαλλήλου Καθαριότητας

1. Κάντε κλικ στο κουμπί "Add Housekeeping Maid"
2. Συμπληρώστε το υποχρεωτικό πεδίο (ΟΝΟΜΑ)
3. Ενεργοποιήστε ή απενεργοποιήστε το toggle **ΕΝΕΡΓΟ**
4. Επιλέξτε έναν χρήστη (προαιρετικό)
5. Κάντε κλικ στο κουμπί "CREATE MAID"

#### Επεξεργασία Υπάρχοντος Υπαλλήλου Καθαριότητας

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Τροποποιήστε τα επιθυμητά πεδία
4. Κάντε κλικ στο κουμπί "UPDATE MAID"

#### Διαγραφή Υπαλλήλου Καθαριότητας

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Delete"
3. Επιβεβαιώστε τη διαγραφή

#### Ενεργοποίηση/Απενεργοποίηση Υπαλλήλου

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Χρησιμοποιήστε το toggle **ΕΝΕΡΓΟ** για να ενεργοποιήσετε ή να απενεργοποιήσετε τον υπάλληλο
4. Κάντε κλικ στο κουμπί "UPDATE MAID"

#### Σύνδεση Υπαλλήλου με Χρήστη

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Κάντε κλικ στο πεδίο "ΧΡΗΣΤΗΣ"
4. Αναζητήστε και επιλέξτε τον χρήστη
5. Κάντε κλικ στο κουμπί "UPDATE MAID"
