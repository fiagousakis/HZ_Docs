# Υπηρεσίες Καθαριότητας

Η ενότητα **Υπηρεσίες Καθαριότητας** (Housekeeping Services) σας επιτρέπει να δημιουργήσετε και να διαχειριστείτε τις διάφορες υπηρεσίες καθαριότητας που προσφέρει το ξενοδοχείο. Κάθε υπηρεσία καθαριότητας αποτελεί μια ξεχωριστή εργασία που μπορεί να εκχωρηθεί σε σχέδια καθαριότητας και να εκτελεστεί από το προσωπικό καθαριότητας.

**Κουμπιά Ενεργειών**

* **Filter:** Κουμπί φιλτραρίσματος
* **Προσθήκη Υπηρεσίας:** Δημιουργία νέας υπηρεσίας καθαριότητας

#### Λίστα Υπηρεσιών Καθαριότητας

| Στήλη             | Περιγραφή                           | Τύπος Δεδομένων   |
| ----------------- | ----------------------------------- | ----------------- |
| **ΟΝΟΜΑ**         | Το όνομα της υπηρεσίας καθαριότητας | Text              |
| **ΣΥΝΤΟΜΟ ΟΝΟΜΑ** | Σύντομη ονομασία για αναφορές       | Text              |
| **ΕΝΕΡΓΟ**        | Κατάσταση ενεργοποίησης             | Boolean (ΝΑΙ/ΟΧΙ) |
| **ΧΡΩΜΑ**         | Χρώμα κωδικοποίησης                 | Color             |
| **Action Menu**   | Ενέργειες (Edit/Delete)             | Dropdown          |

Κάθε γραμμή στον πίνακα διαθέτει ένα action menu που περιέχει:

* **Edit:** Ανοίγει τη φόρμα επεξεργασίας της υπηρεσίας
* **Delete:** Διαγράφει την υπηρεσία (με επιβεβαίωση)

#### Κουμπιά Ενεργειών

* **ΕΝΗΜΕΡΩΣΗ ΥΠΗΡΕΣΙΑΣ:** Αποθήκευση αλλαγών σε υπάρχουσα υπηρεσία
* **ΔΗΜΙΟΥΡΓΙΑ ΥΠΗΡΕΣΙΑΣ:** Δημιουργία νέας υπηρεσίας (εμφανίζεται μόνο σε νέα εγγραφή)

### Λειτουργίες & Ενέργειες

#### Αναζήτηση Υπηρεσίας Καθαριότητας

1. Πληκτρολογήστε το όνομα της υπηρεσίας στο πεδίο αναζήτησης
2. Το σύστημα φιλτράρει αυτόματα τα αποτελέσματα

#### Φιλτράρισμα

1. Κάντε κλικ στο κουμπί "Filter"
2. Επιλέξτε τα κριτήρια φιλτραρίσματος (π.χ. Ενεργές υπηρεσίες)
3. Εφαρμόστε τα φίλτρα

#### Δημιουργία Νέας Υπηρεσίας Καθαριότητας

1. Κάντε κλικ στο κουμπί "Προσθήκη Υπηρεσίας"
2. Συμπληρώστε τα υποχρεωτικά πεδία (ΟΝΟΜΑ, ΣΥΝΤΟΜΟ ΟΝΟΜΑ)
3. Προσθέστε περιγραφή (προαιρετικό)
4. Επιλέξτε ένα χρώμα (προαιρετικό)
5. Ενεργοποιήστε ή απενεργοποιήστε το toggle **ΕΝΕΡΓΟ**
6. Κάντε κλικ στο κουμπί "ΔΗΜΙΟΥΡΓΙΑ ΥΠΗΡΕΣΙΑΣ"

#### Επεξεργασία Υπάρχουσας Υπηρεσίας Καθαριότητας

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Τροποποιήστε τα επιθυμητά πεδία
4. Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΥΠΗΡΕΣΙΑΣ"

#### Διαγραφή Υπηρεσίας Καθαριότητας

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Delete"
3. Επιβεβαιώστε τη διαγραφή

#### Ενεργοποίηση/Απενεργοποίηση Υπηρεσίας

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Χρησιμοποιήστε το toggle **ΕΝΕΡΓΟ** για να ενεργοποιήσετε ή να απενεργοποιήσετε την υπηρεσία
4. Κάντε κλικ στο κουμπί "ΕΝΗΜΕΡΩΣΗ ΥΠΗΡΕΣΙΑΣ"

### Σχέση με Άλλες Ενότητες

#### Σχέση με Σχέδια Καθαριότητας (Housekeeping Plans)

* Κάθε σχέδιο καθαριότητας περιέχει μια ή περισσότερες υπηρεσίες καθαριότητας
* Οι υπηρεσίες εκχωρούνται σε σχέδια με συγκεκριμένη συχνότητα

#### Σχέση με Υπαλλήλους Καθαριότητας (Housekeeping Maids)

* Οι υπηρεσίες εκτελούνται από τους υπαλλήλους καθαριότητας
* Κάθε υπάλληλος μπορεί να εκτελέσει μία ή περισσότερες υπηρεσίες

### Συχνές Ερωτήσεις

#### Ερώτηση: Τι είναι η διαφορά μεταξύ υπηρεσιών καθαριότητας και σχεδίων καθαριότητας;

**Απάντηση:** Οι υπηρεσίες καθαριότητας είναι ατομικές εργασίες (π.χ. "Change Sheet"), ενώ τα σχέδια καθαριότητας είναι συλλογές υπηρεσιών που εκχωρούνται σε δωμάτια με συγκεκριμένη συχνότητα.

#### Ερώτηση: Μπορώ να αλλάξω το σύντομο όνομα μετά τη δημιουργία;

**Απάντηση:** Ναι, μπορείτε να αλλάξετε το σύντομο όνομα επεξεργάζοντας την υπηρεσία.

#### Ερώτηση: Τι συμβαίνει αν διαγράψω μια υπηρεσία που χρησιμοποιείται;

**Απάντηση:** Δεν θα μπορέσετε να διαγράψετε την υπηρεσία εάν χρησιμοποιείται σε ενεργά σχέδια καθαριότητας. Θα πρέπει πρώτα να αφαιρέσετε την υπηρεσία από τα σχέδια.

#### Ερώτηση: Πόσες υπηρεσίες καθαριότητας μπορώ να δημιουργήσω;

**Απάντηση:** Δεν υπάρχει όριο στον αριθμό των υπηρεσιών που μπορείτε να δημιουργήσετε.
