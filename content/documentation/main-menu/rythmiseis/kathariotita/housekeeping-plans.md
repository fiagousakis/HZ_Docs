# Housekeeping Plans

Η ενότητα **Σχέδια Καθαριότητας** (Housekeeping Plans) σας επιτρέπει να δημιουργήσετε και να διαχειριστείτε σχέδια καθαριότητας που ορίζουν ποιες υπηρεσίες καθαριότητας θα εκτελούνται και με ποια συχνότητα για συγκεκριμένα δωμάτια ή ομάδες δωματίων. Κάθε σχέδιο περιέχει μια λίστα υπηρεσιών καθαριότητας με τη συχνότητα εκτέλεσής τους.

<figure><img src="../../../.gitbook/assets/Screenshot 2026-05-13 150752.jpg" alt=""><figcaption></figcaption></figure>

**Κουμπιά Ενεργειών**

* **Filter:** Κουμπί φιλτραρίσματος
* **Add Housekeeping Plan:** Δημιουργία νέου σχεδίου καθαριότητας

#### Λίστα Σχεδίων Καθαριότητας

| Στήλη           | Περιγραφή                               | Τύπος Δεδομένων   |
| --------------- | --------------------------------------- | ----------------- |
| **ΟΝΟΜΑ**       | Το όνομα του σχεδίου καθαριότητας       | Text              |
| **ΤΥΠΟΣ**       | Τύπος σχεδίου (Rooms, Apartments, etc.) | Text              |
| **ΕΝΕΡΓΟ**      | Κατάσταση ενεργοποίησης                 | Boolean (ΝΑΙ/ΟΧΙ) |
| **Action Menu** | Ενέργειες (Edit/Delete)                 | Dropdown          |

Στο κάτω μέρος της λίστας εμφανιζεται το σύνολο των πλάνων καθαριότητας (π.χ. TOTAL HOUSEKEEPING PLANS: 2)

Κάθε γραμμή στον πίνακα διαθέτει ένα action menu που περιέχει:

* **Edit:** Ανοίγει τη φόρμα επεξεργασίας του σχεδίου
* **Delete:** Διαγράφει το σχέδιο (με επιβεβαίωση)

### Φόρμα Δημιουργίας/Επεξεργασίας Σχεδίου Καθαριότητας

Η φόρμα περιέχει τρεις ενότητες:

1. **Βασικές Πληροφορίες (Basic Details)**
2. **Περιορισμοί (Restrictions)**
3. **Υπηρεσίες (Services)**

#### Περιορισμοί (Restrictions)

Αυτή η ενότητα σας επιτρέπει να ορίσετε κάποια φίλτρα περιορισμούς βάση των οποίων θα ισχύει το πλάνο καθαρισμού, όπως πηγή, δωμάτιο, ομάδα δωματίων και άλλα.

| Πεδίο         | Περιγραφή                        | Τύπος           | Υποχρεωτικό | Παράδειγμα                    |
| ------------- | -------------------------------- | --------------- | ----------- | ----------------------------- |
| **ΠΗΓΗ**      | Πηγή (Booking.com, Airbnb, κλπ.) | Dropdown Search | Όχι         | "Booking.com"                 |
| **ROOM TYPE** | Τύπος δωματίου                   | Dropdown Search | Όχι         | "Double Room", "Suite"        |
| **ROOM**      | Συγκεκριμένο δωμάτιο             | Dropdown Search | Όχι         | "101", "102"                  |
| **ΓΚΡΟΥΠ**    | Ομάδα δωματίων                   | Dropdown        | Όχι         | "Ground Floor", "First Floor" |
| **FLOOR**     | Όροφος δωματίων                  | Dropdown        | Όχι         | "1st Floor", "2nd Floor"      |
| **ALLOTMENT** | Σύμβαση/Allotment                | Dropdown Search | Όχι         | "Contract 1"                  |
| **ΕΤΑΙΡΙΑ**   | Εταιρία                          | Dropdown Search | Όχι         | "TUI", "Booking.com"          |
| **AGENTS**    | Πράκτορες                        | Dropdown Search | Όχι         | "Agent 1"                     |

#### Υπηρεσίες (Services)

Αυτή η ενότητα περιέχει τη λίστα των υπηρεσιών καθαριότητας που περιλαμβάνονται στο σχέδιο.

| Στήλη         | Περιγραφή                    | Τύπος Δεδομένων |
| ------------- | ---------------------------- | --------------- |
| **ΟΝΟΜΑ**     | Όνομα υπηρεσίας καθαριότητας | Text            |
| **FREQUENCY** | Συχνότητα εκτέλεσης          | Text            |
| **ΕΝΕΡΓΟ**    | Κατάσταση ενεργοποίησης      | Boolean         |
| **Action**    | Αφαίρεση υπηρεσίας           | Button          |

**Ενέργειες Υπηρεσιών**

* **Add service:** Προσθήκη νέας υπηρεσίας στο σχέδιο
* **Remove (X):** Αφαίρεση υπηρεσίας από το σχέδιο

#### Κουμπιά Ενεργειών

* **UPDATE PLAN:** Αποθήκευση αλλαγών σε υπάρχον σχέδιο
* **CREATE PLAN:** Δημιουργία νέου σχεδίου (εμφανίζεται μόνο σε νέα εγγραφή)

### Λειτουργίες & Ενέργειες

#### Αναζήτηση Σχεδίου Καθαριότητας

1. Πληκτρολογήστε το όνομα του σχεδίου στο πεδίο αναζήτησης
2. Το σύστημα φιλτράρει αυτόματα τα αποτελέσματα

#### Φιλτράρισμα

1. Κάντε κλικ στο κουμπί "Filter"
2. Επιλέξτε τα κριτήρια φιλτραρίσματος (π.χ. Ενεργά σχέδια)
3. Εφαρμόστε τα φίλτρα

#### Δημιουργία Νέου Σχεδίου Καθαριότητας

1. Κάντε κλικ στο κουμπί "Add Housekeeping Plan"
2. Συμπληρώστε τα υποχρεωτικά πεδία (ΟΝΟΜΑ, PLAN TYPE)
3. Προσθέστε περιορισμούς (προαιρετικό)
4. Προσθέστε υπηρεσίες καθαριότητας
5. Κάντε κλικ στο κουμπί "CREATE PLAN"

#### Επεξεργασία Υπάρχοντος Σχεδίου Καθαριότητας

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Τροποποιήστε τα επιθυμητά πεδία
4. Κάντε κλικ στο κουμπί "UPDATE PLAN"

#### Διαγραφή Σχεδίου Καθαριότητας

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Delete"
3. Επιβεβαιώστε τη διαγραφή

#### Προσθήκη Υπηρεσίας σε Σχέδιο

1. Κάντε κλικ στο κουμπί "Add service"
2. Επιλέξτε την υπηρεσία καθαριότητας από το dropdown
3. Ορίστε τη συχνότητα εκτέλεσης
4. Κάντε κλικ στο κουμπί "UPDATE PLAN" για αποθήκευση

#### Αφαίρεση Υπηρεσίας από Σχέδιο

1. Κάντε κλικ στο κουμπί "X" δίπλα στην υπηρεσία
2. Κάντε κλικ στο κουμπί "UPDATE PLAN" για αποθήκευση

#### Ενεργοποίηση/Απενεργοποίηση Σχεδίου

1. Κάντε κλικ στο action menu (τρεις τελείες) της γραμμής
2. Επιλέξτε "Edit"
3. Χρησιμοποιήστε το toggle **ΕΝΕΡΓΟ** για να ενεργοποιήσετε ή να απενεργοποιήσετε το σχέδιο
4. Κάντε κλικ στο κουμπί "UPDATE PLAN"



### Συχνότητες που Υποστηρίζονται

* **Κάθε Μέρα** (Daily)
* **Κάθε 2 Ημέρες** (Every 2 days)
* **Κάθε 3 Ημέρες** (Every 3 days)
* **Κάθε Εβδομάδα** (Weekly)
* **Στην Άφιξη** (On Arrival)
* **Στην Αναχώρηση** (On Departure)
* **Every 2 days Except 1 day before Departure** (Κάθε 2 ημέρες εκτός 1 ημέρας πριν την αναχώρηση)

### Σχέση με Άλλες Ενότητες

#### Σχέση με Υπηρεσίες Καθαριότητας (Housekeeping Services)

* Κάθε σχέδιο περιέχει μία ή περισσότερες υπηρεσίες καθαριότητας
* Οι υπηρεσίες πρέπει να δημιουργηθούν πρώτα πριν τις προσθέσετε σε ένα σχέδιο

#### Σχέση με Υπαλλήλους Καθαριότητας (Housekeeping Maids)

* Τα σχέδια εκχωρούνται σε υπαλλήλους καθαριότητας για εκτέλεση
* Κάθε υπάλληλος μπορεί να εκτελέσει ένα ή περισσότερα σχέδια

#### Σχέση με Δωμάτια (Rooms)

* Τα σχέδια εφαρμόζονται σε δωμάτια ή ομάδες δωματίων
* Κάθε δωμάτιο μπορεί να έχει ένα ή περισσότερα σχέδια

### Συχνές Ερωτήσεις

#### Ερώτηση: Τι είναι η διαφορά μεταξύ σχεδίου καθαριότητας και υπηρεσίας καθαριότητας;

**Απάντηση:** Μια υπηρεσία καθαριότητας είναι μια ατομική εργασία (π.χ. "Change Sheet"), ενώ ένα σχέδιο καθαριότητας είναι μια συλλογή υπηρεσιών που εκχωρούνται σε δωμάτια με συγκεκριμένη συχνότητα.

#### Ερώτηση: Μπορώ να έχω πολλαπλά σχέδια για το ίδιο δωμάτιο;

**Απάντηση:** Ναι, μπορείτε να έχετε πολλαπλά σχέδια για το ίδιο δωμάτιο.&#x20;

#### Ερώτηση: Τι συμβαίνει αν αφαιρέσω μια υπηρεσία από ένα σχέδιο;

**Απάντηση:** Η υπηρεσία θα αφαιρεθεί από το σχέδιο και δεν θα εκτελείται πλέον για τα δωμάτια που χρησιμοποιούν αυτό το σχέδιο.

#### Ερώτηση: Πόσες υπηρεσίες μπορώ να προσθέσω σε ένα σχέδιο;

**Απάντηση:** Δεν υπάρχει όριο στον αριθμό των υπηρεσιών που μπορείτε να προσθέσετε σε ένα σχέδιο.

#### Ερώτηση: Μπορώ να αλλάξω τη συχνότητα μιας υπηρεσίας σε ένα σχέδιο;

**Απάντηση:** Ναι, μπορείτε να αλλάξετε τη συχνότητα επεξεργάζοντας το σχέδιο και τροποποιώντας τη συχνότητα της υπηρεσίας.
