# Ενέργειες πλάνου

Το Πλάνο Κρατήσεων παρέχει πληθώρα ενεργειών που επιτρέπουν τη διαχείριση κρατήσεων και δωματίων γρήγορα και αποτελεσματικά, χρησιμοποιώντας το ποντίκι ή ειδικά μενού επιλογών.

#### Ενέργειες σε Κενό Δωμάτιο (Action Selector)

<div align="left"><figure><img src="../../.gitbook/assets/Screenshot 2026-01-14 133115.jpg" alt=""><figcaption></figcaption></figure></div>

Κάνοντας κλικ σε ένα κενό κελί στο πλάνο, εμφανίζεται το μενού επιλογών Please select an action:

* Add Reservation: Έναρξη διαδικασίας για προσθήκη νέας κράτησης.
* Set as out of order: Θέτει το συγκεκριμένο δωμάτιο σε κατάσταση "Εκτός Λειτουργίας".
* Stop selling this room: Ενεργοποιεί τον περιορισμό "Κλείσιμο Πώλησης" (Stop Sale) για το επιλεγμένο δωμάτιο.
* Reserve Room: Πραγματοποιεί δέσμευση του δωματίου.



#### Αλλαγή Κατάστασης Δωματίου (Housekeeping)

<div align="left"><figure><img src="../../.gitbook/assets/Screenshot 2026-01-14 133920.jpg" alt=""><figcaption></figcaption></figure></div>

Πατώντας πάνω στο εικονίδιο κατάστασης (π.χ. CLN, DRT) στην αριστερή στήλη των δωματίων, ανοίγει το παράθυρο διαχείρισης καθαριότητας:

* Καθαρό: Ορισμός δωματίου ως έτοιμο προς χρήση.
* Ελεγμένο: Επιβεβαίωση ελέγχου μετά τον καθαρισμό.
* Βρώμικο: Σήμανση ότι το δωμάτιο χρειάζεται καθαρισμό.
* Εκτός Υπηρεσίας: Προσωρινή απόσυρση από τη διαθεσιμότητα για λόγους συντήρησης.
* Εκτός Λειτουργίας: Πλήρης απενεργοποίηση του δωματίου.
* Σε εξέλιξη: Ένδειξη ότι ο καθαρισμός πραγματοποιείται τη δεδομένη στιγμή.



#### Περιορισμοί Διαθεσιμότητας

<div align="left"><figure><img src="../../.gitbook/assets/Screenshot 2026-01-14 133237.jpg" alt=""><figcaption></figcaption></figure></div>

Κάνοντας κλικ σε κάποια ημερομηνία στη γραμμή τύπου δωματίου εμφανίζεται η φόρμα περιορισμοί διαθεσιμότητας και μπορείτε να ορίσετε τα εξής:

* Τύπος Δωματίου: Επιλογή της κατηγορίας δωματίου για την εφαρμογή του περιορισμού.
* Εύρος Ημερομηνιών: Καθορισμός της περιόδου έναρξης και λήξης.
* Κατάσταση Διαθεσιμότητας: Εναλλαγή μεταξύ ΑΝΟΙΧΤΗ ή ΚΛΕΙΣΙΜΟ ΠΩΛΗΣΕΩΝ.
* Δημόσια Διαθεσιμότητα: Χειροκίνητη ρύθμιση του πλήθους των δωματίων που θα είναι διαθέσιμα στα κανάλια πωλήσεων. Επιλέγοντας - ή + στη δημόσια διαθεσιμότητα μπορείτε να μειώσετε ή να αυξήσετε τα διαθέσιμα δωμάτια (undersell / oversell). &#x20;



#### Εφαρμογή Τιμοκαταλόγων

<div align="left"><figure><img src="../../.gitbook/assets/Screenshot 2026-01-14 133345.jpg" alt=""><figcaption></figcaption></figure></div>

Στο παράθυρο Εφαρμογή Τιμοκαταλόγων υπάρχουν οι επιλογές:

* Τιμοκατάλογος: Αναζήτηση και επιλογή του επιθυμητού rate level.
* Εύρος Ημερομηνιών: Καθορισμός του διαστήματος στο οποίο θα εφαρμοστεί η νέα τιμή.



#### Πλήρες Μενού Ενεργειών Κράτησης&#x20;

Αυτό το μενού είναι διαθέσιμο με δεξί κλικ στην κράτηση ή μέσω του εικονιδίου (...):

* View Reservation: Προβολή των βασικών στοιχείων της κράτησης.
* View Online Reservation: Προβολή της αρχικής online κράτησης από το κανάλι προέλευσης.
* Print Reg. Card: Εκτύπωση του δελτίου άφιξης του πελάτη.
* Διαχείριση Διαμονής: Πρόσβαση στις ρυθμίσεις της διαμονής.
* Αλλαγή Διαμονής: Λειτουργία για αλλαγή δωματίου ή ημερομηνιών.
* Στάθμευση Διαμονής: Διαχείριση θέσης parking.
* Κλείδωμα Κράτησης: Αποτροπή τυχαίων αλλαγών ή μετακινήσεων.
* Εκχώρηση Πρωτεύοντος Επισκέπτη: Ορισμός του κύριου υπεύθυνου της κράτησης.
* Αλλαγή Τιμοκαταλόγου: Άνοιγμα παραθύρου για εφαρμογή νέου rate level.
* Παράταση Διαμονής: Επέκταση της περιόδου παραμονής.
* Μείωση Διαμονής: Σύντμηση της περιόδου παραμονής.
* Τροποποίηση Αναχώρησης/Άφιξης: Αλλαγή των ωρών check-in/out.
* Αλλαγή Ενοίκων: Προσθαφαίρεση ή τροποποίηση των ατόμων που διαμένουν.
* Financial actions: Μετάβαση σε υπομενού για οικονομικές κινήσεις και έκδοση παραστατικών.
* Delete: Οριστική διαγραφή της κράτησης.
