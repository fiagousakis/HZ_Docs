# Multi-property πλάνο

Η λειτουργία Multi Property Calendar επιτρέπει τη συνδυαστική προβολή και τη διαχείριση διαθεσιμότητας και κρατήσεων για περισσότερες από μία ξενοδοχειακές μονάδες/καταλύματα μέσα από ένα ενοποιημένο ημερολόγιο.

#### Ρυθμίσεις Multiproperty (Multiproperty Settings)

<div align="left"><figure><img src="../../.gitbook/assets/image (5).png" alt=""><figcaption></figcaption></figure></div>

Κάνετε κλικ στο εικονίδιο multiproperty και στο αναδυόμενο παράθυρο παραμετροποίησης ορίζετε τα καταλύματα που θέλετε να συμμετέχουν στη συνδυαστική προβολή:

<div align="left"><figure><img src="../../.gitbook/assets/image (7).png" alt=""><figcaption></figcaption></figure></div>

* PROPERTIES `*`: Πεδίο πολλαπλής επιλογής (multi-select tags) υποχρεωτικής συμπλήρωσης (φέρει κόκκινο αστερίσκο).
  * Επιτρέπει την επιλογή των καταλυμάτων από όσα έχετε πρόσβαση ως χρήστης, που θα εμφανίζονται ταυτόχρονα στο ημερολόγιο.
  * Κάνοντας κλικ στο εικονίδιο `✕` δίπλα από το όνομα οποιουδήποτε καταλύματος, αυτό αφαιρείται άμεσα από τη λίστα προβολής.

#### Κουμπιά Ενεργειών

* Disable: Απενεργοποίηση της πολυ-καταλυματικής λειτουργίας και επαναφορά του συστήματος στη μεμονωμένη προβολή καταλύματος.
* Update: Μπλε κουμπί για την οριστική αποθήκευση των επιλογών και την εφαρμογή τους στο Multi Property Calendar.

> Δεν μπορείτε να κάνετε αλλαγές στο πλάνο όσο βρίσκεσται σε multi-properry view
