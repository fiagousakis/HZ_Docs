# Τραπέζια

Η ενότητα Τραπέζια (Tables) αποτελεί τον κεντρικό πίνακα ελέγχου του Point of Sale (POS). Από εδώ, το προσωπικό μπορεί να επιβλέπει την κατάσταση όλων των τραπεζιών στα διάφορα τμήματα εστίασης και παροχής υπηρεσιών του καταλύματος (όπως Εστιατόριο, Pool Bar ή SPA), να βλέπει ποια είναι διαθέσιμα (ελεύθερα) ή ανοιχτά (απασχολημένα) και να ανοίγει νέες παραγγελίες.

Μπορείτε να κάνετε κλικ σε ένα διαθέσιμο τραπέζι για να ξεκινήσετε μία νέα παραγγελία ή σε ανοιχτό τρπέζι ώστε να μεταβείτε στην ανοιχτή παραγγελία.&#x20;

Η διεπαφή προσφέρει δύο βασικούς τρόπους προβολής: List (Λίστα) και Plan (Κάτοψη).

#### Εργαλεία Πλοήγησης & Φίλτρα (Κοινά και στις δύο προβολές)

Στο πάνω μέρος της οθόνης (header) βρίσκεται η κεντρική μπάρα εργαλείων:

* **Εναλλαγή Προβολής:**
  * List (Λίστα): Εμφανίζει τα τραπέζια ως ομοιόμορφες παραλληλόγραμμες κάρτες.
  * Plan (Κάτοψη): Απεικονίζει τα τραπέζια στον χώρο (καθημερινή κάτοψη/σκαρίφημα) με τα πραγματικά τους σχήματα και θέσεις.
* **Φίλτρα Κατάστασης:**
  * Όλα: Προβολή όλων των τραπεζιών (ανεξαρτήτως κατάστασης).
  * Ανοιχτά (Κόκκινη ένδειξη): Εμφανίζει μόνο τα τραπέζια που έχουν ενεργή παραγγελία ή ανοιχτό λογαριασμό.
  * Διαθέσιμα (Πράσινη ένδειξη): Δείχνει μόνο τα άδεια/ελεύθερα τραπέζια.
* **Φίλτρα Τμημάτων** (Δεξί μέρος): Εμφανίζει τα τραπέζια συγκεκριμένων σημείων πώλησης (π.χ. Όλα, Pool Bar, Restaurant, Reception, SPA).

Στην προβολή λίστας κάθε τραπέζι ή σημείο πώλησης αναπαρίσταται ως μια διακριτή έγχρωμη  κάρτα (ανάλογα το τμήμα-section στο οποίο ανήκει). Κάθε κάρτα περιέχει τις εξής πληροφορίες:

* Όνομα Τραπεζιού: Ο κωδικός ή το όνομα (π.χ. _Bar1_, _SB2_, _R1_, _SPA - Couple Room_).
* Τρέχον Υπόλοιπο: Στην πάνω δεξιά γωνία της κάρτας αναγράφεται το τρέχον ποσό του ανοιχτού λογαριασμού (π.χ. _0 €_ για άδεια τραπέζια).
* Τμήμα (Department): Στο κάτω αριστερό μέρος της κάρτας αναγράφεται ο χώρος στον οποίο ανήκει το τραπέζι (π.χ. _Pool Bar_, _Restaurant_).

#### Προβολή Κάτοψης (Plan View)

Στην προβολή κάτοψης τα τραπέζια απεικονίζονται με ρεαλιστική διάταξη πάνω σε έναν εικονικό καμβά:

* Σχήματα Τραπεζιών: Τα αντικείμενα έχουν διαφορετικά σχήματα που αντιστοιχούν στην πραγματικότητα (π.χ. στρογγυλά, τετράγωνα, παραλληλόγραμμα, ρόμβοι).
* Χρωματική Οργάνωση: Διατηρείται η ίδια χρωματική φιλοσοφία με την προβολή λίστας, βοηθώντας το προσωπικό να αναγνωρίζει τις ζώνες ευθύνης του.
* Εργαλεία Καμβά (Πάνω Δεξιά): Υπάρχει ένα μικρό μενού ελέγχου για τον χρήστη:
  * \+ / -: Zoom in / Zoom out στην κάτοψη.
  * \[ ] (Full Screen): Επέκταση του καμβά.
  * Λουκέτο (Lock): Ξεκλείδωμα της θέσης των τραπεζιών ώστε να μπορείτε να τα μετακινήσετε, να αλλάξετε σχήμα τραπεζιού και να ορίσετε χωρητικότητα τραπεζιού.
  * Γρανάζι (Settings): Πρόσβαση στις ρυθμίσεις του grid (πλέγματος)
    * Minimap: Διακόπτης switch για την ενεργοποίηση ή απενεργοποίηση ενός μικρού χάρτη πλοήγησης (minimap) πάνω στον καμβά, διευκολύνοντας τη γρήγορη μετακίνηση σε πλάνα με μεγάλο αριθμό τραπεζιών.
    * Snap to grid: Πεδίο ορισμού pixel (π.χ. 10) συνοδευόμενο από διακόπτη switch (ενεργοποιημένος με μπλε σήμανση). Όταν είναι ενεργός, τα τραπέζια «μαγνητίζουν» αυτόματα στις γραμμές του αόρατου πλέγματος κατά τη μετακίνησή τους, εξασφαλίζοντας την απόλυτη ευθυγράμμιση και ομοιομορφία του σχεδίου.
    * Background color: Παλέτα έτοιμων χρωματικών επιλογών (shades) με ενσωματωμένη μπάρα κύλισης (scrollbar) στα δεξιά. Επιτρέπει την άμεση αλλαγή του χρώματος φόντου της κάτοψης για βέλτιστη αντίθεση κατά τη διάρκεια της εργασίας.
