# Events

Η ενότητα Events επιτρέπει την καταγραφή, οργάνωση και παρακολούθηση συνεδρίων, εκθέσεων, γάμων ή άλλων εκδηλώσεων που λαμβάνουν χώρα στο κατάλυμα. Η διαχείριση αυτών των εκδηλώσεων βοηθά στον σωστό προγραμματισμό των διαθέσιμων πόρων.

#### Λίστα Events

Στην κύρια οθόνη της ενότητας εμφανίζεται ο πίνακας με όλα τα καταχωρημένα γεγονότα:

* Search for events...: Πεδίο ελεύθερου κειμένου με μπλε κουμπί αναζήτησης για τη γρήγορη εύρεση συγκεκριμένων εκδηλώσεων.
* Φίλτρα v: Dropdown επιλογή για το φιλτράρισμα και την κατηγοριοποίηση των εγγραφών.
* +Add Event: Μπλε κουμπί στο πάνω δεξί μέρος για τη δημιουργία μιας νέας εκδήλωσης.

**Στήλες Πίνακα Δεδομένων**

* ONOMA: Η ονομασία της εκδήλωσης (π.χ. _wedding 1_, _Philoxenia_, _Agrotica_, _WEDDING_).
* FROM/TO: Το χρονικό διάστημα (ημερομηνία έναρξης και λήξης) διεξαγωγής του event.
* COLOR: Η ειδική χρωματική κωδικοποίηση (hex code) που έχει αποδοθεί στην εκδήλωση για την οπτική της αναγνώριση στο σύστημα (π.χ. _#0073ff_).
* ΕΝΕΡΓΟ: Διακόπτης switch με πράσινη ένδειξη ΝΑΙ που υποδεικνύει ότι το event είναι ενεργό.
* ... v: Drop-down μενού στο τέλος κάθε γραμμής για την επεξεργασία ή τη διαγραφή της αντίστοιχης εγγραφής.

**Στοιχεία Υποσέλιδου & Πλοήγηση**

* TOTAL EVENTS: Ο συνολικός αριθμός των καταχωρημένων εκδηλώσεων (π.χ. _4_).
* Σελιδοποίηση: Πλήκτρα πλοήγησης (`<`, `1`, `>`) για τη μετακίνηση μεταξύ των σελίδων του πίνακα.
* 10 / page v: Dropdown επιλογή για τον καθορισμό του πλήθους των γραμμών που προβάλλονται ανά σελίδα.

#### Δημιουργία / Επεξεργασία Event

Η φόρμα προσθήκης ή επεξεργασίας event εμφανίζεται σε αναδυόμενο παράθυρο με τον τίτλο Create new event ή Update event αντίστοιχα.

Basic details

* ONOMA `*`: Το όνομα της εκδήλωσης (υποχρεωτικό πεδίο). Κατά την επεξεργασία μιας έγκυρης καταχώρησης, το σύστημα εμφανίζει μια πράσινη ένδειξη επιβεβαίωσης (checkmark).
* ΕΝΕΡΓΟ: Διακόπτης switch για την ενεργοποίηση (ΝΑΙ - μπλε σήμανση) ή την απενεργοποίηση (ΟΧΙ - γκρι σήμανση) του event.
* ΠΕΡΙΓΡΑΦΗ: Πεδίο ελεύθερου κειμένου για την εισαγωγή αναλυτικών πληροφοριών ή διευκρινίσεων σχετικά με την εκδήλωση.
* ΑΠΟ `*`: Ημερομηνία έναρξης της εκδήλωσης με ενσωματωμένο εικονίδιο ημερολογίου (υποχρεωτικό πεδίο).
* ΕΩΣ `*`: Ημερομηνία λήξης της εκδήλωσης με ενσωματωμένο εικονίδιο ημερολογίου (υποχρεωτικό πεδίο).
* ΧΡΩΜΑ: Μπάρα επιλογής (slider) για τον ορισμό του αντιπροσωπευτικού χρώματος της εκδήλωσης. Κατά την επεξεργασία (Update), εμφανίζεται και το κουμπί Διαγραφή χρώματος για την επαναφορά της προεπιλογής.

Κουμπιά Ενεργειών Φόρμας

* ΚΛΕΙΣΙΜΟ: Ακύρωση της τρέχουσας διαδικασίας και επιστροφή στην κεντρική λίστα.
* CREATE EVENT / UPDATE EVENT: Μπλε κουμπί με εικονίδιο check για την οριστική αποθήκευση της νέας καταχώρησης ή την επιβεβαίωση των αλλαγών αντίστοιχα.
