# Eτικέτες Επαφών

Η ενότητα Ετικέτες Επαφών (Contact Labales) του Hotelizer PMS επιτρέπει την κατηγοριοποίηση των πελατών μέσω προσαρμοσμένων ετικετών (labels). Αυτά τα επίπεδα χρησιμεύουν στην άμεση οπτική αναγνώριση ειδικών κατηγοριών επισκεπτών (π.χ. VIP ή Loyalty) σε πολλές λίστες του συστήματος και εμφανίζονται ως έγχρωμα "pills" δίπλα στο όνομα του επισκέπτη (π.χ. Παραμένοντες Επισκέπτες).

#### Λίστα Ετικετών

Η κεντρική οθόνη εμφανίζει τα ήδη δημιουργημένα επίπεδα και τις βασικές τους ιδιότητες:

* ΟΝΟΜΑ: Η περιγραφή της κατηγορίας (π.χ. Blacklist, Loyalty, Repeater, VIP).
* ΧΡΩΜΑ: Η χρωματική σήμανση που συνοδεύει το επίπεδο, επιτρέποντας την ταχεία αναγνώριση από τη ρεσεψιόν.
* TOTAL LABELS: Ο συνολικός αριθμός των ετικετών που έχουν οριστεί (στο παράδειγμα: 4)

Εργαλεία:

* Μπάρα αναζήτησης για εύρεση ετικέτας&#x20;
* +Add Contact Label για τη δημιουργία νέου

#### Φόρμα Επεξεργασίας (Update contact label)

Όταν δημιουργείτε ή επεξεργάζεστε ένα επίπεδο, εμφανίζεται μια φόρμα με τα εξής πεδία:

* NAME (\*): Το όνομα του επιπέδου. Είναι υποχρεωτικό πεδίο (επισημαίνεται με κόκκινο αστερίσκο).
* ΧΡΩΜΑ: Επιλογή του χρώματος μέσω παλέτας ή εισαγωγή hex code (π.χ. #ba68c8). Το επιλεγμένο χρώμα θα εμφανίζεται ως φόντο στην ετικέτα του πελάτη.
