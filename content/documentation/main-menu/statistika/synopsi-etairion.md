# Σύνοψη εταιριών

Ιδανικό εργαλείο για να παρακολουθείτε την απόδοση των B2B συνεργασιών σας (εταιρίες, πρακτορεία).Βασικές Λειτουργίες & Πληροφορίες:

* Ανάλυση Συνεργατών: Το πρώτο γράφημα (ραβδόγραμμα) σας δίνει στατιστικά στοιχεία για τις κρατήσεις και τα έσοδα με τις εταιρίες που έχετε συνεργασία.
* Εταιρίες Ανά Μήνα: Στο δεύτερο γράφημα (line chart) μπορείτε να δείτε αναλυτικά, ανά μήνα, την πορεία των εσόδων ανά εταιρία.
* Αναλυτικά Δεδομένα: Ο πίνακας προσφέρει δεδομένα για Έσοδα Δωματίου (Τρέχον, Προηγούμενο, Πραγματικότητα, Προβολή), ADR, Κρατήσεις, Ακυρώσεις και Νύχτες ανά εταιρία. Μπορείτε να εξάγετε τα δεδομένα σε Excel.
