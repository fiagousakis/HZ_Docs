# Ανοιχτοί Λογαριασμοί

<figure><img src="../../../.gitbook/assets/Screenshot 2026-02-12 170425.jpg" alt=""><figcaption></figcaption></figure>

Ο ανοιχτός λογαριασμός είναι η **προφόρμα** πριν το τελικό παραστατικό. Μπορείτε να τον **επεξεργαστείτε**, να τον **εκτυπώσετε** και όταν είστε έτοιμοι μπορείτε να τον **εκδώσετε** ώστε να δημιουργηθεί το **τελικό παραστατικό**.

Ανοιχτός λογαριασμός μπορεί να δημιουργηθεί σε ένα δωμάτιο που δεν έχει αναχωρήσει ακόμα από το κατάλυμά σας ή αφού έχει αναχωρήσει, δεν έχει εκδοθεί παραστατικό (ΑΠΥ Απόδειξη Παροχής Υπηρεσιών, ΤΠΥ Τιμολόγιο Παροχής Υπηρεσιών, είτε άλλος τύπος).&#x20;

Αν επιθυμείτε κάποιο συγκεκριμένο ή κάποιους συγκεκριμένους ανοιχτούς λογαριασμούς, Μπορείτε να βρείτε κάποιονν συγκεκριμένο ανοιχτό λογαριασμό μέσω της αναζήτησης ή εφαρμόζοντας τα κατάλληλα φίλτρα.&#x20;

Είναι δυνατή η εκτύπωση και εξαγωγή σε excel αυτής της λίστας.

#### Λίστα ανοιχτών λογαριασμών&#x20;

* ΑΡ. ΛΟΓ. (Αριθμός Λογαριασμού): Περιλαμβάνει τον αύξοντα αριθμό του λογαριασμού (π.χ. 4800) και ακριβώς από κάτω το όνομα του εκδότη (π.χ. Μ ΚΑΤΣΟΥΡΑΣ Ι ΠΑΠΑΠΙ...).
* ΚΩΔΙΚΟΣ ΚΡΑΤΗΣΗΣ: Εμφανίζει τον μοναδικό κωδικό RES ID (π.χ. HZRFJI9AK337) και την ημερομηνία/ώρα που δημιουργήθηκε η κράτηση.
* ΠΕΛΑΤΗΣ: Το ονοματεπώνυμο του φυσικού προσώπου ή η επωνυμία της εταιρείας στην οποία εκδίδεται το παραστατικό.
* ΤΥΠΟΣ ΤΙΜΟΛΟΓΙΟΥ: Αναφέρει τον τύπο του παραστατικού συνοπτικά και με αναλυτική περιγραφή (π.χ. ΕΣΤΑ, ΑΠΥ, ΤΠΥ).
* ΣΥΝΟΛΟ: Η συνολική αξία (gross amount) του συγκεκριμένου λογαριασμού, συμπεριλαμβανομένων όλων των φόρων.
* ΥΠΟΛΟΙΠΟ: Το ποσό που παραμένει ανεξόφλητο για τον συγκεκριμένο λογαριασμό. Εμφανίζεται με έντονο κόκκινο χρώμα όταν υπάρχει εκκρεμότητα.
* ΚΑΤΑΣΤΑΣΗ: Η ένδειξη εγκυρότητας του λογαριασμού:
  * VALID (Πράσινο): Ο λογαριασμός είναι έτοιμος προς έκδοση.
  * INVALID (Κόκκινο): Ο λογαριασμός παρουσιάζει κάποιο πρόβημα. Πηγάνοντας το ποντίκι πάνω του βλέπουμε περισσότερες πληροφορίες.
* Totals: Σύνολο ανοιχτών λογαριασμών, Συνολικό Ποσό χρέωσης, Συνολικό Ποσό Υπόλοιπου. &#x20;
