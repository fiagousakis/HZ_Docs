# Μεταφορά προχρεώσεων

Όταν ανοίξει το παράθυρο της μεταφοράς προχρεώσεων θα εμφανίσει τις **διαθέσιμες χρεώσεις** της **ίδιας κράτησης** τις οποίες μπορείτε να μεταφέρετε στον λογαριασμό. Οι χρεώσεις είναι ομαδοποιημένες ανά τύπο χρέωσης. Τσεκάρετε τις χρεώσεις που θέλετε και πατάτε **ΜΕΤΑΦΟΡΑ ΧΡΕΩΣΕΩΝ**.

<figure><img src="../../../.gitbook/assets/Screenshot 2026-02-17 153926.jpg" alt=""><figcaption></figcaption></figure>

Μπορείτε επίσης να μεταφέρετε χρεώσεις **από άλλες κρατήσεις** και με αυτόν τον τρόπο να **τιμολογήσετε περισσότερες από μια κρατήσεις σε ένα παραστατικό**. Για να γίνει αυτό θα πρέπει να **αναζητήσετε** την άλλη κράτηση στο πεδίο της κράτησης χρησιμοποιώντας τον κωδικό της κράτησης ή κάποιο άλλο στοιχείο και έπειτα θα εμφανιστούν στην λίστα για επιλογή.
