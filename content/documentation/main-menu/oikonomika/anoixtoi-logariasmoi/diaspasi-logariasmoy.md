# Διασπαση Λογαριασμού

Μπορούμε να διασπάσουμε έναν λογαριασμό όταν θέλουμε να χωρίσουμε τις χρεώσεις σε δύο ή περισσότερους πελάτες ή και σε διαφορετικούς τύπους παραστατικού. Για παράδειγμα θέλουμε ένα μέρος του ποσού να χρεωθεί σε ιδιώτη και ένα άλλο στην εταιρεία του.

Ρυθμίζουμε το ποσό απευθείας σε κάθε λογαριασμό ή αλλάζουμε το πεδίο ποσοστό (percentage).  &#x20;
