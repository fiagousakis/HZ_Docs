# Κατάσταση καταλύματος

Η ενότητα Κατάσταση καταλύματος (House Status) αποτελεί το καθημερινό «κέντρο επιχειρήσεων» του ξενοδοχείου, προσφέροντας μια συγκεντρωτική και άμεση εικόνα των κινήσεων της ημέρας. Μέσω αυτής της οθόνης, η ρεσεψιόν μπορεί να διαχειριστεί γρήγορα τις αφίξεις, τις αναχωρήσεις και τις εκκρεμότητες χωρίς να χρειάζεται να πλοηγηθεί σε επιμέρους κρατήσεις.

Στο επάνω μέρος της οθόνης υπάρχουν τέσσερις διακριτές ενότητες (Tabs), οι οποίες φιλτράρουν τις διαμονές βάσει της ημερομηνίας που έχει επιλεγεί στο ημερολόγιο:

* ΑΦΙΞΕΙΣ: Εμφανίζει όλους τους επισκέπτες που αναμένονται για Check-in την επιλεγμένη ημέρα.
* ΠΑΡΑΜΕΝΟΝΤΕΣ: Λίστα των ενοίκων που βρίσκονται ήδη στο κατάλυμα και συνεχίζουν τη διαμονή τους.
* ΑΝΑΧΩΡΗΣΕΙΣ: Εμφανίζει τις διαμονές που ολοκληρώνονται και πρέπει να πραγματοποιηθεί Check-out.
* ΕΚΚΡΕΜΟΤΗΤΕΣ: Συγκεντρώνει κρατήσεις που απαιτούν κάποια ενέργεια ή παραμένουν σε κατάσταση αναμονής.

***

#### Ανάλυση Πεδίων και Πληροφοριών

Οι λίστες της κατάστασης καταλύματος και στις 4 ενότητες περιλαμβάνουν τα περισσότερα από τα παρακάτω πεδία.

| **Πεδίο**          | **Περιγραφή**                                                                                   |
| ------------------ | ----------------------------------------------------------------------------------------------- |
| ΕΠΙΣΚΕΠΤΗΣ         | Το ονοματεπώνυμο, η εθνικότητα (σημαία) και εικονίδια κατάστασης όπως το Web check-in.          |
| ΔΩΜΑΤΙΟ            | Ο αριθμός, ο τύπος δωματίου και η κατάσταση καθαριότητας (π.χ. Βρώμικο ή Καθαρό).               |
| ΕΝΟΙΚΟΙ            | Ο αριθμός των ενηλίκων και των παιδιών που αντιστοιχούν στη συγκεκριμένη διαμονή.               |
| CHECK-IN/OUT       | Οι προγραμματισμένες ημερομηνίες και ώρες άφιξης και αναχώρησης.                                |
| ΤΙΜΗ & ΥΠΟΛΟΙΠΟ    | Η συνολική αξία και το οφειλόμενο ποσό (με κόκκινη σήμανση αν υπάρχει υπόλοιπο).                |
| ΠΗΓΗ               | Η προέλευση της κράτησης (π.χ. webhotelier, Telephone, E-mail).                                 |
| TASKS / PREFS      | Ενδείξεις για την ύπαρξη σημειώσεων εργασίας ή ειδικών προτιμήσεων του πελάτη.                  |
| TAGS               | Ειδικές ετικέτες που έχουν αποδοθεί στην κράτηση για γρήγορη αναγνώριση (π.χ. VIP).             |
| ΚΑΤΑΣΤΑΣΗ ΔΙΑΜΟΝΗΣ | Το τρέχον status της κράτησης, όπως Επιβεβαιωμένη, Παραμένων ή Αναχώρησε.                       |
| ΕΝΕΡΓΕΙΕΣ          | Διαδραστικά κουμπιά ή σύνδεσμοι για άμεσες πράξεις, όπως Check-in, Check-out ή Αλλαγή Δωματίου. |

> Η ένδειξη "<mark style="color:red;">Δεν παραχωρήθηκε δωμάτιο</mark>" με κόκκινο φόντο υποδεικνύει ότι η κράτηση δεν έχει ακόμη αντιστοιχιστεί σε συγκεκριμένο δωμάτιο στο πλάνο, κάτι που πρέπει να διευθετηθεί πριν το Check-in.

#### Λειτουργίες και Ενέργειες

Η στήλη ΕΝΕΡΓΕΙΕΣ στις λίστες επιτρέπει την αλλαγή της κατάσταστης της κράτησης ανάλογα με την τρέχων κατάσταση (check in, check out, no-show, cancel, revoke confirm, express checkin).

Πατώντας το εικονίδιο «...» ανοίγει ένα εκτενές μενού επιλογών:

* View Reservation: Ανοίγει την πλήρη καρτέλα της κράτησης για προβολή όλων των στοιχείων και των συνδεδεμένων δωματίων.
* View Online Reservation: Επιτρέπει την προβολή της αρχικής κράτησης όπως αυτή ελήφθη από την online πηγή (π.χ. WebHotelier).
* Print Reg. Card: Δημιουργεί το Δελτίο Εγγραφής (Registration Card) του πελάτη προς εκτύπωση για την απαραίτητη υπογραφή κατά το check-in.
* Αλλαγή Διαμονής: Ενέργεια για τη μετακίνηση του πελάτη σε άλλο δωμάτιο ή την τροποποίηση της περιόδου παραμονής του.
* Στάθμευση Διαμονής: Διαχείριση της αντιστοίχισης θέσης στάθμευσης που αφορά τη συγκεκριμένη διαμονή.
* Κλείδωμα Κράτησης: «Κλειδώνει» τη διαμονή στο πλάνο, αποτρέποντας τυχαίες μετακινήσεις ή αλλαγές από άλλους χρήστες.
* Εκχώρηση Πρωτεύοντος Επισκέπτη: Ορισμός του κύριου ατόμου που θα εμφανίζεται ως υπεύθυνο για το δωμάτιο και στο οποίο θα εκδίδονται τα παραστατικά.
* Αλλαγή Τιμοκαταλόγου: Δυνατότητα εφαρμογής διαφορετικής τιμολογιακής πολιτικής ή αλλαγή του Rate Plan της κράτησης.
* Αλλαγή Ενοίκων: Τροποποίηση του αριθμού των ενηλίκων ή των παιδιών που διαμένουν στο δωμάτιο.
* Παράταση Διαμονής: Γρήγορη προσθήκη επιπλέον διανυκτερεύσεων στην τρέχουσα διαμονή.
* Τροποποίηση Αναχώρησης/Άφιξης: Αλλαγή των προβλεπόμενων ωρών check-in ή check-out (π.χ. για παροχή late check-out).
* Financial actions: Υπομενού που οδηγεί στις οικονομικές ενέργειες της κράτησης, όπως προσθήκη χρεώσεων και πληρωμών.
* Delete: Οριστική διαγραφή της συγκεκριμένης διαμονής (σημειώνεται με κόκκινο χρώμα ως ενέργεια που απαιτεί προσοχή).
