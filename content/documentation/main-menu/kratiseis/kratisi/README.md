# Κράτηση

Αποτελεί το κεντρικό σημείο ελέγχου για κάθε κράτηση στο Hotelizer PMS. Εδώ συγκεντρώνονται όλες οι πληροφορίες που αφορούν τις διαμονές, τους επισκέπτες, τις οικονομικές συναλλαγές και την επικοινωνία. Μία κράτηση μπορεί να περιλαμβάνει περισσότερες από μία διαμονές (π.χ. οικογένεια σε δύο δωμάτια), οι οποίες διαχειρίζονται συγκεντρωτικά σε αυτή την οθόνη.

#### Βασικές πληροφορίες και ενέργειες

Στο πάνω μέρος της σελίδας εμφανίζονται το ονοματεπώνυμο του κύριου επισκέπτη, ο μοναδικός Κωδικός Κράτησης (π.χ. #HZRFJI9AK337) και η ημερομηνία/ώρα δημιουργίας. Πιο δεξιά εμφανίζονται:&#x20;

* Κατάσταση Κράτησης: Πτυσσόμενο μενού αλλαγής status  (π.χ. Επιβεβαιωμένη) αλλαγή σε Check-in, Ακύρωση, No show, Ανάκληση Επιβεβαίωσης ή Express checkin.
* Κατάσταση Τιμολόγησης: Ένδειξη αν η κράτηση είναι Μη τιμολογημένη (κόκκινο) ή Πλήρως τιμολογημένη (πράσινο).
* Μενού ενεργειών:
  * Εκτύπωση κράτησης: Επιτρέπει την εκτύπωση των στοιχείων της κράτησης.
  * Μεταφορά Διαμονών: Επιλογή για τη μετακίνηση των ημερομηνιών ή των δωματίων διαμονής.
  * Επιλογές χρέωσης: Ρυθμίσεις που αφορούν τον τρόπο τιμολόγησης (εμφανίζεται απενεργοποιημένο στο screenshot).
  * Προσθήκη Έξτρα: Για την καταχώρηση επιπλέον υπηρεσιών (π.χ. πρωινό, μεταφορά).
  * Προσθήκη χρέωσης: Για τη χειροκίνητη εισαγωγή μιας νέας χρέωσης στην κράτηση.
  * Επιλογές πληρωμής: Ρυθμίσεις σχετικά με τους τρόπους πληρωμής (επίσης απενεργοποιημένο).
  * Προσθήκη Πληρωμής: Για την καταχώρηση μιας νέας εισπραχθείσας πληρωμής.
  * Επιστροφή Πληρωμής: Για τη διαδικασία επιστροφής χρημάτων (refund) στον πελάτη.
*   Μενού αποστολής email: Επιτρέπει την άμεση αποστολή τυποποιημένων μηνυμάτων στον πελάτη, καλύπτοντας όλο τον κύκλο της διαμονής του, από την κράτηση έως και μετά την αναχώρηση.

    * Booking Confirmation: Επιβεβαίωση κράτησης.
    * Booking Pre-confirmation: Προ-επιβεβαίωση (συχνά χρησιμοποιείται για εκκρεμείς πληρωμές).
    * Cancellation Email: Ενημέρωση για την ακύρωση της κράτησης.
    * Offer email: Αποστολή οικονομικής προσφοράς.
    * Online check-in: Πρόσκληση στον πελάτη να συμπληρώσει τα στοιχεία του ηλεκτρονικά για ταχύτερη εξυπηρέτηση.
    * Pre-arrival: Ενημερωτικό μήνυμα καλωσορίσματος με οδηγίες πρόσβασης ή άλλες πληροφορίες.
    * Post-stay: Ευχαριστήριο μήνυμα ή πρόσκληση για κριτική (Review).
    * Κατάσταση Τιμολόγησης: Ένδειξη αν η κράτηση είναι Μη τιμολογημένη (κόκκινο) ή Πλήρως τιμολογημένη (πράσινο).

#### Περισσότερες Πληροφορίες (Expandable Section)

Πατώντας την Εμφάνιση Περισσότερων, το σύστημα αναπτύσσει τις λεπτομέρειες "βάσης" της κράτησης:

* Πληροφορίες πελάτη: Επεξεργασία της επαφής και αναζήτηση/σύνδεση Booker, Εταιρείας ή Πράκτορα (Travel Agent).
* Λεπτομέρειες κράτησης: Καθορισμός της Πηγής (π.χ. Telephone), του Τμήματος (Segment) και του Allotment.
* Πολιτικές & παρατηρήσεις:
  * Hotel Notes: Εσωτερικές σημειώσεις ορατές μόνο στο προσωπικό.
  * Παρατηρήσεις: Γενικά σχόλια που αφορούν τη διαμονή και τις ανάγκες του πελάτη.

#### Καρτέλες κράτησης&#x20;

Η πληροφορία της κράτηση οργανώνεται σε επιμέρους ενότητες:

| **Tab**                 | **Περιγραφή**                                                                                                                                                                                                |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ΔΙΑΜΟΝΕΣ                | Προβολή και διαχείριση των δωματίων διαμονών που περιλαμβάνει η κράτηση.                                                                                                                                     |
| ΕΠΙΣΚΕΠΤΕΣ              | Διαχείριση των στοιχείων όλων των ενοίκων και εγγράφων ταυτοποίησης.                                                                                                                                         |
| ΕΞΤΡΑ                   | Προσθήκη επιπλέον παροχών ή υπηρεσιών (π.χ. Spa, Parking).                                                                                                                                                   |
| ΧΡΕΩΣΕΙΣ                | Αναλυτικό ημερολόγιο όλων των χρεώσεων ανά ημέρα και υπηρεσία.                                                                                                                                               |
| ΠΛΗΡΩΜΕΣ                | Καταγραφή προκαταβολών, εξοφλήσεων και ιστορικό εισπράξεων.                                                                                                                                                  |
| ΛΟΓΑΡΙΑΣΜΟΙ & ΤΙΜΟΛΟΓΙΑ | Διαχείριση οικονομικών, λογαριασμών και έκδοση παραστατικών (ΑΠΥ, Τιμολόγια).                                                                                                                                |
| ΣΗΜΕΙΩΣΕΙΣ              | Γενικές σημειώσεις και ιστορικό εσωτερικών ενεργειών.                                                                                                                                                        |
| INBOX                   | Συγκέντρωση όλων των συνομιλιών και μηνυμάτων που αφορούν την κράτηση.                                                                                                                                       |
| ΜΕΤΑΦΟΡΕΣ               | Προγραμματισμός και διαχείριση των transfers (αφίξεις/αναχωρήσεις).                                                                                                                                          |
| ΑΡΧΕΙΟ                  | Στην καρτέλα αυτή μπορείτε να δείτε όλες τις **κινήσεις** που έχουν γίνει στη συγκεκριμένη κράτηση. Από το ποιος δημιούργησε την κράτηση και πότε, μέχρι αν άλλαξε ο τιμοκατάλογος, η τιμή της διανυκτέρευση |
| EMAIL LOG               | Πλήρης καταγραφή όλων των emails που έχουν σταλεί στον πελάτη.                                                                                                                                               |
